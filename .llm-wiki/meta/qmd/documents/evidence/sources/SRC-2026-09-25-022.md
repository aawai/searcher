# Source Code: masonry.ts (Shortest-Column Masonry Algorithm and Hook)

## Summary

`web/src/components/searcher/masonry.ts` 是 [[entities/searcher-项目]]
中实现真实 Masonry
瀑布流布局与自适应高度测量的核心组件代码。文件导出了纯数学计算函数
`calculateMasonryLayout` 与配套的 React hook `useMasonryLayout`。

算法核心基于**最短列贪心补位机制**：

- 输入项序列、高度缓存、容器宽度、间距与基准列宽；
- 维护各列累计高度
  `columnHeights`，遍历待排布元素，将其放置于当前累计高度最小的列；
- 输出各元素的 `(x, y, width, height, column)` 坐标以及整个容器的真实高度
  `maxBottom`。

在 React hook 中：

- 使用 Callback Ref 绑定容器 DOM，保证在抽屉弹窗后置挂载时即刻启动
  `ResizeObserver` 宽度监听；
- 使用统一的 `ResizeObserver` 实例监听每个卡片 DOM 节点，设置
  $|h_{\text{new}} - h_{\text{old}}| \ge 1\text{px}$ 门限，并通过
  `requestAnimationFrame` 批处理合并状态更新，杜绝无限重渲染循环。

## Key Takeaways

- **纯函数解耦**：布局计算纯粹由输入参数驱动，零外部依赖，极易进行单元测试；
- **防抖防死循环**：`requestAnimationFrame` + 1px 阈值彻底规避了
  `ResizeObserver loop completed with undelivered notifications` 异常；
- **无缝对接滚动条**：精准计算
  `containerHeight = maxBottom`，杜绝内容截断与多余滚动死区。
