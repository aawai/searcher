# Set-Cookie header

原文：[MDN Set-Cookie](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Headers/Set-Cookie)；[提取文本](../../raw/sources/SRC-2026-11-05-002/extracted.md)，第 265–304、311–370 行。

## 摘要

省略 `Domain` 得到仅限设置方主机的 host-only Cookie；指定 Domain 则包含子域。`Path` 限制发送范围，但不是防止不同路径读取的安全边界。`HttpOnly` 阻止脚本读取，却不阻止浏览器在 JavaScript 发起的请求中携带 Cookie；`Secure` 限制 HTTPS 传输，localhost 有例外。

显式 `SameSite=Lax` 允许跨站顶层安全方法导航；浏览器默认 Lax 可能对近期设置的 Cookie 额外允许跨站 POST，不能视为显式 Lax 的同义词。`SameSite=None` 要求 Secure；同时给出时 `Max-Age` 优先于 `Expires`，浏览器会话恢复可能恢复会话 Cookie。支持前缀的浏览器会对 `__Host-` 强制 Secure、Path=/ 和不指定 Domain；不支持前缀的浏览器不提供这些额外保证。
