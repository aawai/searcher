# Fetch metadata

原文：[MDN Fetch metadata](https://developer.mozilla.org/en-US/docs/Web/HTTP/Guides/Fetch_metadata)；[提取文本](../../raw/sources/SRC-2026-11-05-001/extracted.md)，第 181–207、257–296、311–353 行。

## 摘要

Fetch Metadata 请求头描述请求上下文：`Sec-Fetch-Site` 区分请求方与目标的 origin/site 关系，`Sec-Fetch-Mode` 和 `Sec-Fetch-Dest` 描述请求模式与目标，`Sec-Fetch-User` 标识用户发起的请求。same-site 包含兄弟子域，不能等同 same-origin。

资源隔离策略可允许同源请求、必要的顶层导航和明确开放跨源的端点；MDN 示例还允许直接用户发起的 `none`。若响应依赖这些头且可缓存，需相应设置 `Vary`。此通用示例不等同 Searcher 当前 API 策略，亦不构成部署安全审计。
