# Plugins 101 (Milkdown)

原文：[docs/plugin/plugins-101.md](https://raw.githubusercontent.com/Milkdown/website/main/docs/plugin/plugins-101.md)；[提取文本](../../raw/sources/SRC-2026-11-13-006/extracted.md)（替代仅含导航壳的 [SRC-2026-11-13-004](/sources/SRC-2026-11-13-004.md)）。

原始 `MilkdownPlugin` 由三层嵌套函数构成：Prepare（`.use()` 注册时执行，`ctx.record` / `ctx.inject`）、Run（编辑器加载时执行，`ctx.wait` / `ctx.get` / `ctx.set` / `ctx.update` / `ctx.done`）与 Post（`.remove()` 或销毁时执行，`ctx.clearTimer` / `ctx.remove`）（第 7–30、161–167 行）。

插件不仅可通过 `ctx.wait(EditorViewReady)` 等待内置阶段，也可创建自定义 `Timer` 并将其追加至 `editorStateTimerCtx` 等 timer slice，从而阻塞内置状态初始化直至异步数据（如远端 Markdown）就绪并写回 `defaultValueCtx`（第 54–91、137–159 行）。注意原文正文第 97、133 行写作 `post.remove` / `pre.inject`，而代码示例第 105、127 行实际调用的是 `ctx.inject` 与 `ctx.remove`。
