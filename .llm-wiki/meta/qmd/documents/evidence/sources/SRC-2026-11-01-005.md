## 摘要

覆盖在其他内容之上的内容有多种名称（overlay、popup、popover、dialog），可分为**模态**（弹层存在时页面其余部分不可交互）与**非模态**（可继续交互）（第 212–215 行）。用 Popover API 创建的弹层**始终非模态**；需要模态时应使用 `<dialog>`，二者可组合，如 `<dialog popover>` 合法（第 217 行）。典型用途：操作菜单、自定义 toast、表单建议、内容选择器、教学 UI（第 219 行）。

`showPopover()` 通过加入 top layer 显示元素；`hidePopover()` 将其移出 top layer 并以 `display: none` 样式隐藏（第 291–295 行）。

## 关键要点

- Popover API 始终非模态，进 top layer。
- 模态需求归 `<dialog>`。
- 显隐通过 `showPopover()` / `hidePopover()`。
