# Shortest-Column Masonry Algorithm and Dynamic Web Layout Architecture

## Summary

本文详细阐述了用于解决不定高卡片布局中 CSS Grid
行高拉伸缺陷的**最短列贪心瀑布流算法（Shortest-Column Greedy Masonry
Algorithm）**。在传统的网格布局中，一行内任意单张卡片的内容增多或展开都会拉长该行所有单元格的高度，造成严重的垂直留白死区。

该架构利用动态 `ResizeObserver`
持续监控容器宽度与各卡片的实际渲染尺寸，按当前累计高度最低的列进行卡片位置贪心分配（$X = \text{minCol} \times (\text{width} + \text{gap})$，$Y = \text{colHeights}[\text{minCol}]$），并将容器总高度设置为所有卡片底部的最大值
$\max(p.y + p.\text{height})$。同时，通过双层 DOM 包装彻底隔离了 Masonry
静态坐标位移与 [[entities/dnd-kit-system]] 交互拖拽位移。

## Key Takeaways

- **贪心填充消除行空白**：后续卡片优先向当前高度最短的列上方补齐，彻底解决传统
  CSS Grid 导致的同行死区空白；
- **真实容器高度计算**：采用 `maxBottom`
  动态更新容器高度，确保外层滚动条与滚动区域严密吻合，避免内容截断；
- **双层 DOM 隔离交互变换**：外层节点管理静态 `translate3d(x, y, 0)` 与平滑
  transition，内层节点承接拖拽手柄与 dnd-kit transform，避免属性相互覆盖。
