# ascent-override CSS descriptor

原文：[MDN](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/@font-face/ascent-override)；[提取正文](../../raw/sources/SRC-2026-11-11-001/extracted.md)第 183–245 行。

`@font-face` 的 `ascent-override` 覆盖用于行盒布局的基线上方高度。默认 `normal` 使用字体文件的度量，也可指定百分比；可用于使回退字体更接近主字体。MDN 将该能力标为 limited availability，不能假设所有广泛使用的浏览器均支持；最新标准的完整语法也不一定已实现。
