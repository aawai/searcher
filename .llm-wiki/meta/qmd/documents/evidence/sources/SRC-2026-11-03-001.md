# Cross-site request forgery (CSRF)

原文：[MDN CSRF](https://developer.mozilla.org/en-US/docs/Web/Security/Attacks/CSRF)；证据：[提取文本](../../raw/sources/SRC-2026-11-03-001/extracted.md)，第 181–183、237–251、253–269、290–330 行。

## 摘要

CSRF 利用浏览器可能自动携带的用户凭据，诱使服务器执行用户没有发起的状态变更；跨源表单等简单请求可被发出，不能仅靠同源策略防止请求到达。

MDN 介绍不可预测 CSRF token、Fetch Metadata 和要求非简单请求等防线，并将 SameSite Cookie 作为纵深防御。非简单请求方案需要服务端实际拒绝简单请求，并保持严格 CORS 策略；不应把浏览器的响应读取限制等同于服务端请求鉴权。
