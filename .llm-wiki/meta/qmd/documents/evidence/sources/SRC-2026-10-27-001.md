# SQLite Online Backup API

原文：[SQLite Backup API](https://www.sqlite.org/backup.html)；证据：[不可变提取文本](../../raw/sources/SRC-2026-10-27-001/extracted.md)，第 33–83、151–219、294–355 行。

## 摘要

Online Backup API 将源数据库复制到目标数据库，完成后得到一致快照；目标的原有数据库内容会被替换。增量复制不必全程锁住源库，而在读取各批数据时短暂持锁。文档另列 `VACUUM INTO` 和 `sqlite3_rsync` 作为在线数据库复制方式。

API 示例使用 `sqlite3_backup_init`、`sqlite3_backup_step` 和 `sqlite3_backup_finish`；需检查错误，包括锁争用。源库在增量复制间被修改会影响复制进程，具体行为及调用约束应以 API 参考为准。本次收录不代表项目采用此 API 或完成了备份恢复验证。
