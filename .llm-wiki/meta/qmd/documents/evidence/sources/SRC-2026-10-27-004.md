# Registering custom properties in CSS

原文：[MDN — Registering custom properties](https://developer.mozilla.org/en-US/docs/Web/CSS/Guides/Properties_and_values_API/Registering_properties)；证据：[不可变提取文本](../../raw/sources/SRC-2026-10-27-004/extracted.md)，第 221–230、259–290、375–396 行。

## 摘要

`@property` 及 `CSS.registerProperty()` 为变量指定类型、继承行为和初始值。`syntax` 与 `inherits` 必需；当 `syntax` 不是通用 `*` 时，还须提供计算独立的 `initial-value`。注册值在计算阶段验证：不合法值不能假定回退到较早的有效级联声明，实际结果受继承与初始值控制。

注册可使可插值的类型进行平滑插值，而未注册变量通常是离散动画。原文将注册变量插值称为 GPU 卸载；[Motion 渲染管线来源](/sources/SRC-2026-10-05-004.md) 同时指出 CSS 变量变化会触发绘制，即使变量通过 `@property` 动画也不例外。两者讨论的插值计算与整体渲染范围不同，不能据此保证任意动画都只在合成线程执行；须对目标浏览器和属性实测。
