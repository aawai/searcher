# Composable Plugins (Milkdown)

原文：[docs/plugin/composable-plugins.md](https://raw.githubusercontent.com/Milkdown/website/main/docs/plugin/composable-plugins.md)；[提取文本](../../raw/sources/SRC-2026-11-13-007/extracted.md)。

`@milkdown/utils`（新包入口 `@milkdown/kit/utils`）提供可组合工厂以替代手写三阶段插件样板：`$node` / `$mark` 扩展 ProseMirror `NodeSpec` / `MarkSpec`，并内联定义 `parseMarkdown`（Remark AST → ProseMirror）与 `toMarkdown`（ProseMirror → Remark AST）runner；`$inputRule`、`$command` 与 `$useKeymap` 则允许彼此直接引用 `.type()` 或经 `commandsCtx.call(cmd.key)` 复用命令（第 3–85 行）。

注：原文第 16–21 行的 `$node` 示例在无 `ctx` 参数的回调内引用了 `ctx.get(blockquoteAttr.key)`，属文档示例笔误。
