# Message Branching
> _Original: [https://www.assistant-ui.com/docs/guides/branching.md](https://www.assistant-ui.com/docs/guides/branching.md)_

## Summary

本页概述了 `@assistant-ui/react` 中对话分支（Message Branching）的触发条件与 UI/编程导航方式。分支在两种交互下产生：用户编辑已有用户消息并重新提交，或对助手消息执行重新生成（Reload）。

在 UI 层，只需在消息组件内放置 `BranchPickerPrimitive.Root`（常用 `hideWhenSingleBranch`）、`Previous`、`Number`、`Count` 与 `Next`，边界处及生成运行期间（除非 Runtime 支持 `switchBranchDuringRun`）按钮会自动禁用。重新生成由 `ActionBarPrimitive.Reload` 触发，并在 `thread.isRunning` 或 `thread.isDisabled` 时自动禁用。在无头或快捷键场景中，可在消息作用域内通过 `useAui().message.switchToBranch({ branchId })` 编程切换。

## Key Takeaways

- **两种分支来源**：编辑用户消息（`onEdit`）与重新生成助手回复（`onReload` / `ActionBarPrimitive.Reload`）都会产生替代消息分支。
- **内置禁用守卫**：`BranchPickerPrimitive` 在首尾边界和运行中自动禁用，`ActionBarPrimitive.Reload` 在 `thread.isRunning` 或 `thread.isDisabled` 时禁用。
- **编程式切换须在消息作用域内**：`aui.message.switchToBranch({ branchId })` 必须位于 `MessagePrimitive.Root` 等提供 `message` scope 的上下文中调用。
