# 🔴 Observation: UI 视觉品质与设计规范治理全量完成（含 3 项交互深化）

完成了 Searcher 全面 UI 治理及三项深度交互优化：1. Token 解耦：新增 --input-radius: 8px 彻底隔离 pill 偏好对表单 Input/Select 的椭圆污染，搜索框族改绑 --search-radius 保持同心胶囊（999px）；2. 材质底色阻断：dialog-panel 改绑 --surface-solid 并移除 glass 模式下模糊叠加，彻底解决浮窗透字缺陷；3. 实体语言统一：全局清除中英混用 APP 统称为常用网站/快捷方式，扁平化设置与 AI 标题层级；4. 双 Logo 消除与导航激活：首页居中呈现大字标时隐藏角标 s.，/settings 与 /ask 增加激活态指示；5. 移动端 Sheet 自适应高度（height: auto; max-height: 85dvh; min-height: 220px）消除空态大黑底且保证滚动；6. 搜索建议大幅降噪，消除默认引擎全行同名徽标并为书签项保留域名徽章防溢出；7. NoteEditor 无界化重构为 20px 粗体无边界透明大字标题输入流，且正文 Textarea 与预览面板样式/背景/边距 100% 像素级对齐；8. /ask 页面重构消除 96px 外置死区，左右两栏实现 0px 像素级垂直基线对齐并保证发送区不截断；9. 首页常用网站实现数学平衡行算法，10 项自适应排布为 5x2 对称居中网格并补充了单元测试与实机实测验证。161 个测试与生产构建全绿。
