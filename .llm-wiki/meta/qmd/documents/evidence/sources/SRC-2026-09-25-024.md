# Source Code: SearchHome.tsx (Masonry Integration and Drag-and-Drop Drawer)

## Summary

`web/src/app/SearchHome.tsx` 是 [[entities/searcher-项目]]
的前端核心工作台页面。在便签管理抽屉（`ContentSheet`）中，该文件整合了
`useMasonryLayout` 瀑布流驱动与 [[entities/dnd-kit-system]] 拖拽排序能力。

关键工程集成包括：

1. **双层 DOM 架构隔离 Transform**：
   - 外层 `.note-masonry-item`：由 Masonry 驱动
     `position: absolute; width: ${colWidth}px; transform: translate3d(x, y, 0); transition: transform 200ms ease;`；
   - 内层 `SortableDrawerNoteItem`：挂载 dnd-kit `setNodeRef`
     与事件监听；在拖拽期间不叠加自身位移变换，彻底杜绝两个 transform
     属性互相覆盖覆盖导致的拖拽抖动；
2. **`DragOverlay` 视效脱离**：
   - 拖拽激活时由 `<DragOverlay>`
     承载浮动副本，网格原位卡片降透明度（`opacity: 0.35`）占位，骨架不坍塌；
3. **碰撞与排序定位优化**：
   - `DndContext` 采用组合碰撞策略（`pointerWithin` 优先、回退
     `closestCenter`）；
   - `SortableContext` 采用 `strategy={() => null}`；
   - `handleDrawerNotesDragEnd` 结合指针中心 Y 轴与目标卡片中心 Y
     轴判定前后插入点，并受置顶分区区间强制约束（置顶卡片 clamp 在
     `[0, pinnedCount - 1]`，普通卡片 clamp 在
     `[pinnedCount, length - 1]`），杜绝越界导致的排序回弹与回滚。

## Key Takeaways

- **双层解耦避免冲突**：外层管静态坐标与平滑动画，内层管拖拽事件与悬停指示；
- **Null Strategy 消除网格扭曲**：彻底放弃 `rectSortingStrategy`，由 Masonry
  统筹真实几何坐标；
- **强约束排序分区**：拖拽排序严格遵从置顶业务模型。
