# Retry-After header (MDN)

原文：[MDN Retry-After](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Headers/Retry-After)；[提取文本](../../raw/sources/SRC-2026-11-08-003/extracted.md)，正文第 186–247 行，其余为站点导航。

## 摘要

- `Retry-After` 是响应头，告诉 user agent 等多久再发后续请求。用于三种场景：`503`（预计不可用多久）、`429 Too Many Requests`（多久后可再请求）、重定向（如 `301`，重定向前至少等待多久）（第 188–193 行）。
- 两种语法：`<http-date>`，或 `<delay-seconds>`（非负十进制整数，从收到响应起计算）（第 213–225 行）。
- 客户端与服务端的支持仍不一致；部分爬虫（如 Googlebot）会遵守（第 231–233 行）。
- 规范来源：RFC 9110 HTTP Semantics §field.retry-after（第 247 行）。
