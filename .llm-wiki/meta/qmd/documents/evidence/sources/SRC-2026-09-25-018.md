# Announcing Hono on JSR

> _Original:
> [https://deno.com/blog/hono-on-jsr](https://deno.com/blog/hono-on-jsr)_

## Summary

Deno 宣布轻量级 Web 标准路由框架 [[entities/hono-framework]] 正式发布到
JavaScript Registry (JSR)。Hono 凭借其极速路由匹配、超轻量体积、原生 TypeScript
类型支持以及完备的中间件生态，成为现代边缘计算与单进程全栈服务端开发的行业标杆。

通过 JSR，开发者可以通过 `jsr:@hono/hono` 直接引入模块，在
[[entities/deno-runtime]] 环境下享受零配置的完整类型提示与智能补全。框架直接接入
`Deno.serve(app.fetch)` 原生 HTTP 服务器，省去了传统 Node.js
生态中繁重的适配层与 polyfill。

## Key Takeaways

- **Web 标准优先**：Hono 原生基于 `Request`、`Response` 与
  `Fetch API`，天然跨平台兼容 Deno、Node、Cloudflare Workers 等运行时；
- **原生 Deno.serve 结合**：只需将 `app.fetch` 传给 `Deno.serve` 即可启动高性能
  HTTP 服务；
- **类型安全的路由与中间件**：提供强大的上下文上下文类型安全推断，中间件修改的内容可在下游
  handler 获得强类型感知。
