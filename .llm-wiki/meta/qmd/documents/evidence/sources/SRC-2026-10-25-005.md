# dnd-kit Accessibility Guide
> _Original: [https://docs.dndkit.com/guides/accessibility](https://docs.dndkit.com/guides/accessibility)_

## Summary

dnd-kit 关于可访问拖放的官方指南（legacy 文档版本，对应 `@dnd-kit/core` 6.x）。三根支柱：**键盘支持**、**屏幕阅读器说明（instructions）**、**live region 播报（announcements）**。

键盘：`KeyboardSensor` 默认启用；激活元素必须可聚焦（`useDraggable` 默认 `tabindex="0"`）；Space / Enter 拾起与放下，方向键移动，Escape 取消（建议所有 sensor 都支持 Escape 取消）。方向键默认每次移动 25px，应通过 `coordinateGetter`（`getNextCoordinates`）按应用语义定制；`useSortable` 自带 `sortableKeyboardCoordinates`，按方向跳到下一个可排序项。

语义：`useDraggable` 默认给激活元素 `role="button"`、`aria-roledescription="draggable"`、`aria-describedby="DndContext-[uniqueId]"`（指向离屏说明文本）。`DndContext` 渲染离屏说明与 live region，可分别用 `screenReaderInstructions` 与 `announcements`（`onDragStart/Over/End/Cancel`）定制；**只内置英文**，多语言应用必须自行翻译。播报列表位置时用 1 起的 position 而非 0 起的 index。

## Key Takeaways

- 默认播报以 `active.id` 拼接（如 "Picked up draggable item {id}."）；id 是 UUID 时对用户无意义，应换为可读标题。
- 定制 `getNextCoordinates` 是把"像素步进"变为"按网格单元 / 列表位置步进"的官方扩展点；另一种做法是不启用 `KeyboardSensor`、在元素上自行处理方向键并维护独立 live region。
- Searcher 现状（核对 `@dnd-kit/core@6.3.1` 与源码）：
  - `WebAppLauncher.tsx`（首页应用网格）启用 `PointerSensor` + `KeyboardSensor` 且 `coordinateGetter: sortableKeyboardCoordinates`。
  - `HomeNotes.tsx`（首页笔记吸附网格）只启用 `PointerSensor`；键盘移动由 `role="group"`、`tabIndex=0` 的卡片 `onKeyDown` 自行实现（方向键按单元移动、Enter/Space 确认、Escape 取消），用自有 `role="status"` live region 播报中文位置；`aria-roledescription="可移动的首页笔记"`。
  - 两处 `DndContext` 均未传 `accessibility` prop，因此库的英文默认说明与播报仍会渲染（[INFERENCE] 指针拖动首页笔记时，库 live region 可能播报 "Picked up draggable item <uuid>."，与自定义中文播报叠加；未在屏幕阅读器上实测）。
