# Cache
> _Original: [https://developer.mozilla.org/en-US/docs/Web/API/Cache](https://developer.mozilla.org/en-US/docs/Web/API/Cache)_

## 摘要

Cache API 保存由应用管理的 `Request` / `Response` 对，可在窗口和 Worker 中使用，不要求 Service Worker。条目不会自动按 HTTP 缓存头刷新或过期；应用负责版本、更新和删除，浏览器仍可按存储策略清理整个 origin 的数据。

匹配请求时会考虑已存响应的 `Vary`；这个匹配规则不等于 Cache API 遵循 `Cache-Control`。因此 `no-store` 不能阻止脚本显式写入 Cache Storage。
