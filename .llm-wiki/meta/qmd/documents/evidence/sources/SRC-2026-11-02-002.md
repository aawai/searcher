# AbortController

原文：[MDN](https://developer.mozilla.org/en-US/docs/Web/API/AbortController)；证据：[提取文本](../../raw/sources/SRC-2026-11-02-002/extracted.md) 第 184–245 行（前 183 行为站点导航，未使用）。

## 摘要

`AbortController` 是一个控制器对象，用于按需中止一个或多个 Web 请求（第 197 行）。它通过只读属性 `signal` 返回的 `AbortSignal` 与异步操作通信（第 199、216–219 行），唯一的实例方法 `abort()` 可中止 fetch 请求、响应体的消费以及 streams（第 221–224 行）。页面标注 Baseline Widely available，自 2019 年 3 月起可用，Web Workers 中同样可用（第 186–195 行）。

页面本身没有示例，示例指向 `AbortSignal` 页（第 226–230 行）。因此 `abort()` 的 reason、已中止信号再次中止的幂等性、`AbortSignal.timeout()` 等细节**不在本来源内**，需另行收录 `AbortSignal` 页后才能断言。

## 关键要点

- 一个 controller 一个 signal；一个 signal 可传给多个异步操作，`abort()` 一次性取消全部。
- 取消对象包括 fetch、响应体读取和 streams，不止“请求发出前”的阶段。
- 本页不规定被中止的 promise 以什么错误 reject，该行为需读 `AbortSignal` / fetch 规范。
