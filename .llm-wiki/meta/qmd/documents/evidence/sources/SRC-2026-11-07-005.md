# React Router createBrowserRouter

原文：[reactrouter.com · createBrowserRouter](https://reactrouter.com/api/data-routers/createBrowserRouter)（由源码 JSDoc 生成，参考链接指向 API v8）；[提取文本](../../raw/sources/SRC-2026-11-07-005/extracted.md)。

## 摘要

`createBrowserRouter(routes, opts?)` 创建基于 `history.pushState`/`replaceState` 的 data router，交给 `<RouterProvider>`（第 25–40、530–532 行）。

- **生命周期约束**：“Data Routers should not be held in React state”，应在 React 树外创建一次（第 29–30 行）。2026-11-07 用 `curl` 检查 [v7 API 参考](https://api.reactrouter.com/v7/functions/react-router.createBrowserRouter.html) 也含同一句，因此不是 v8 新增要求。
- `opts`：`basename`、`dataStrategy`（覆盖默认并行 loader）、`future`、`getContext`（每次导航/fetcher 生成新 context）、`hydrationData`、`instrumentations`、`patchRoutesOnNavigation`、`window` 等（第 48–528 行）。
- 默认要求一次性提供完整路由树以便同步匹配；`route.lazy`（v6.9.0 起）延迟加载实现部分，`patchRoutesOnNavigation` 延迟路由定义本身（第 232–247 行）。
