# ⭐ Observation: Issue 338 C3 AI 窗口与最终验收结果

AI 问答已是 data-window-id=ai 的窗口：DesktopCoordinator 持有后台局部 navigate（仅 AI 的 replace 在非活动时只更新窗口记录，askEntries 记录历史条目到会话 URL 的映射，POP 回到该条目时 replace 对齐）；AskPage 的 useNavigationGuard 只拦截替换会话的导航与退出登录（DESTRUCTIVE_ACTION_KEY），关闭窗口走 registerCloseGuard，后果文案与规则在 web/src/features/ask/leave-loss.ts。窗口列表通过 setBusy 标注正在生成。发现并修复 WindowFrame 的缺陷：用键盘 Enter 选中菜单“移动 / 调整”时，同一次 keydown 会冒泡到窗口的 Enter 提交处理并立即结束操作，现以 operation.startedAt 与 event.timeStamp 比较忽略。壁纸派生画布与 data-ask 规则、Dock 实色回退、search-focus 模块已删除（--canvas-derived 令牌仍保留为设计能力）。AI 窗口内线性渐隐必须使用 --surface-l3 而非 --background，否则深色窗口出现黑带。验收：deno task test 866 通过、check:ui 0 违规、check:e2e 75 文件；workspace、routing、supplemental、bundle、home-notes、wallpaper、documents-core 全部通过；documents 四个分页分片未重跑（未触及编辑器）。web/e2e/ai-window.test.ts 覆盖保活、关闭 / 切换 / 退出保护、临时会话删除、5 分钟租约续期（Playwright clock）、后台命名与历史对齐、键盘移动 / 最小化 / 恢复 / 关闭；390/768/1440 × light/dark 实页截图已逐张审阅。
