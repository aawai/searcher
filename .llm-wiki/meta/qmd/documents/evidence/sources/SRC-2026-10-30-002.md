# MDN CSS container queries

原文：[MDN CSS container queries](https://developer.mozilla.org/en-US/docs/Web/CSS/CSS_containment/Container_queries)；证据：[不可变提取文本](../../raw/sources/SRC-2026-10-30-002/extracted.md)，第 184–418 行。前 183 行为站点导航，第 424 行之后为页脚与站内链接。

## 摘要

容器查询按容器属性而非视口为元素应用样式；可查询的属性包括容器名、尺寸、样式、scroll-state 以及 anchor-positioned 状态。尺寸查询要求先用 `container-type` 声明包含上下文：`size` 同时查询 inline 与 block 维度，并施加 layout、style、size containment；`inline-size` 只查询 inline 维度，施加 inline-size containment；`normal` 为默认值，不是尺寸查询容器，但仍可作为 name-only 和样式查询的容器。`@container` 命中最近的、满足条件的祖先容器；`container-name` 可指定目标，`container: name / type` 为简写。

仅有 `container-name` 时可写 name-only 查询（`@container my-container { … }`），按“是否位于具名容器内”选样式，无尺寸条件。`cqw`、`cqh`、`cqi`、`cqb`、`cqmin`、`cqmax` 单位相对查询容器；没有合格容器时回落到对应轴的小视口单位（`sv*`）。不支持容器查询的浏览器，页面给出的回退是 grid/flex 加媒体查询。
