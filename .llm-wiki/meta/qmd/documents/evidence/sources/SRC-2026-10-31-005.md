# MDN `overscroll-behavior` CSS property

原文：[MDN overscroll-behavior](https://developer.mozilla.org/en-US/docs/Web/CSS/overscroll-behavior)；证据：[不可变提取文本](../../raw/sources/SRC-2026-10-31-005/extracted.md)，第 184–361 行（前 183 行为站点导航）。

## 摘要

`overscroll-behavior` 控制滚动到滚动容器边缘后的行为。MDN 标注 **Limited availability**（不是 Baseline，部分主流浏览器不支持；具体浏览器兼容表在提取文本中未渲染，需启用 JavaScript 才可见，本页未核实各浏览器版本）。它是 `overscroll-behavior-x` / `-y` 的简写，接受一或两个值，两个值依次为 x、y（第 287–320 行）。

值（第 322–332 行）：`auto`（默认，允许滚动链到外层）；`chain`（允许链出，但禁止回弹效果）；`contain`（阻止链出，回弹仍可能发生）；`none`（阻止链出并禁止回弹）。动机是去除不想要的**滚动链**（对话框滚到边界后底层页面继续滚动）以及移动端的回弹/下拉刷新（第 336–338 行）。

约束：只对滚动容器生效，`<iframe>` 不是滚动容器，须在其文档的 `<html>` 与 `<body>` 上同时设置（第 340 行）。无可滚动溢出的容器（如 `overflow: hidden`）始终视为处于滚动边界，因此给它设 `contain` 或 `none` 也能阻止链向祖先，可用来在对话框或浮层打开时阻止背景滚动（第 342 行）。应用于非替换块级与行内块元素，不继承，动画类型 discrete（第 346–352 行）。
