# ⭐ Observation: Issue 157 拖拽边界积分与碰撞接触状态

Searcher #157 的真实 Chromium M0 表明普通触边时 capture 和 active 保持，但初始锚点累计位移在 clamp 后造成反向死区。WindowChrome.tsx 改为 4px 激活第一帧保留总位移，此后 currentFrame + 相邻 pointer delta，每个处理事件推进锚点。碰撞只在请求越界时触发；dx/dy 为 0 的沿墙移动必须保留该轴接触状态，否则下一次施力会错误重复脉冲。新增 E2E 捕获了沿墙双脉冲红测，修复后沿墙仍 1 次、反向退出再碰撞为 2 次。实现 commit 59ec119，PR https://github.com/aawai/searcher/pull/162；证据分支 evidence/issue-157。
