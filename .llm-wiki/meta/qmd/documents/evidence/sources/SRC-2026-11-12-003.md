# File Locking And Concurrency In SQLite Version 3

原文：[SQLite Locking](https://www.sqlite.org/lockingv3.html)；[提取文本](../../raw/sources/SRC-2026-11-12-003/extracted.md)。

本参考仅描述 rollback 模式，不描述 WAL 锁（第 13–24 行）。SHARED 允许多个读取者；RESERVED 仅允许一个并与 SHARED 共存；PENDING 阻止新 SHARED，而 EXCLUSIVE 与其他锁互斥（第 70–88 行）。

读取前 SQLite 检查 hot journal，必要时取得锁并回滚；锁不可取得时可能返回 `SQLITE_BUSY`（第 118–182 行）。这与 [应用层队列](/concepts/database-queue-serialization.md)承担的共享连接异步操作串行化不是同一边界；另见 [SQLite Isolation and Connection Boundaries](/concepts/sqlite-isolation-and-connection-boundaries.md)。此处未核验项目的日志模式或部署环境。
