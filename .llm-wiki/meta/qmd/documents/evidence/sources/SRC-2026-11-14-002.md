# Message Conversion
> _Original: [https://www.assistant-ui.com/docs/api-reference/external-store/message-conversion.md](https://www.assistant-ui.com/docs/api-reference/external-store/message-conversion.md)_

## Summary

本页记录 `@assistant-ui/react` 外部存储消息转换相关的公开与实验性 API，用于将宿主自定义消息类型 `T` 映射为 assistant-ui 内部的 `ThreadMessage`，并在 UI 组件层按需取回原始消息对象。

核心稳定 API 包括 `getExternalStoreMessages(input)`（从 `ThreadMessage`、消息列表或单个内容 part 反查对应的宿主原始消息数组，因为多条相邻助手消息可能被合并显示）以及 `useExternalMessageConverter`（接收 `callback`、`messages`、`isRunning`、`joinStrategy`、`metadata` 与 `getMetadataKey`，在元数据高频变化时按单条消息粒度维持转换结果缓存）。

页面同时列出了实验性工具函数，包括 `bindExternalStoreMessage`（将原始消息绑定到手动构造的 `ThreadMessage` 或 part，已绑定时为 no-op）、`unstable_createExternalMessageConversionCache`（2026-09-15 新增，按源消息引用身份缓存转换结果，要求 `callback` 与 `metadata` 引用稳定）以及 `unstable_convertExternalMessages` / `unstable_createMessageConverter`。

## Key Takeaways

- **`getExternalStoreMessages` 返回数组**：即使对应单个 UI `ThreadMessage`，由于合并策略（`concat-content`）可能把多条相邻助手/工具消息合并展示，反查结果始终为 `T[]`。
- **`getMetadataKey` 避免全量重算**：当 `metadata`（如 `toolStatuses`、`messageTiming`）频繁变更时，返回每条消息实际依赖的稳定原语/引用可避免无关消息重新转换。
- **转换缓存要求引用稳定**：使用 `unstable_createExternalMessageConversionCache` 或 `useExternalMessageConverter` 时，`callback` 与 `metadata` 对象引用变动会触发缓存重建。
