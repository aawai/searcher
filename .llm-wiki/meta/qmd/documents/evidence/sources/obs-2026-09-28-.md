# ⭐ Observation: 常用网站弹出窗口正方形网格与文件夹几何规范

### 常用网站与应用抽屉网格设计矫正规范

1. 统一正方形网格系统：网格基础 Cell 宽高严格 1:1（`--launcher-col-w` 等于 `--launcher-row-h`，默认 112×112px，紧凑 100×100px，大号 126×126px），`--launcher-gap-x` 等于 `--launcher-gap-y`（8px/8px/10px）。无论是否存在应用名称，单元格永远是正方形。
2. 小文件夹等大原则：小文件夹卡片 surface 的尺寸（56×56px）与应用图标 glyph 完全相同，圆角一致。
3. 大文件夹 2×2 空间与正方形原则：上下两排 4 个图标占用的几何空间（宽 2*col_w+gap，高 2*row_h+gap）天然严格相等，恰好为一个大文件夹正方形卡片（232×232px）。
4. 大文件夹名称采用底部半透明胶囊浮层（overlay），不挤占外部高度。
5. 尺寸独立性原则：变换不同文件夹大小时，普通图标的正方形尺寸完全不跟随变动，彻底删除 `.launcher-grid--folders` 及任何拉大图标间距的补丁。
6. 居中对称原则：弹出窗口内网格采用 `justify-content: center; margin: 0 auto;`，一行排满或不满时左右留白严格对称。
7. 移出文件夹追加至末尾：无论是单项移出还是删除文件夹批量移出，均分配 `max(sortOrder) + 1` 默认排至末尾。
8. 补充修复：`EngineIcon` default 分支增加 null/undefined 安全防护，确保访客态首屏渲染永不崩溃。
