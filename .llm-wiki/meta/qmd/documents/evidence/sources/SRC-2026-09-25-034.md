# Announcing Hono on JSR

> _Original:
> [https://deno.com/blog/hono-on-jsr](https://deno.com/blog/hono-on-jsr)_

## Summary

Deno 官方博客宣布现代 Web 路由框架 Hono 正式上架 JSR（JavaScript
Registry）。Hono 是一款轻量、高性能、符合 Web 标准（Fetch API, Request,
Response）的跨运行时服务端框架，具备一流的 TypeScript 原生支持。

文章详细介绍了在 Deno 生态中通过 `deno add @hono/hono`（生成 `jsr:@hono/hono`
依赖导入）直接构建和部署高性能 HTTP 服务的开发体验。依托 JSR 原生 TypeScript
发布机制，开发者可免除转译构建流程，直接在编辑器中获取完整的内联类型定义与文档支持。配合
`Deno.serve(app.fetch)`，Hono 应用可以在单进程中以极低开销处理高并发请求。

## Key Takeaways

- **Web 标准原生契约**：Hono 基于现代 Web 平台原生标准（`Request` / `Response` /
  `Headers`）构建，与 Deno 内置的 Fetch API 原生兼容，消除 Node.js HTTP
  抽象层的适配开销。
- **JSR 无构建发布集成**：通过 `jsr:@hono/hono` 直接引入原生 TypeScript
  源代码，杜绝了 npm 时代 `.d.ts` 与实现版本不同步的类型断层问题。
- **极简服务组装**：通过 `Deno.serve(app.fetch)` 即可启动零开销单进程 HTTP
  服务，适合构建单进程、同源部署的现代化搜索主页与微服务。
