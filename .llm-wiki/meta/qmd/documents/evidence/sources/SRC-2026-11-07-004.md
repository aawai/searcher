# Cryptographic Storage Cheat Sheet (OWASP)

原文：[OWASP Cryptographic Storage Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/Cryptographic_Storage_Cheat_Sheet.html)；[提取文本](../../raw/sources/SRC-2026-11-07-004/extracted.md)，正文第 229–432 行。

## 摘要

面向静态数据保护。口令不可逆向加密，应使用口令哈希（第 235 行）。加密层次（应用/数据库/文件系统/硬件）按威胁模型选择；最好的保护是不存储敏感信息（第 245–258 行）。

- **算法**：对称加密用 AES，密钥至少 128 位、理想 256 位（第 262 行）；优先认证模式 GCM/CCM（第 296 行）；IV 等由库自动处理（第 294 行）。
- **随机数**：密钥、IV、session ID、CSRF token 必须来自 CSPRNG（第 308–314 行）。
- **纵深防御**：加密失效时仍需访问控制保护（第 339 行）。
- **密钥轮换**：在泄露、cryptoperiod 到期、接近模式使用上限（含 AES-GCM 的 IV 唯一性）或算法被攻破时轮换；旧数据或重新加密，或为每条记录标记 key ID 并保留多把密钥；轮换代码须**事先**就位（第 360–377 行）。
- **密钥存储**：优先 HSM/KMS/Vault；退而求其次时不硬编码、不入版本库、限制配置文件权限，并**避免放在环境变量**（可经 `/proc/self/environ` 等泄露）（第 383–404 行）。
- **密钥与数据分离**：如数据在数据库，密钥放文件系统；DEK/KEK 信封加密，KEK 单独存放（第 408–427 行）。
