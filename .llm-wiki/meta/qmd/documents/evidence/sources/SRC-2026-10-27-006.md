# Trusted Types API

原文：[MDN — Trusted Types API](https://developer.mozilla.org/en-US/docs/Web/API/Trusted_Types_API)；证据：[不可变提取文本](../../raw/sources/SRC-2026-10-27-006/extracted.md)，第 203–226、268–290、339–344、386–470 行。

## 摘要

Trusted Types 区分 HTML、脚本和脚本 URL 注入 sink；应用定义策略及其转换函数，API 本身不附带 sanitizer。仅创建策略不会阻止未处理的字符串进入 sink。

在支持该机制的浏览器中，CSP `require-trusted-types-for` 可强制受保护的 sink 使用可信类型；若配置了 default policy，普通字符串先经过该策略，未配置或转换失败才抛错。`trusted-types` 指令限制允许创建的策略名称。tinyfill 能保持显式调用净化函数的代码路径，但不能给不支持的浏览器增加强制检查。
