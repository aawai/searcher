# Cache-Control header

原文：[MDN Cache-Control](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Headers/Cache-Control)。证据：[提取文本](../../raw/sources/SRC-2026-11-04-002/extracted.md)，第 260–267、328–345、372–398、602–627 行。

## 摘要

响应 `no-cache` 允许保存，但通常须在复用前验证；历史导航或 bfcache 恢复不保证重新验证。`no-store` 指示私有及共享 HTTP 缓存均不保存响应；`private` 允许私有缓存保存但限制共享缓存。个性化内容若被共享缓存复用，可能泄露用户信息。

`public` 可解除带 Authorization 请求的共享缓存限制；使用 Cookie 管理会话时不能假设共享缓存天然禁用。此文档不是对 Searcher 部署缓存头的实测。
