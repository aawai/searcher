# Tailwind CSS v4: CSS-First Architecture, Native Variables and Viewport Adaptations
> _Original: [https://tailwindcss.com/blog/tailwindcss-v4](https://tailwindcss.com/blog/tailwindcss-v4)_

## Summary

Tailwind CSS v4.0 是该样式框架自发布以来的底层全面重写，全面拥抱当代 Web 标准与浏览器原生能力。v4.0 彻底废弃了传统的 JavaScript 配置文件（`tailwind.config.js`），转为纯正的 **CSS-First** 架构。开发者只需在全局主样式表中声明 `@import "tailwindcss";` 即可完成零配置开箱即用，所有主题令牌、扩展规则和自定义指令均通过标准 CSS 指令（如 `@theme`、`@utility`、`@custom-variant`）进行声明。

借助全新的 Rust 编译核心与 Lightning CSS 深度集成，v4.0 实现了全量构建提速 3.5 到 5 倍、增量重构提速超 100 倍至微秒级的极致性能。在标准支持方面，Tailwind CSS v4 原生利用了 CSS Cascade Layers（`@layer`）、`@property` 类型化自定义属性以及 `color-mix()` 颜色空间插值；更重要的是，原生支持全套现代动态视口高度/宽度单位（`dvh`、`dvw`、`svh`、`lvh`），解决了移动端浏览器工具栏展开/折叠时 100vh 导致的布局裁切与溢出顽疾。

## Key Takeaways

- **CSS-First 配置范式**：废弃 JS 配置文件，所有主题 Design Token 通过 `@theme` 块定义，并在构建时自动映射为原生 CSS 变量（如 `var(--color-*)`、`var(--spacing-*)`），无需 JS 桥接函数即可被任意 CSS 和内联样式直接消费。
- **现代化动态视口适配**：内置 `h-dvh`（Dynamic Viewport Height）、`h-svh`（Small Viewport Height）等工具类，确保移动端工作区面板和抽屉在地址栏收起与弹出时自适应屏幕实际可用面积，避免硬编码 100vh 带来的遮挡。
- **原生级联层与属性插值**：深度集成 `@layer theme, base, components, utilities` 与 `@property`，解决长期存在的样式优先级竞争问题，同时借助 `color-mix(in oklab, ...)` 带来广色域与更精确的透明度计算。
- **First-party Vite 插件集成**：提供专用 `@tailwindcss/vite` 插件，无缝嵌入基于 Vite 的现代全栈构建管道，消除 PostCSS 繁复配置层。
