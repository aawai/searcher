# ProseMirror Guide

原文：[ProseMirror Guide](https://prosemirror.net/docs/guide/)；[提取文本](../../raw/sources/SRC-2026-11-08-007/extracted.md)，共 1930 行。之所以收录这份指南：Searcher 编辑器使用的 Milkdown 构建在 ProseMirror 之上，而 Milkdown 文档页没能抓到正文（见 `discard` 事件）。

## 摘要

- **Transaction 是唯一的更新路径**：每次修改都生成一个 transaction，apply 后得到新 state，再交给 view（第 111–145 行）。`dispatchTransaction` prop 可以拦截所有 transaction（第 124–140 行）。
- **单次计算**：`state.apply(tr)` 根据旧 state 与 transaction 一次算出 state 的每个组成部分（第 1124–1128 行）。
- **插件状态不可变**：plugin state 的 `apply` 必须返回新值，不能修改旧值，其他代码也不应修改它（第 1231–1235 行）。
- **Transaction metadata**：插件可以给 transaction 打标记。history 用标记识别 undo 产生的 transaction（第 1237–1243 行）。元数据键推荐用插件对象，避免冲突；内置的字符串键包括 `"addToHistory"`（设为 `false` 时该 transaction 不可撤销）和 `"paste"`（第 1266–1271 行）。
- **数据流**：DOM event → transaction → 新 state → view，形成单向循环。可以通过 `dispatchTransaction` 接入应用自己的 store（第 1322–1386 行）。
- 其余章节（schema、steps/mapping/rebasing、decorations、node views、collab）本次未用于对照。
