# ⭐ Observation: Issue 369 D2 改为细边框并新增 D8 分组表单

用户看浅填充无边框示意图后觉得不好看。原因：灰块读作禁用/骨架、与次要按钮 --surface-soft 同色、灰色面积大于原描边、聚焦跳变、与原生材质方向不符；重的根因是 #86868B 深灰边框而非有边框。对照 A 浅填充/B 细边框/C 白底软阴影/D 分组行内四方案（/tmp/searcher-ui/field-options.png）后用户选：多字段表单（AppForm、AuthPage、AccountPage 改密、AdminPage 建用户、DocumentPaperSettingsDialog）改为 SettingsRow 分组行（D8，新任务 T15，错误放行内第二行，长字段用 settings-row--vertical，对话框内容区用 --surface-grouped-canvas）；其余独立字段用 B 细边框（--field-border 亮 rgb(0 0 0/.13) 暗 rgb(255 255 255/.14)，hover .24/.26，聚焦 border+1px box-shadow 合计 2px）；搜索/筛选框保留 --surface-soft 填充。T6 分节无容器改为分组列表。#369 标题与交付拆分 PR-1..PR-5 已更新。
