# MDN：PWA Caching

原文：https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Caching

## 摘要

PWA 缓存策略在离线能力、响应速度和新鲜度之间取舍，应按资源分别制定。Cache API 持久保存 Request/Response 对，页面主线程和 Service Worker 都能使用；它不以用户安装 PWA 为前提。

预缓存适合某版本确定需要的静态 UI；cache-first 命中时不主动更新，stale-while-revalidate 先返回旧值再刷新，network-first 尝试网络失败后回退缓存。对不允许过期数据的请求，应采用 network-only，不能把 network-first 当作不落盘。

## 关键约束

- 指南的 cache-first 示例只缓存明确列出的资源，其余请求走网络；示例中的 URL 后缀过滤不是通用安全规则。
- 缓存可能被用户清除或因配额被浏览器驱逐；预缓存成功不意味着资源永久存在。
- `install` 的 waitUntil 可让预缓存失败阻止安装；`activate` 是清理旧版本缓存的常用阶段。
- Service Worker 安装和用户安装 PWA 是不同事件。
