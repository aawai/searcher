# ⭐ Observation: UI/UX 精致化与设计系统收敛落地

补齐 Switch、RadioGroup、Slider、Separator、Card 5套 shadcn UI
标准原语；SettingsPage 拆分为主题、主页、壁纸 3 大 Section 并移除巨型白色 Card
容器；顶部 Header 收敛为 Avatar DropdownMenu（44px 触控区）；Web App 抽屉移除
40/65/90% 按钮重构为单键全屏切换并收敛次级工具到更多菜单；AI Provider 解耦为
Dialog 模态框并提供密钥显隐切换与行内校验；添加 Web App 弹窗重构为 4
档图标来源选项卡（自动抓取、上传图片、网络链接、AI
生成）、单选打开方式与首页固定开关；全站满足 44x44px 交互热区、键盘
focus-visible 与触屏 hover:none 兜底。
