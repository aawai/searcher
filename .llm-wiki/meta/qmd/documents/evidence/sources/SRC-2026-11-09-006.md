# `color-scheme` CSS property (MDN)

原文：[developer.mozilla.org/en-US/docs/Web/CSS/color-scheme](https://developer.mozilla.org/en-US/docs/Web/CSS/color-scheme)；[提取文本](../../raw/sources/SRC-2026-11-09-006/extracted.md)，正文第 185–379 行，其余为站点导航。

## 摘要

- 声明元素可用的配色方案。UA 据此调整画布底色、滚动条与表单控件默认色、拼写下划线等 UI chrome；其余元素由作者通过 `prefers-color-scheme` 处理（第 196–205 行）。
- 取值 `normal`、`light`、`dark`、`light dark`、`only light`。`only` 禁止 UA 覆盖，例如关闭 Chrome Auto Dark Theme（第 245–280 行）。
- 可继承，动画类型 discrete（第 282–290 行）。
- 建议在 `<head>` 中、任何 CSS 之前放 `<meta name="color-scheme">`，以避免加载时的闪烁（第 332 行）。
- 也可用 `light-dark()` 按方案取色（第 360–373 行）。
