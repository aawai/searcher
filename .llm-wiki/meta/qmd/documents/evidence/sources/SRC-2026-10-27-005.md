# Cross-site scripting (XSS)

原文：[MDN — Cross-site scripting](https://developer.mozilla.org/en-US/docs/Web/Security/Attacks/XSS)；证据：[不可变提取文本](../../raw/sources/SRC-2026-10-27-005/extracted.md)，第 337–342、386–439、464–529 行。

## 摘要

将不可信输入当文本呈现时，应按输出上下文进行编码；需要当 HTML 呈现时，应使用可信的净化实现。HTML、属性、JavaScript 与 CSS 上下文的防护规则不同，不能将某一种 HTML 编码视为所有上下文的保护。

MDN 指出 React `dangerouslySetInnerHTML` 绕过常规输出编码，开发者负责净化；Trusted Types 可帮助约束 DOM 注入 sink，但 API 不提供净化函数。严格 CSP 是后备防御，不替代正确编码或净化。本页描述一般机制，未审计项目中的 Markdown 渲染或 CSP。
