# ⭐ Observation: 外观首帧闪烁经 PR 392 消除并合并 main

#383 遗留的首帧闪烁（先按跟随系统渲染、约 120ms 后切到所存主题）经 PR https://github.com/aawai/searcher/pull/392 修复并合并 main（merge 5346839），CI 17 项通过。设计：每个 owner 在 localStorage 同步保存首帧字段（theme/accent/shape/glassIntensity/tabIcon，key first-frame:appearance:<owner>）与最近确认的 owner 指针（first-frame:owner）；web/vite-first-frame.ts 用 rolldown 把 web/src/app/first-frame-boot.ts 打成 IIFE 内联到 <head> 末尾（样式表后、首绘前），AppState 初始状态与 owner store seed 取自快照，store onChange 回写；owner 指针仅在确定的会话结果写入，连接错误不覆盖；hydrate 在 IndexedDB 无缓存时保留 seed。壁纸不进 localStorage（本地壁纸可达 5MB）。取舍：会话在别处失效时下次载入先显示上个账号的首帧字段。E2E 在 high-contrast.test.ts（延迟 /api/auth/me 600ms，记录 html 主题变更）。
