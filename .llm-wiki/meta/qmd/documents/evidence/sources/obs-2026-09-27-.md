# ⭐ Observation: 便签多版本历史展开文字重叠根因与修复

便签存在多个版本时点击「版本历史」按钮出现文字重叠。经真实浏览器测量，根因是 .note-editor (web/src/styles/global.css:1008) 设置了固定 height: 100% 的 flex column 布局，子元素 Tabs 设置了 flex-1 与 min-h-0。当历史版本卡片（约 400px+）作为兄弟节点插入后，Tabs 容器被 flex 压缩至约 2.9px，但其内部 TabsContent / Textarea 有 min-h-[300px]，导致文本向下溢出并在相同垂直坐标（304px~604px）与版本历史卡片重叠。修复方案：将 .note-editor 的 height: 100% 改为 min-height: 100%，让编辑区自适应撑开并由外层 .sheet-content 的 overflow: auto 接管滚动；同时给 .note-versions 添加 flex-shrink: 0 防止被挤压。
