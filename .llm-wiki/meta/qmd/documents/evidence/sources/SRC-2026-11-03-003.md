# SQLite Online Backup API reference

原文：[SQLite C API](https://sqlite.org/c3ref/backup_finish.html)；证据：[提取文本](../../raw/sources/SRC-2026-11-03-003/extracted.md)，第 41–90 行。

## 摘要

每个成功的 `sqlite3_backup_init` 都必须对应一次 `sqlite3_backup_finish`；源和目标必须为不同连接。`step` 返回 `SQLITE_DONE` 才表示复制完成；提前 finish 会回滚目标上的活动写事务，而 finish 返回 `SQLITE_OK` 本身不证明复制已完成。

`SQLITE_BUSY` 与 `SQLITE_LOCKED` 可稍后重试。备份期间目标连接不得被其他 API 使用，源库仅在每次读取步骤期间加读锁。进度计数只在 step 后更新，不能假设持续实时。本资料描述 SQLite C API，不能推断项目采用该 API 或已验证恢复流程。
