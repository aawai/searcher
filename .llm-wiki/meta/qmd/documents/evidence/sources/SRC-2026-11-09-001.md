# `forced-colors` CSS media feature (MDN)

原文：[developer.mozilla.org/en-US/docs/Web/CSS/@media/forced-colors](https://developer.mozilla.org/en-US/docs/Web/CSS/@media/forced-colors)；[提取文本](../../raw/sources/SRC-2026-11-09-001/extracted.md)，正文第 183–309 行，其余为站点导航。

## 摘要

- 取值 `none` / `active`。`active` 时浏览器通过 system color 关键字提供调色板，并按 `Canvas` 的明度给出 `prefers-color-scheme` 的值（第 205–215 行）。
- 被强制的属性：`color`、`background-color`、`text-decoration-color`、`text-emphasis-color`、`border-color`、`outline-color`、`column-rule-color`、`-webkit-tap-highlight-color`、SVG `fill`/`stroke`。这些值在绘制时强制，不参与层叠（第 219–234 行）。
- 特殊处理：`box-shadow`、`text-shadow` 变为 `none`；非 url 的 `background-image` 变为 `none`；`color-scheme` 变为 `light dark`；`scrollbar-color` 变为 `auto`（第 236–242 行）。
- 系统色按**原生元素语义**选择，不看 ARIA role：`div[role=button]` 不会得到 `ButtonText`（第 246–248 行）。文字后会绘制 backplate（第 250 行）。
- 作者显式写 system color 时，用作者值替代强制值（第 258 行）。
- 不应借此做一套独立设计，只做小范围修补，例如阴影被去掉后补边框（第 262–266、277–305 行）。
