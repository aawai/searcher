# Using HTTP cookies

原文：[MDN Using HTTP cookies](https://developer.mozilla.org/en-US/docs/Web/HTTP/Guides/Cookies)；[提取文本](../../raw/sources/SRC-2026-11-06-003/extracted.md)，第 187–226、267–294、350–362 行。

## 摘要

Cookie 支持会话管理，也会随符合条件的请求发送；通用客户端存储可使用 Web Storage 或 IndexedDB，而不是把大量数据放进 Cookie。

同时设置时 `Max-Age` 优先于 `Expires`；浏览器会话恢复可能延长 session Cookie 的存在时间。删除 Cookie 需要匹配名称、路径及原先指定的 domain，并设置过期时间或非正 `Max-Age`。认证时重新生成会话 Cookie 有助于防止 session fixation。
