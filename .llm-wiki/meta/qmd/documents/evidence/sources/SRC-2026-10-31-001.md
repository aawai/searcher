# Hono Secure Headers Middleware

原文：[Hono Secure Headers Middleware](https://hono.dev/docs/middleware/builtin/secure-headers)；证据：[不可变提取文本](../../raw/sources/SRC-2026-10-31-001/extracted.md)，第 1–247 行。

## 摘要

`hono/secure-headers` 的 `secureHeaders()` 一次设置一组安全响应头，参考 Helmet。选项逐项对应一个响应头；设为 `false` 关闭，设为字符串覆盖默认值（第 14–47 行）。第 53–74 行的选项表给出默认值：默认开启的有 `Cross-Origin-Resource-Policy: same-origin`、`Cross-Origin-Opener-Policy: same-origin`、`Origin-Agent-Cluster: ?1`、`Referrer-Policy: no-referrer`、`Strict-Transport-Security: max-age=15552000; includeSubDomains`、`X-Content-Type-Options: nosniff`、`X-DNS-Prefetch-Control: off`、`X-Download-Options: noopen`、`X-Frame-Options: SAMEORIGIN`、`X-Permitted-Cross-Domain-Policies: none`、`X-XSS-Protection: 0`，并删除 `X-Powered-By`。`Cross-Origin-Embedder-Policy` 默认**关闭**；`Content-Security-Policy`、`Content-Security-Policy-Report-Only`、`Trusted Types`、`Permissions-Policy`、`Reporting-Endpoints`、`Report-To` 默认不设置。

CSP 以驼峰指令对象配置（`defaultSrc`、`scriptSrc`、`frameAncestors`、`upgradeInsecureRequests` 等，第 98–144 行），并支持 `reportingEndpoints` / `reportTo`。导入 `NONCE` 放进 `scriptSrc` / `styleSrc` 后，中间件为每个请求生成 nonce，handler 用 `c.get('secureHeadersNonce')` 读取；也可传函数自行生成并 `c.set` 到上下文（第 146–218 行）。示例中的自定义生成器用 `Math.random()`，属文档示例写法，文档未就随机源作说明。`permissionsPolicy` 接受 `['self']`、`[]`、`false`（输出 `()`）、`true`（输出 `*`）等形式（第 220–247 行）。

与 `poweredBy()` 的顺序有关：先注册 `secureHeaders()` 再注册 `poweredBy()`，`X-Powered-By` 被删除；顺序反过来则被添加（第 76–94 行）。
