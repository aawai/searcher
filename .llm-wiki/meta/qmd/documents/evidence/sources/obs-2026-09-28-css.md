# ⭐ Observation: 便签拟物纸质化改造与CSS层叠特异性避坑

完成了便签拟物纸质感样式重塑（web/src/styles/global.css）。核心结论与避坑：1. 纸质噪点使用 ::before 叠加层（z-index: 1, pointer-events: none），底色保留 color-mix 体系；2. 规避 ::after { z-index: -1 }，因 backdrop-filter 强制生成 Stacking Context 会导致负层级形成卡内脏带；3. 暗色基卡必须使用 [data-theme='dark'] :where(.note-card) 降特异性，否则 (0,2,0) 会强行压死后续彩色变体 (0,1,0) 的 border-color；4. Markdown 排版行高离散，正文绝不能强刷固定像素 ruled lines，否则基线严重错位。
