# line-gap-override CSS descriptor

原文：[MDN](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/%40font-face/line-gap-override)；[提取正文](../../raw/sources/SRC-2026-11-11-003/extracted.md)第 184–246 行。

`@font-face` 的 `line-gap-override` 覆盖字体建议的行间距（external leading）。默认 `normal` 使用字体文件的度量，也可指定百分比；可用于使回退字体更接近主字体。MDN 将该能力标为 limited availability，不能假设所有广泛使用的浏览器均支持；最新标准的完整语法也不一定已实现。
