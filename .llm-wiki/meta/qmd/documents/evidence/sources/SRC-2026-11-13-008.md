# Using Plugins (Milkdown)

原文：[docs/plugin/using-plugins.md](https://raw.githubusercontent.com/Milkdown/website/main/docs/plugin/using-plugins.md)；[提取文本](../../raw/sources/SRC-2026-11-13-008/extracted.md)。

Milkdown 的一切能力均通过插件装配：基础组合为 `Editor.make().use(commonmark).use(history).use(listener).create()`（第 3–14 行）。

运行期动态切换插件需先 `await editor.remove(...)`、清理配置 `editor.removeConfig(...)`、再 `.use(...)` 新插件，并重新调用 `await editor.create()` 生效（第 18–41 行）。官方 `@milkdown/kit` 收录稳定常用的 `preset/commonmark`、`preset/gfm` 与 `plugin/history`、`listener`、`clipboard`、`cursor`、`indent`、`upload`、`block`、`tooltip`、`slash`、`streaming`、`diff` 等；协作（`plugin-collab`/Yjs）、代码高亮（`plugin-prism`）与表情（`plugin-emoji`）作为独立包提供（第 45–86 行）。

注：原文第 26 行示例误将静态调用写为 `Editor.config(...)`（正常链式入口为第 13 行的 `Editor.make().config(...)`）。
