# Using CSS custom properties (variables)

原文：[MDN — Using CSS custom properties](https://developer.mozilla.org/en-US/docs/Web/CSS/Guides/Cascading_variables/Using_custom_properties)；证据：[不可变提取文本](../../raw/sources/SRC-2026-10-27-003/extracted.md)，第 185–198、418–561、659–752 行。

## 摘要

普通自定义属性参与 CSS 级联、默认继承；`@property` 可以设置类型、继承与初始值。`var()` 提供变量不可用时的回退，但不解决浏览器完全不支持自定义属性的问题。

未注册变量可以持有对最终使用位置不合法的值。替换导致消费属性在计算值阶段无效时，浏览器按消费属性的继承或初始值处理；不能依赖 `var()` 的 fallback 自动修复消费属性的类型错误，也不能假定恢复到前一条同属性声明。
