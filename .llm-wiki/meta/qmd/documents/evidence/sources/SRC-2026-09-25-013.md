# MDN CSS Grid Layout 规范与双维轨道布局架构文档

## Summary

本源文档是 MDN 关于 CSS Grid Layout
核心机制、显式与隐式轨道、项目跨越（spanning）以及网格间距（gap）的官方参考规范。CSS
Grid 是 Web
平台唯一的原生双维度网格布局系统，能够同时在行与列两个方向上分配空间与定位网格项。

文档重点阐释了列轨道定义（`grid-template-columns`）、自动行高（`grid-auto-rows`）、轨道间距（`row-gap`
与 `column-gap`）以及项目定位属性（`grid-column` 与 `grid-row` 的 `span`
语法）。在混合尺寸网格中，子元素通过 `grid-column: col / span N` 和
`grid-row: row / span M` 可以横跨多个单元格。配合现代 `aspect-ratio: 1`
属性，跨列子元素能够自适应锁定 1:1
正方形外观，并防止容器因名称文字行高不同而发生竖向形变。在
[[entities/searcher-项目]]
的桌面启动器架构中，[[concepts/dnd-kit-2d-grid-sorting-architecture]] 结合 CSS
Grid 实现了现代手机桌面风格的 Occupancy Grid，普通图标占 1×1 单元格，大文件夹占
2×2（跨 2 列 2 行），且所有网格元素严格落在统一的轨道基准线上。

## Key Takeaways

1. **显式轨道基准与单元格跨度**：Grid
   容器通过固定或响应式声明定义列宽与行高；跨尺寸元素通过 `grid-column: span 2`
   严格占据多轨道，其宽度天然等于
   `2 * col_w + gap_x`，确保与相邻单列元素精确对齐。
2. **独立内层与外层排版流**：卡片正方形主体通过 `aspect-ratio: 1`
   锚定在列宽几何上，外层文本名称通过 Flex
   布局垂直排列在外，不侵占也不参与卡片主体的宽高比计算。
3. **消除隐式行高污染**：网格项目自身避免使用 `min-height` 或 `height: 100%`
   去撑高所属行的隐式轨道，从而保障多行快捷方式不会被多行文本或跨列文件夹推挤错位。
