# Atomic Commit In SQLite

原文：[SQLite Atomic Commit](https://www.sqlite.org/atomiccommit.html)；[提取文本](../../raw/sources/SRC-2026-11-12-001/extracted.md)。

SQLite 的事务原子性意味着事务中的数据库修改要么全部生效，要么全部不生效，即使发生系统崩溃或断电。本文详述 rollback journal 模式；WAL 也提供原子提交，但使用不同机制，不能将本文提交步骤直接套到 WAL（第 113–142 行）。

原子性依赖底层存储、锁和同步等假设，并非数据库文件与其他应用文件之间自动构成原子事务。恢复文件和部署边界参见 [SQLite Backup and Recovery Boundaries](/concepts/sqlite-backup-and-recovery-boundaries.md)，锁语义参见 [SQLite Isolation and Connection Boundaries](/concepts/sqlite-isolation-and-connection-boundaries.md)。此处未验证 Searcher 的运行配置或故障恢复行为。
