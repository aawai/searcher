# README.md: Searcher 项目使用与运维部署总览

## Summary

`README.md` 是 Searcher 项目的面向开发者与管理员的用户手册。系统基于 [[entities/deno-runtime]]、[[entities/hono-framework]]、React 19 与 SQLite，实现单进程全功能搜索主页。普通访客提供纯净搜索体验；登录后开放 Web App 抽屉面板、Markdown 便签、AI 问答服务、壁纸以及跨设备偏好同步。

文档详细描述了本地开发（Deno 2.9.7+、Vite 代理）、生产部署（精确 `APP_ORIGIN`、TLS 终止）、管理员管理（交互式 CLI、无默认密码）、AI 密钥加密存储（`ENCRYPTION_KEY`）、数据备份与恢复规范（ZIP 包含 manifest、database 与 assets，恢复前自动创建快照），以及基于 [[entities/shadcn-ui-system]] 的组件体系。

## Key Takeaways

1. **单进程全栈部署**：通过 `deno task build` 与 `deno task start` 实现前端单页应用与 API 服务同端口单进程运行，符合 [[concepts/single-process-architecture]]。
2. **Web App 抽屉面板**：支持 40%、65%、90% 三段高度切换，支持文件夹管理、图标智能抓取、键盘方向键排序以及离线只读缓存。
3. **安全与密钥体系**：遵循 [[concepts/session-security-and-isolation]]，管理员仅由 CLI 生成，AI Key 使用对称加密，跨实例迁移需单独保管 `ENCRYPTION_KEY`。
4. **数据库与快照运维**：SQLite 采用 WAL 模式，备份通过完整 ZIP 导出，恢复时强制验证完整性并在数据库旁保存保护性快照。
