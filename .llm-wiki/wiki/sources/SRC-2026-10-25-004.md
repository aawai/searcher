# Understanding WCAG 2.2 SC 2.5.8: Target Size (Minimum)
> _Original: [https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html)_

## Summary

WCAG 2.2 新增的 Level AA 条款：pointer 输入的目标至少 **24×24 CSS px**。判定方法是能否在目标内放下一个与页面轴对齐的实心 24×24 正方形——圆角过大、无法放下正方形的目标即 *undersized*。要求与页面缩放无关（缩放不改变 CSS px 尺寸）。

五个例外：**Spacing**（以每个 undersized 目标的 bounding box 中心画 24px 直径圆，圆之间及与其他目标不相交）、**Equivalent**（同页另有达标控件实现同一功能）、**Inline**（句内链接或受非目标文本行高约束）、**User agent control**（未被作者修改的原生控件，如 `<input type="date">` 日历、默认滚动条；作者改过滚动条尺寸则须留间距）、**Essential**（如地图图钉位置本身就是信息）。被交互后弹出的内容（combobox 下拉、模态框、cookie banner）遮挡期间的目标不计，但新弹出内容中的目标本身须满足。

## Key Takeaways

- 2.5.8 是"最低线"，满足后仍可能有很小的目标；本文还建议提供"增大命中区而不增大可见尺寸"或可调布局密度的机制。（更高的 AAA 条款 2.5.5 为 44×44——本文未展开，属背景知识。）
- 间距例外按圆是否相交判断：20×20 目标间隔 4px 合格，零间隔不合格；小目标紧贴大目标同样不合格。
- Searcher 采用比 AA 更严的自定标准：`VISUAL_LANGUAGE.md` 底线规定粗指针（`any-pointer: coarse`）下所有可操作目标 ≥44px（`--control-touch-target` 44、`--row-min-height` 44），仅 hover 出现的操作在触屏常显或进入 `⋯` 菜单。见 [[concepts/pointer-target-size]]。
