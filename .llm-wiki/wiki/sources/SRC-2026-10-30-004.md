# MDN `backdrop-filter` CSS property

原文：[MDN backdrop-filter](https://developer.mozilla.org/en-US/docs/Web/CSS/backdrop-filter)；证据：[不可变提取文本](../../raw/sources/SRC-2026-10-30-004/extracted.md)，第 189–198、255–315、391–399 行。

## 摘要

`backdrop-filter` 对元素背后已绘制的像素施加模糊、调色等效果；元素自身或其背景必须透明或半透明才能看到效果。MDN 标注 Baseline 2024（2024 年 9 月起在最新设备与浏览器上可用）。值可为 `none`、SVG 滤镜 URL 或 filter function 列表（`blur()`、`brightness()`、`saturate()` 等，可串联）。初始值 `none`，不继承，可动画（filter function 列表插值）。

效果只覆盖到最近的 **backdrop root** 为止，其上方内容不受影响。backdrop root 包括：根元素；`filter` 非 `none`；`opacity` < 1；`mask`/`mask-image`/`mask-border`/`clip-path` 非 `none`；`backdrop-filter` 非 `none`；`mix-blend-mode` 非 `normal`；以及 `will-change` 指向上述任一属性的元素。因此父元素 `opacity: 0.9` 会使其成为 backdrop root，子元素的模糊只作用于父子之间的内容，看不到父元素背后的页面——MDN 称这是“已正确应用却无可见效果”的常见原因。
