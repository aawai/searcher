# Base UI: Dialog Component Architecture, Nested Modals and Dismissal
> _Original: [https://base-ui.com/react/components/dialog](https://base-ui.com/react/components/dialog)_

## Summary

Base UI 的 Dialog 原语（`@base-ui/react/dialog`）提供了一套无样式、强无障碍支持且高度可组合的弹出层解决方案。它将弹出层解耦为明确的解剖结构（Anatomy）：`Dialog.Root` 统一维护受控或非受控显示状态；`Dialog.Trigger` 绑定触发事件；`Dialog.Portal` 负责将其渲染至顶层 DOM；`Dialog.Backdrop` 呈现遮罩；`Dialog.Viewport` 处理居中与滚动态；`Dialog.Popup` 容纳实际弹窗内容，并配套 `Dialog.Title`、`Dialog.Description` 与 `Dialog.Close` 形成完整的无障碍语义闭环。

针对复杂应用中的多层交互，Base UI 原生支持对话框嵌套（Nested Dialogs）。当在父弹窗内部挂载子弹窗时，组件层通过 `[data-nested-dialog-open]` 属性和 `--nested-dialogs` CSS 变量暴露层级状态，并自动抑制子对话框的背景遮罩（Backdrop），保证深浅层叠视觉的清晰整洁。在键盘与指针交互上，默认按 `Esc` 键、点击 Backdrop 或触发关闭动作时会调用 `onOpenChange(open: false)`，并可配合受控状态实现级联关闭阻断（如表单未保存时的二次确认弹窗），确保用户操作具有明确的心智模型。

## Key Takeaways

- **复合解剖结构（Anatomy）**：通过拆分 `Portal`、`Backdrop`、`Viewport` 与 `Popup`，开发者能精确控制遮罩动画、滚轮穿透隔离以及弹窗在全屏范围内的几何居中定位。
- **嵌套弹窗遮罩抑制**：子弹窗打开时，其 Backdrop 默认不渲染，避免多层暗色遮罩叠加导致父层界面过暗；同时父层挂载 `data-nested-dialog-open` 供宿主实现缩放或透明度微调。
- **逐层 Escape 响应机制**：弹窗拦截 Esc 按键并向上分发 `onOpenChange(open: false)`。嵌套结构中仅最上层的活动 Dialog 会捕获键盘事件并关闭，防止全局 Esc 导致所有弹窗一并注销。
- **防误触与非指针关闭**：提供 `disablePointerDismissal` 阻止点击外部遮罩误关闭未提交表单，并在受控模式下可平滑接入二步放弃确认流。
