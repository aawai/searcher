# Web Storage API

原文：[MDN Web Storage API](https://developer.mozilla.org/en-US/docs/Web/API/Web_Storage_API)。证据：[提取文本](../../raw/sources/SRC-2026-11-04-003/extracted.md)，第 209–226、245–255、274–276 行。

## 摘要

MDN 描述 `sessionStorage` 按标签页与 origin 分隔，标签页关闭后销毁；`localStorage` 按 origin 分隔，常规浏览下可跨浏览器重启保留。两者操作均同步，大量读写可能阻塞 JavaScript；IndexedDB 可用于异步操作。

私密浏览的数据生命周期较短；第三方 iframe 的访问也可能受浏览器隐私设置限制。origin 边界并不提供应用账号隔离，也不保证设备数据不会丢失。
