# Deno 2.2: OpenTelemetry, Lint Plugins, node:sqlite

> _Original: [https://deno.com/blog/v2.2](https://deno.com/blog/v2.2)_

## Summary

Deno 2.2 是一次重要版本发布，核心增强包括内置 OpenTelemetry 集成、基于 JS/Wasm
的自定义 Lint 插件、Node.js 兼容性深层强化以及对 `node:sqlite` 原生嵌入式 SQLite
引擎的官方支持。这标志着在 Deno 环境中运行原生 SQLite
数据库应用无需外部编译依赖或 node-gyp
工具链，为单进程全栈应用提供了开箱即用的持久化基础设施。

该版本引入了基于 `node:sqlite` 的同步数据库操作接口
`DatabaseSync`，支持纯内存模式（`:memory:`）和磁盘持久化文件，大幅加速了集成测试与本地快速状态管理。同时，`deno check`
与 `deno lsp` 在多包工作区与跨模块类型推断上的性能显著提升，与 TypeScript 5.7
对齐。

## Key Takeaways

- **内置 `node:sqlite` 支持**：Deno 2.2 原生内置 Node 兼容的 SQLite
  模块，无需本地 C++ 工具链或 node-gyp 即可通过
  `import sqlite from "node:sqlite"` 初始化
  `DatabaseSync`，天然契合单进程嵌入式持久化需求。
- **内存模式与高效测试**：支持
  `new sqlite.DatabaseSync(":memory:")`，为单元与契约测试提供毫秒级隔离测试数据库实例，大幅简化测试脚手架并杜绝临时文件残留。
- **工程化工具链强化**：内置 OpenTelemetry 链路追踪，增强型 Linter
  插件架构以及更紧凑的 `deno compile`
  二进制打包，为全栈微应用部署提供完善生命周期支持。
