# React 19 useActionState Reference
> _Original: [https://react.dev/reference/react/useActionState](https://react.dev/reference/react/useActionState)_

## Summary

`useActionState` 是 [[entities/react-19-framework]] 核心 Hook，取代了早期 Canary 版本的 `ReactDOM.useFormState`。它允许开发者基于 Action（异步或同步 Transition）的结果来更新组件状态，并自动提供执行状态指示符 `isPending`。

与传统的 `useReducer` 不同，`useActionState` 接受的 `reducerAction` 允许是异步函数并执行副作用。React 在底层自动将连续的 Action 分发排队并按序执行，彻底消除了并发网络请求导致的竞态冲突（Race Conditions）。此外，它原生支持配合 `<form action={...}>` 实现渐进式增强（Progressive Enhancement）。

## Key Takeaways

- **异步 Reducer 原生支持**：`reducerAction(prevState, payload)` 可以是异步函数并返回 Promise。
- **自动排队与竞态保护**：React 对 `dispatchAction` 的并发调用进行顺序排队，后续 Action 自动接收前序 Action 的结算结果。
- **状态三元组**：返回 `[state, dispatchAction, isPending]`，无需开发者手动维护 `isLoading` 状态。
- **表单重置约定**：当绑定到 `<form action={formAction}>` 时，React 会在提交时自动重置表单内的非受控输入控件。
