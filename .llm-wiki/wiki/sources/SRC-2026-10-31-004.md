# MDN `prefers-reduced-motion` CSS media feature

原文：[MDN prefers-reduced-motion](https://developer.mozilla.org/en-US/docs/Web/CSS/@media/prefers-reduced-motion)；证据：[不可变提取文本](../../raw/sources/SRC-2026-10-31-004/extracted.md)，第 185–318 行（前 184 行为站点导航）。

## 摘要

该媒体特性检测用户是否在系统层面开启了“减少非必要动效”。MDN 标注 Baseline Widely available（2020 年 1 月起）。动机：缩放或平移大面积对象等动画可能诱发前庭运动障碍用户的不适（第 199–201 行）。取值只有 `no-preference`（用户未表态，求值为 false）与 `reduce`（求值为 true；`@media (prefers-reduced-motion)` 等价于 `: reduce`）（第 214–218 行）。

页面列出各平台开启方式（第 222–239 行）：GNOME「Reduced animation」、KDE 动画速度设为 Instant、Windows 10/11 动画效果、macOS「Reduce motion」、iOS「Motion」、Android 9+「Remove animations」，以及 Firefox `about:config` 的 `ui.prefersReducedMotion`（0 完整动画，1 偏好减少）。在 GNOME 下让 Firefox 等基于 GTK4 的程序生效，另需 `gsettings set org.gnome.desktop.interface enable-animations false`。

示例（第 243–273 行）的做法是**替换而非删除**：把带缩放的 `pulse` 动画在 `reduce` 下换成只改透明度的 `dissolve`；覆盖规则与原规则同特异性且写在后面，靠源码顺序生效。第 332 行另提到 `Sec-CH-Prefers-Reduced-Motion` 客户端提示头。
