# src/app.ts: Hono 路由组装与单进程全栈中间件管线

## Summary

`src/app.ts` 是 Searcher 后端应用层核心组装工厂 `createApp` 的所在地。它基于
[[entities/hono-framework]] 构建完整的 HTTP
中间件流和路由树。系统在此处集成了统一响应封装
`responseMiddleware`、全局错误处理 `errorResponse`、未匹配路由回退
`notFoundResponse` 以及访问日志中间件。

在安全方面，针对 `/api/*` 请求设置了细粒度 `bodyLimit`：普通请求体限制为 64
KiB，壁纸上传与系统备份导入放宽至 50 MiB；同时加载 `createApiSecurityMiddleware`
强制 Origin 和跨站安全防护。业务路由由各个业务 feature 显式注册（包括
auth、users、bookmarks、notes、preferences、wallpaper、ai、audit、search、webapp-icons、system），并挂载基于
[[concepts/session-security-and-isolation]] 的 Session 中间件。在静态资源与 SPA
路由方面，将 `/assets/*` 代理至
`web/dist`，并将根路径及客户端页面路由（`/`、`/ask`、`/settings`
等）统一渲染返回前端 `index.html`，完美实现
[[concepts/single-process-architecture]]。

## Key Takeaways

1. **统一中间件流水线**：全局错误、响应信封、日志、请求体体积熔断（64 KiB / 50
   MiB）及 Origin 安全检查。
2. **模块化业务特性注册**：各业务 feature 显式导出
   `register*Routes`，并通过依赖注入（`AppDeps`）与 Session 中间件挂载到应用树。
3. **同源 SPA 宿主**：通过 `serveStatic`
   托管静态资源，并将白名单单页路由直接返回前端入口 HTML，无需额外的 Nginx
   反向代理。
