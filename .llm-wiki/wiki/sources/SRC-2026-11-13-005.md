# Architecture Overview (Milkdown)

原文：[docs/guide/architecture-overview.md](https://raw.githubusercontent.com/Milkdown/website/main/docs/guide/architecture-overview.md)；[提取文本](../../raw/sources/SRC-2026-11-13-005/extracted.md)（替代仅含导航壳的 [SRC-2026-11-13-001](/sources/SRC-2026-11-13-001.md)）。

Milkdown 采用四层模块化架构：Core 层（插件加载、基础文档模型与核心接口）、Plugin 层（语法/UI/功能/工具插件）、Component 层（无头 UI 组件）与 Editor 层（Crepe 或自定义编辑器）（第 7–42 行）。

Markdown 双向转换通过 Remark AST 与 ProseMirror Schema 桥接：解析为 `Markdown → Remark AST → ProseMirror Schema → ProseMirror Document`，序列化为其逆序路径（第 54–77 行）。插件间状态共享与加载时序依赖由 Context System（`Ctx`、`Slice`、`Timer`）驱动，插件按 Setup（`ctx.inject` / `ctx.record`）→ Initialization（`ctx.wait`）→ Runtime（`ctx.get` / `ctx.set` / `ctx.watch`）→ Cleanup（`ctx.remove`）组织（第 79–176 行）。
