# `forced-color-adjust` CSS property (MDN)

原文：[developer.mozilla.org/en-US/docs/Web/CSS/forced-color-adjust](https://developer.mozilla.org/en-US/docs/Web/CSS/forced-color-adjust)；[提取文本](../../raw/sources/SRC-2026-11-09-002/extracted.md)，正文第 183–307 行，其余为站点导航。

## 摘要

- 状态 Limited availability，非 Baseline（第 185–187 行）。
- 取值 `auto`（默认）、`none`（不做强制调整）、`preserve-parent-color`（`color` 继承时取父元素的 used color，否则等同 `none`）（第 222–233 行）。
- 可继承，初始值 `auto`，不可动画（第 239–247 行）。
- 只应用于改善用户的颜色与对比需求，**不得用来阻止用户选择生效**（第 235–237 行）。
- 示例：在 `@media (forced-colors: active)` 内给特定元素设 `none` 以保留站点颜色（第 260–300 行）。
