# ⭐ Observation: 笔记标题焦点下划线与窄窗口抽屉固定错位

用户批准修改约定：笔记标题 .document-title-input 静止无边框，聚焦为盒内 2px --ring 下划线（透明底边预留，forced-colors 用 Highlight），修复原 outline-offset 4px 被标题行顶部 0 padding 与滚动容器裁切；登记为 VISUAL_LANGUAGE 默认交互实现的唯一文本字段焦点例外。窄窗口抽屉：编辑卡片不再 scale(.94)，改为 translateX(抽屉宽 + --space-3) + margin-block --space-3 + --radius + --shadow-l2，抽屉底 --surface-grouped-canvas（亮 #F4F4F5 对白卡片；暗 #242428 对 #1C1C1F 差异小，靠间隙与阴影）；减少动效下保留错位只取消 transition。常驻侧栏样式不变。documents-drawer-motion.test.ts 改为断言两种动效下 12px 间隙与不缩放。标题与正文左边线对齐提案未实施。
