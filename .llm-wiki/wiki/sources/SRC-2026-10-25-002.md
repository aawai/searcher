# Understanding WCAG 2.2 SC 1.4.3: Contrast (Minimum)
> _Original: [https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)_

## Summary

Level AA：文本与文本图像对背景的 contrast ratio 至少 **4.5:1**；large-scale 文本（18pt，或 14pt 粗体）至少 **3:1**。例外：非激活 UI 组件、纯装饰、不可见、作为大量其他视觉内容一部分的附带文字（incidental），以及 logotype。

对比度基于 relative luminance：`(L1 + 0.05) / (L2 + 0.05)`。阈值是硬边界，计算值**不得四舍五入**（4.499:1 不满足 4.5:1）。由于作者无法控制字体平滑 / 抗锯齿，评估取用户代理给出的前景 / 背景色，而非渲染后的像素；细字体实际观感更淡，建议超过最低值留余量。

## Key Takeaways

- 阈值不取整 → 在自动生成配色时应把"合格"定义为 `ratio >= minimum`，并为浏览器 `color-mix()` 等运行时混色的取整误差预留余量。
- 以图标字符（"X"、">"）充当控件时属于非文本，由 1.4.11 而非 1.4.3 约束（见 [[sources/SRC-2026-10-25-003]]）。
- logotype 豁免只适用于 logo 本身；logo 充当链接等控件时仍应选可读变体。
- Searcher 对照：`wallpaper-accent.ts` 的 `TEXT_CONTRAST = 4.5`、`CONTRAST_MARGIN = 0.1`（注释明确用于 browser colour-mix rounding）；检查的文字对包括 强调色文字/表面、强调色文字/浅底（`--accent-soft-mix` 混色）、前景/强调色及其 hover / active 态。relative luminance 线性化阈值使用 `0.04045`（sRGB 标准值）。
