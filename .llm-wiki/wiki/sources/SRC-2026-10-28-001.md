# HTTP caching
> _Original: [https://developer.mozilla.org/en-US/docs/Web/HTTP/Guides/Caching](https://developer.mozilla.org/en-US/docs/Web/HTTP/Guides/Caching)_

## 摘要

HTTP 缓存分为客户端私有缓存和代理等共享缓存。个性化响应不能仅因请求包含 Cookie 就假定为私有；`private` 限制共享缓存保存，`no-cache` 允许保存但复用前需验证，`no-store` 则指示 HTTP 缓存不要保存响应。`no-store` 不会删除同一 URL 已保存的旧响应。

Service Worker 配合 Cache API 属于应用管理的缓存：脚本可自行决定是否存储及复用，不自动受 HTTP 缓存指令约束。`Vary` 可区分语言等请求变体；历史导航及 bfcache 不一定执行与新请求相同的重新验证。
