# Element: setPointerCapture() method

原文：[MDN](https://developer.mozilla.org/en-US/docs/Web/API/Element/setPointerCapture)；证据：[提取文本](../../raw/sources/SRC-2026-11-02-001/extracted.md) 第 182–300 行（前 181 行为站点导航，未使用）。

## 摘要

`setPointerCapture(pointerId)` 把某个元素指定为该指针后续事件的 *capture target*：此后该指针的事件都发往该元素，直到调用 `releasePointerCapture()` 或触发 `pointerup`（第 193–198 行）。页面标注 Baseline Widely available，自 2020 年 7 月起各浏览器可用（第 184–188 行）。

`pointerId` 必须对应一个活动指针，否则抛 `NotFoundError` `DOMException`（第 228–231 行）。官方示例在 `pointerdown` 时捕获、`pointerup` 时释放，使元素在指针移出自身边界后仍可继续被拖动；示例 CSS 同时设置了 `touch-action: none`（第 233–286 行）。

本页未说明 `pointercancel`、`lostpointercapture` 的触发条件；浏览器兼容性表依赖 JS 渲染，提取文本中缺失（第 298 行），未引用。

## 关键要点

- 捕获把后续指针事件重定向到捕获元素，使拖拽不依赖指针是否仍在元素内。
- 对不存在的活动指针调用会抛 `NotFoundError`。
- 释放有两条路径：显式 `releasePointerCapture()`，或 `pointerup` 自动结束。
- 官方示例配 `touch-action: none`，说明触屏上拖拽需同时声明手势归属。
