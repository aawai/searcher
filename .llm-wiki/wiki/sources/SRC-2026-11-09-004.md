# `<system-color>` CSS type (MDN)

原文：[developer.mozilla.org/en-US/docs/Web/CSS/system-color](https://developer.mozilla.org/en-US/docs/Web/CSS/system-color)；[提取文本](../../raw/sources/SRC-2026-11-09-004/extracted.md)，正文第 183–319 行，其余为站点导航。

## 摘要

- forced colors 模式下，system color 暴露用户 / UA 选定的调色板。作者应在**未被强制**的属性上也使用 system color，使整页调色一致（第 198–204 行）。
- 当前关键字：`AccentColor`、`AccentColorText`、`ActiveText`、`ButtonBorder`、`ButtonFace`、`ButtonText`、`Canvas`、`CanvasText`、`Field`、`FieldText`、`GrayText`、`Highlight`、`HighlightText`、`LinkText`、`Mark`、`MarkText`、`SelectedItem`、`SelectedItemText`、`VisitedText`（第 222–242 行）。
- 为减少指纹，部分浏览器对 `AccentColor` / `AccentColorText` 返回固定值（第 244–245 行）。
- 旧关键字（`Window`、`Menu`、`ThreeDFace` 等）已废弃，各有替代（第 247–275 行）。
- 示例与 forced-colors 页相同，只是边框改用 `ButtonBorder`（第 279–310 行）；forced-colors 页用的是 `ButtonText`。两者都可用，不构成矛盾。
