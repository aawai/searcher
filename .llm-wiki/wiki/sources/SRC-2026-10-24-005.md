# MDN：Web App Manifest Members Reference

原文：https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Manifest/Reference

## 摘要

该参考页定义 Web App Manifest 各成员的职责。`id` 是应用标识，`start_url` 是安装后启动的入口，`scope` 是应用页面和子目录的顶层 URL 路径；离开 scope 时浏览器可显示 URL 栏等上下文提示。`display` 定义期望的显示模式，图标与名称成员定义安装身份呈现。

`share_target` 允许已安装的 PWA 注册为系统分享目标，`shortcuts` 描述关键任务入口。该成员列表不是浏览器兼容性保证；需要区分字段定义、浏览器支持和真实入口可用性。

## 关键边界

- Manifest scope 与 Service Worker 注册 scope 是不同机制，不能互相替代。
- 参考页中的 `serviceworker` 字段用于 Web Payment Handler 的 Just-In-Time Worker，不是通用站点 Worker 的注册声明。
- [INFERENCE] Manifest 本身不提供 API 授权或离线数据保障，分享入口仍需要项目自身的登录与输入处理。
