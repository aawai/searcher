# deno.jsonc: Deno 项目依赖锁定与工程任务定义

## Summary

`deno.jsonc` 是 Searcher 仓库唯一的项目配置文件与工程任务清单。它基于 [[entities/deno-runtime]] 的原生模块标准，管理整个项目的前后端依赖映射（imports）与脚本命令（tasks）。

在依赖方面，集成了 [[entities/hono-framework]]、`@std/assert`、`@std/crypto`、`drizzle-orm`、SQLite 原生驱动以及 React 19 / Vite 等生态库。在 tasks 方面，定义了开发阶段的 `dev:api`、`dev`，生产阶段的 `build`、`start`，数据迁移任务 `db:generate`、`db:migrate`，管理员维护命令 `admin:create`、`admin:reset`，以及自动化测试套件 `test`。

## Key Takeaways

1. **统一工作区任务**：通过 `deno task` 覆盖从本地全栈开发、前端 Vite 构建、数据库迁移到安全 CLI 的全部运维生命周期。
2. **严格依赖收敛**：全部由 Deno 官方标准库与 npm 现代 ESM 库构成，无额外外部进程依赖。
3. **测试任务保障**：定义 `deno test -A` 驱动全部契约测试，支撑 [[concepts/contract-first-testing]]。
