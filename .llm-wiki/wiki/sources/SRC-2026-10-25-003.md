# Understanding WCAG 2.2 SC 1.4.11: Non-text Contrast
> _Original: [https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html)_

## Summary

Level AA：识别 UI 组件及其状态所需的视觉信息（边框、焦点指示、勾选标记等），以及理解内容所需的图形对象，与**相邻颜色**的 contrast ratio 至少 **3:1**。非激活组件与外观完全由 user agent 决定的组件除外。同 1.4.3，阈值不取整（2.999:1 不合格）。

"相邻颜色"按组件实际所处位置判断：输入框内白、外白、深色边框时，边框需对两侧白色达标；组件使用多色时，不影响识别的颜色（如 3D 投影）可忽略。没有可见边界的按钮可仅靠文字表明存在，但**聚焦时的焦点指示仍须 3:1**。

## Key Takeaways

- 焦点指示的比较对象取决于位置：在组件外侧的 outline 只需对组件所在背景达标；完全在内侧的需对组件底色达标；跨内外的任一部分达标即可；直接改变组件边框颜色时需与组件内部对比。
- 不要求同一组件不同状态之间颜色差达到 3:1（不相邻时），但状态差异若仅靠颜色，则落入 1.4.1 Use of Color。
- Searcher 对照：`wallpaper-accent.ts` 以 `RING_CONTRAST = 3` 检查强调色焦点环对 `--background`、`--surface`、`--surface-soft` 三种表面；`VISUAL_LANGUAGE.md` 规定首页笔记色点对 Material 组件 ≥3:1、任务框边框 ≥3:1、浅底应用图标边缘 ≥3:1，由 `glass-contrast.test.ts` 检验。
