# AGENTS.md: Searcher 仓库架构与工程指南

## Summary

`AGENTS.md` 是 Searcher 仓库的规范与核心工程指南。Searcher 定位为一个单进程、同源部署的搜索主页服务，由 Deno + Hono 后端与 React + Vite 前端组成，底层通过 Drizzle ORM 操作 SQLite 本地持久化数据库。文档明确了架构原则、数据流动路径、组件库选择（严格要求使用 shadcn/ui）以及严密的权限和安全模型。

指南强调“设计完整、交付增量”和根因优先原则，严禁使用 stopgap 和 hack 代码。所有数据库操作强制经过 `DatabaseStore.run` 的 FIFO 串行队列以避免 SQLite 锁冲突，认证会话仅存储 SHA-256 哈希并通过 HttpOnly Cookie 维护。

## Key Takeaways

1. **单进程同源部署**：由同一个 Deno 进程承载 API 和前端静态页面（`web/dist`），只由 `/` 和 `/admin/users` 返回 React 单页应用壳，API 请求统一返回 JSON 信封。
2. **串行队列数据库访问**：所有查询通过 [[concepts/database-queue-serialization]] 提供的 FIFO 队列，禁用 `.get()`，只用 `.all()` 与 `.limit(1)`。
3. **严格 UI 约束**：禁止重复造轮子，常规组件强制统一基于 [[entities/shadcn-ui-system]]。
4. **安全与权限边界**：管理员仅限交互式 CLI 创建，Session 仅存 SHA-256 哈希，Owner 权限严格限定在当前会话用户。
5. **契约驱动测试**：业务逻辑、数据转换与 API 必须遵循 [[concepts/contract-first-testing]] 流程。
