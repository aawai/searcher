# React useSyncExternalStore
> _Original: [https://react.dev/reference/react/useSyncExternalStore](https://react.dev/reference/react/useSyncExternalStore)_

## 摘要

React 官方 Hook 通过 `subscribe` 与 `getSnapshot` 将外部 store 或浏览器状态接入 React；订阅函数必须返回清理函数。快照应不可变，数据未变化时保持 `Object.is` 相等；可变 store 必须缓存未变化的快照。

Transition 提交前若快照变化，React 会以阻塞更新重试以保持一致性。服务端渲染时需要 `getServerSnapshot`，且服务端与客户端 hydration 初始值一致。React 建议能用内建 state 时优先使用内建 state。

详见 [React 外部状态快照契约](/concepts/react-external-store-snapshot-contract.md)和 [React 19 Framework](/entities/react-19-framework.md)；不据此推断 Searcher 已采用该 Hook。
