# src/main.ts: Searcher 服务端启动与生命周期管理

## Summary

`src/main.ts` 是 Searcher
后端服务的唯一入口文件。它负责严格的启动时校验、环境参数解析、数据库连接与迁移、服务依赖组装以及进程平滑停机（Graceful
Shutdown）。

启动时首先调用 `appOrigin()` 校验 `APP_ORIGIN`
环境变量：在生产环境中必须显式指定且必须为精确
origin；非回环地址（localhost/127.0.0.1）必须强制使用 HTTPS
协议。在生产模式下还会预先检查前端构建产物 `web/dist/index.html`
的存在性。随后初始化基于 [[entities/drizzle-sqlite-store]]
的数据库连接并执行迁移，实例化 [[concepts/session-security-and-isolation]] 的
`AuthService`，创建 [[entities/hono-framework]] 应用，最后通过 `Deno.serve`
监听指定端口。同时注册了 `SIGINT` 和 `SIGTERM` 信号监听器，在停机时依次关闭 HTTP
服务器、关闭数据库队列并刷新日志。

## Key Takeaways

1. **环境与 Origin 严格验证**：防范安全伪造与跨站攻击，生产环境必须提供精确
   origin，非本地回环强制 HTTPS。
2. **启动完整性链条**：校验前端产物存在性 → `openDatabase` → `migrateDatabase` →
   初始化 `AuthService` 预计算 dummy hash（防 timing attack）→ 注入
   `createApp`。
3. **单进程 HTTP 绑定**：直接通过 `Deno.serve({ port }, app.fetch)` 启动服务，是
   [[concepts/single-process-architecture]] 的物理实现点。
4. **平滑停机机制**：捕获系统信号后依次完成 HTTP 停接请求、安全关闭数据库 SQLite
   队列连接以及 flush 日志。
