# `prefers-contrast` CSS media feature (MDN)

原文：[developer.mozilla.org/en-US/docs/Web/CSS/@media/prefers-contrast](https://developer.mozilla.org/en-US/docs/Web/CSS/@media/prefers-contrast)；[提取文本](../../raw/sources/SRC-2026-11-09-003/extracted.md)，正文第 184–261 行，其余为站点导航。

## 摘要

- 自 2022-05 起 Baseline widely available（第 186–190 行）。
- 取值：`no-preference`（布尔上下文为假）、`more`、`less`、`custom`。`custom` 匹配 `forced-colors: active` 用户所选、既非 more 也非 less 的调色板（第 206–218 行）。
- 用户代理通常读取操作系统设置（第 220–222 行）。
- 示例：`prefers-contrast: more` 时把虚线 outline 改为实线（第 224–253 行）。
