# Deno 2 Hono HTTP Server Guide
> _Original: [https://docs.deno.com/examples/hono/](https://docs.deno.com/examples/hono/)_

## Summary

Deno 官方示例详细阐述了如何在 [[entities/deno-runtime]] 2 环境下集成轻量高效的 Web 框架 [[entities/hono-framework]]。依托 Deno 2 对 JSR 的原生支持，开发者可通过 `jsr:@hono/hono` 直接引入依赖，并利用底层高性能的原生 `Deno.serve(app.fetch)` 接口挂载 Hono 的 fetch 调度器。

该集成方案完全免除了传统 Node.js 适配层，在启动速度、内存占用与边缘部署（Deno Deploy）兼容性上具备天然优势，这也是 Searcher 后端采用 `src/main.ts` + `createApp` + `Deno.serve` 架构的官方推荐基石。

## Key Takeaways

- **JSR 原生生态**：在 Deno 2 中推荐通过 `jsr:@hono/hono` 导入框架，获得第一方类型推断与安全审计保障。
- **纯粹的 Fetch 接口**：`Deno.serve(app.fetch)` 直接桥接标准 Web Fetch API 与 Deno 内部 Rust HTTP 引擎，零转换开销。
- **单进程边缘就绪**：天然兼容本地单进程环境与 Deno Deploy，无需调整适配器代码。
