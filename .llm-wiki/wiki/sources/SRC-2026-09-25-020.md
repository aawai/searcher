# dnd-kit DragOverlay and Custom Layout Sorting Strategy Patterns

## Summary

本文深入探讨了在现代非均匀网格及绝对定位布局（如 Masonry 瀑布流、自由多尺寸
Grid）中应用 [[entities/dnd-kit-system]]
的高级工程模式。文章指出，在非规整布局中直接使用默认的 `rectSortingStrategy`
会导致 dnd-kit 按照假定的行列网格计算 `scaleX/scaleY`
与平移形变，从而引起卡片严重扭曲与跳动。

最佳实践架构采用两项核心设计：

1. **`strategy={() => null}` 解耦**：完全禁用 dnd-kit
   的内置网格变形计算，由外部布局算法（如 Masonry 或 Occupancy
   Grid）独立掌控真实物理坐标；
2. **`DragOverlay`
   视效解耦**：将拖拽中的激活项抽离为独立的轻量浮动镜像，原位卡片以半透明占位维持网格骨架稳定，消除
   stacking context 与父容器溢出裁剪带来的视觉异常；
3. **组合碰撞检测**：将 `pointerWithin` 作为首选碰撞策略，以卡片间隙为容错回退到
   `closestCenter`，配合 Y 轴中心相对判定确定 before/after 插入位置。

## Key Takeaways

- **禁止默认网格变换覆盖自定义坐标**：在 Masonry 场景下显式传入
  `strategy={() => null}`；
- **DragOverlay
  消除重绘与视效卡顿**：浮层脱离局部布局流，原位卡片保持半透明占位维持高度与流向；
- **指针精准度提升**：组合碰撞检测（`pointerWithin` +
  `closestCenter`）彻底避免跨列误判远端卡片。
