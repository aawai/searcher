# Hono Streaming Helper: stream, streamText, and Server-Sent Events (streamSSE)

> _Original:
> [https://hono.dev/docs/helpers/streaming](https://hono.dev/docs/helpers/streaming)_

## Summary

Hono 的流式响应工具集 (`hono/streaming`) 提供了基于 Web
标准的流式数据传输能力，包含基础流 (`stream`)、纯文本分块流 (`streamText`)
以及服务端推送事件流 (`streamSSE`)。在 Deno
环境下，这些流式助手无需任何底层运行时适配器即可原生运行于 `Deno.serve` 之上。

`streamSSE` 为实时通信（如 AI
问答逐步打字机吐字、便签协同变更事件广播）提供了开箱即用的协议支持，自动注入
`Content-Type: text/event-stream`、`Cache-Control: no-cache` 与
`Connection: keep-alive` 响应头，并提供 `writeSSE`、非阻塞休眠 `sleep(ms)`
以及连接中断监听
`onAbort`。此外，由于流式传输在回调执行前已发出响应标头，流内部抛出的未捕获异常无法被应用级
`onError` 拦截覆写，必须通过流助手的第三参数错误处理回调（error
callback）进行就地兜底。

## Key Takeaways

- **Web 标准流与 Deno 原生兼容**：`stream` 直接返回符合 Web Streams API 规范的
  `Response` 对象，支持逐 chunk 输出 `Uint8Array` 或管道接入 `ReadableStream`。
- **自动协议注入与事件生命周期**：`streamSSE` 封装了标准的
  `data`、`event`、`id`、`retry` 字段序列化，并通过 `stream.aborted` 和
  `stream.onAbort` 实现客户端断连感知与资源清理。
- **不可覆写的流式异常语义**：流响应启动后响应状态码已锁定，全局中间件的
  `onError` 无法介入，开发时需显式传入错误捕获回调以避免流异常崩溃。
