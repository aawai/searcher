# dnd-kit Sortable Presets and Strategies for Complex Layouts

> _Original:
> [https://docs.dndkit.com/presets/sortable](https://docs.dndkit.com/presets/sortable)_

## Summary

本文档是 [[entities/dnd-kit-system]] 官方关于 `@dnd-kit/sortable`
预设架构与策略体系的核心技术指南。Sortable preset 基于底层 `@dnd-kit/core` 的
Draggable 与 Droppable
抽象，提供了专用于可排序列表和二维网格的高阶构建块。核心组件包括管理排序项标识与空间上下文的
`<SortableContext>`，以及为单个 UI 节点注入 transform 与 transition 属性的
`useSortable` 钩子。

文档重点阐述了针对不同几何维度的排序策略（Sorting Strategy）。其中
`rectSortingStrategy`
作为默认与通用的二维网格排序算法，能够精准计算卡片在网格轨道变动时的位移差值；而
`verticalListSortingStrategy` 和 `horizontalListSortingStrategy`
则分别优化一维流式布局。此外，指南详细解析了 `arrayMove`
索引变换工具、`DragOverlay` 在复杂自定义渲染下的脱模对齐机制，以及通过
`sortableKeyboardCoordinates` 实现的无障碍键盘交互导航规范。

## Key Takeaways

- **网格策略适配**：`rectSortingStrategy`
  专为多行多列网格设计，计算平移变换；而在不等大多尺寸网格（如 1×1 与 2×2
  大文件夹）中，[[concepts/dnd-kit-2d-grid-sorting-architecture]]
  明确禁止对不等大 rect 进行瞬时物理位移，须结合 canonical order 与 DragOverlay
  保持原位占位。
- **状态与表现分离**：`useSortable` 仅计算并提供 CSS transform，组件不应直接修改
  DOM 原生位置，保持动画平滑与渲染一致。
- **无障碍保障**：结合 `KeyboardSensor` 与
  `sortableKeyboardCoordinates`，支持用户通过方向键完成等效拖拽的键盘重排。
- **DragOverlay 精度**：拖拽活动项应挂载于顶层独立 Overlay 轨道，避免父容器
  overflow、z-index 截断及网格挤压变形。
