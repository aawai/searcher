# @dnd-kit/sortable 2D 网格与可排序预设官方指南

## Summary

本源文档是 `@dnd-kit/sortable` 官方关于可排序预设（Sortable
Preset）的架构与使用指南。`@dnd-kit` 是 React
生态中现代、轻量、模块化且高度支持无障碍访问（A11y）的拖拽交互工具库。

文档深入解析了 `<SortableContext>` 与核心 Hook `useSortable`
的工作模型。针对二维网格（2D Grid）与多维排版布局，官方重点阐述了
`rectSortingStrategy`
的应用场景：它通过实时测量网格项的边界矩形（BoundingClientRect）计算拖拽偏移矢量（Transform
Vector），支持在混合尺寸单元格下平滑过渡。此外，文档明确了
`PointerSensor`（配合距离激活约束）与 `KeyboardSensor`（配合
`sortableKeyboardCoordinates`）在移动端与键盘导航中的配置准则。在
[[entities/searcher-项目]] 中，`WebAppLauncher` 与 `FloatingNotes`
均深度基于该体系实现了可靠的磁贴排序与便签拖拽。

## Key Takeaways

1. **分离占位与位移**：`@dnd-kit` 仅通过 CSS `transform` 与 `transition`
   驱动临时拖拽位移，不侵入静态 DOM 布局。最终顺序通过不可变的 `arrayMove`
   派生，由浏览器 CSS Grid 负责静态重排。
2. **2D 网格排序策略**：`rectSortingStrategy` 针对多行多列网格设计，能够天然适配
   1×1 基础单元格与 2×2 文件夹跨行跨列卡片的混合平铺。
3. **传感器与交互冲突防护**：通过 `PointerSensor` 设置 `distance: 8`
   避免普通点击事件与拖拽误触；集成 `KeyboardSensor`
   方向键导航确保完全符合无障碍可访问性。
