# shadcn/ui 官方架构与代码分发模式文档

## Summary

本源文档是 shadcn/ui 的官方架构介绍与设计哲学阐述。shadcn/ui
并不是传统的作为黑盒 npm 依赖分发的 UI
库，而是一套开放代码组件分发架构与注册表系统（Component Distribution
System）。开发者通过 CLI 或 Registry 将组件源代码直接检入到自己的项目中，拥有
100% 的定制和控制权。

文档系统性地列出了包含 Button、Dialog、Drawer、Dropdown Menu、Sheet、Tabs、Table
等在内的全套基础交互组件清单。在 [[entities/searcher-项目]] 中，前端交互严格采纳
[[entities/shadcn-ui-system]] 约束，将所有基础原子组件固化在
`web/src/components/ui/`，并与 Tailwind CSS Token 和 Design Lab
深度绑定，实现高度统一且符合可访问性规范的视觉交互体验。

## Key Takeaways

1. **拥有自己的代码（Code
   Ownership）**：组件源码直接落地在工程目录中，不依赖脆弱的多层第三方抽象包，升级维护可控。
2. **基于优秀原语封装**：底层组合 Radix UI / Base UI
   原语，提供完备的键盘导航、ARIA 属性与焦点管理。
3. **Registry 与设计系统无缝融合**：通过统一配置将 Design Token 注入所有组件，在
   Searcher 中构建起专属的现代 Web 工作台交互质感。
