# `font-display` CSS at-rule descriptor (MDN)

原文：[developer.mozilla.org/en-US/docs/Web/CSS/@font-face/font-display](https://developer.mozilla.org/en-US/docs/Web/CSS/@font-face/font-display)；[提取文本](../../raw/sources/SRC-2026-11-10-002/extracted.md)，正文第 187–310 行，其余为站点导航。

## 摘要

- 取值 `auto` / `block` / `swap` / `fallback` / `optional`（第 224–239 行）。
- 时间线从用户代理首次尝试使用该字体时开始，分为三段：block（用不可见的回退字体渲染）、swap（用可见的回退字体渲染，字体到达后换入）、failure（视为加载失败，正常回退）（第 248–252 行）。
- `swap` = 极短阻塞期 + 无限换入期；`optional` = 极短阻塞期 + 无换入期（第 232–239 行）。
