# Server-Side Request Forgery Prevention Cheat Sheet (OWASP)

原文：[OWASP SSRF Prevention Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/Server_Side_Request_Forgery_Prevention_Cheat_Sheet.html)；[提取文本](../../raw/sources/SRC-2026-11-07-003/extracted.md)，正文第 237–615 行。

## 摘要

SSRF 利用应用对 URL 的处理，让服务端访问内网、外网或本机；典型入口是“用户填写图片 URL 由服务端下载”和 Webhook（第 247–251 行）。不限于 HTTP，`file://`、`gopher://` 等 scheme 也可能被利用（第 259 行）。

两种情形分开防护（第 264–269 行）：

1. **目标可枚举（Case 1）**：allowlist。IP 用不受 Hex/Octal/Dword 编码绕过的库校验，并**以库的输出值**与 allowlist 比较（第 323–346 行）；域名先做格式校验、再严格比对 allowlist（第 348–400 行）。
2. **目标任意外部地址（Case 2）**：无法 allowlist，只能 block-list；IP 须为公网，域名须解析出全部 A + AAAA 并逐一校验（第 502–547 行）。

关键约束：

- 客户端须**禁用重定向跟随**，否则可绕过输入校验（第 302、547 行）。
- 只校验 DNS 答案**不能防 DNS rebinding**：应让 HTTP 客户端只连接已校验的 IP，同时保留原 hostname 用于 `Host`、SNI 与证书校验；重试与回退连接同样适用（第 402–404、542 行）。
- Deny-list 是最后手段且易被绕过；最少应拦截云元数据 `169.254.169.254`、`127.0.0.0/8`、`0.0.0.0/8`、`::1/128`、RFC1918、`fc00::/7`、`fe80::/10`、多播（第 561–576 行）。
- 网络层分段被“高度推荐”（第 500 行）。
