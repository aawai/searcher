# SearXNG Search API

原文：[SearXNG Documentation · Search API](https://docs.searxng.org/dev/search_api.html)（页面版本 2026.11.6+ac11e14c5）；[提取文本](../../raw/sources/SRC-2026-11-07-001/extracted.md)，正文第 204–277 行，前部为站点导航。

## 摘要

SearXNG 通过 `/` 与 `/search` 提供 HTTP 查询，GET 用 query 参数，POST 用 `application/x-www-form-urlencoded` 表单（第 206–224 行）。JSON、CSV、RSS 输出需设置 `format`，且该格式必须在实例 `settings.yml` 的 `search.formats` 中启用；请求未启用的格式返回 **403 Forbidden**，许多公共实例关闭了这些格式（第 211–215 行）。

参数：`q` 必填，原样传给上游引擎，因此 `site:` 等语法只对支持它的引擎生效（第 242–249 行）；`categories`、`language`、`pageno`（默认 1）、`time_range`（`day`/`month`/`year`）、`format`、`safesearch`（`0`/`1`/`2`）、`theme`（第 251–277 行）。
