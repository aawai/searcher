# OWASP：HTML5 Security Cheat Sheet

原文：https://cheatsheetseries.owasp.org/cheatsheets/HTML5_Security_Cheat_Sheet.html

## 摘要

浏览器存储不是认证边界。localStorage 与 IndexedDB 可受 XSS 或有浏览器配置目录访问权限的进程读写；不应在其中存储 session token，并应把读出的值当作不可信输入。HttpOnly Cookie 可降低脚本直接读取会话标识的风险，不代表能消除 XSS 的全部影响。

Service Worker 能透明返回缓存响应，必须有受限控制范围与更新或注销恢复流程。Cache API 不遵循 HTTP 缓存头，缓存条目不会自动过期；敏感响应应显式排除，已有敏感条目需要删除。HTTP 缓存仍需 `Cache-Control: no-store`，但不能靠该头阻止 Worker 主动写 Cache API。
