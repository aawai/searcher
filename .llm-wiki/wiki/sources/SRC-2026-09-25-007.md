# Drizzle ORM SQLite 官方生态与驱动架构文档

## Summary

本源文档是 Drizzle ORM 关于 SQLite 支持与多驱动连接体系的官方指南。Drizzle
提供了针对 SQLite 的轻量、类型安全、贴近 SQL 原生语义的 ORM 抽象层，广泛支持
Node、Deno、Bun 及边缘环境。

文档详细介绍了 SQLite 的 Schema 定义、关系声明、类型系统（如 integer、text、blob
等）以及数据迁移流水线（`drizzle-kit generate` 与
`migrate`）。在驱动生态方面，涵盖了原生驱动以及嵌入式和本地文件库的适配方式。在
[[entities/searcher-项目]] 中，数据层 [[entities/drizzle-sqlite-store]] 正是基于
Drizzle 提供的强类型模式定义，并结合 [[concepts/database-queue-serialization]]
实现了高并发免锁的平稳调用。

## Key Takeaways

1. **类型安全与零运行时开销**：Drizzle ORM 保留原生 SQL 语感，通过 TypeScript
   提供 compile-time 类型推导，完美贴合单进程服务对轻量高性能的要求。
2. **Schema 与迁移闭环**：通过声明式 Schema 定义表结构与索引，利用 `drizzle-kit`
   自动生成严格的 SQL 迁移脚本。
3. **驱动无关性与灵活性**：支持直接操作底层连接句柄，使 Searcher
   能够把所有查询放入全局 FIFO 串行队列。
