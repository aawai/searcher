# `inert` HTML global attribute (MDN)

原文：[MDN](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Global_attributes/inert)；证据：[提取文本](../../raw/sources/SRC-2026-11-01-004/extracted.md) 第 198–217、229–231 行（前段为站点导航）。

**维护说明：**本页于 2026-11-02 依据原始包重建（原页缺失，概念页链接悬空）。

## 摘要

`inert` 是布尔全局属性：元素及其 flat tree 后代变为 inert，其中的链接、按钮、表单控件无法聚焦或点击，并被移出 Tab 顺序与无障碍树（第 198 行）。inert 元素及后代：不触发 `click`；不能聚焦、不触发 `focus`；不能被浏览器页内查找匹配；不能选中文本（类似 `user-select` 禁用）；可编辑内容不可编辑；对辅助技术隐藏（第 207–212 行）。

唯一逃脱者是 `showModal()` 打开的模态 `<dialog>`：不继承祖先的 inert，但可自行设置 `inert`；其他元素都不能逃脱（第 200 行）。`inert` 适合内容区块；单个控件应使用 `disabled`（第 203 行）。也可通过 CSS `interactivity` 属性或 `HTMLElement.inert` DOM 属性达到同样状态（第 214–217 行）。

无障碍：默认没有视觉线索表明某部分是 inert，开发者有责任明确指示哪些内容是活动的、哪些是 inert（第 229–231 行）。

## 关键要点

- 一次性禁用交互、聚焦、查找、选中，并移出无障碍树。
- 只有 `showModal()` 的 dialog 能逃脱继承。
- inert 没有默认视觉标识，需自行提供。
