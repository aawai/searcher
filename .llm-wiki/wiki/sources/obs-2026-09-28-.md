# ⭐ Observation: 精简添加/编辑网站表单视觉层级与轻量化卡片重构

完成了 AppFormDialog.tsx 与 global.css 中 app-dialog 规则的精简视觉层级重构：1) 基础信息首要化：顶部网址输入支持防抖与就近状态反馈（加载中/已获取/错误重试），网站名称与文件夹在桌面端支持双列响应式并排，手机端自动单列折叠，消除 ad-hoc inline styles；2) 打开设置与偏好轻量收拢：将「固定在搜索首页」与「打开方式」整合进紧凑的 .app-dialog-options-card，在跟随全局模式下紧凑展示生效策略；3) 图标能力清晰但不喧宾夺主：将实时图标预览整合至 .app-dialog-icon-card 头部，展示当前图标（38x38px 头像、来源徽标、域名及重置按钮），下方收拢 4 种来源选项卡（自动获取、上传图片、网络图片、AI 生成）；4) 完全支持双主题（var(--surface-soft)、var(--border)、var(--foreground) 等语义 tokens）与移动端响应式（@media (max-width: 640px) 紧凑间距与全宽控制）；5) 严格限定修改范围在 AppFormDialog.tsx 与 global.css 的 app-dialog 样式，通过 deno check 与 deno task build 校验。
