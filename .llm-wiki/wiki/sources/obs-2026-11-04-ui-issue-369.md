# ⭐ Observation: UI 精致化实施计划 Issue 369 已创建

对照 HeroUI v3（@heroui/styles@3.2.7）与本地实页测量，创建 GitHub Issue #369（[设计与计划]，待审查，不授权实施）。用户已确定 D1：修订底线，文本字段（Input/Textarea/NativeSelect）静止态不再要求 ≥3:1 边界；焦点环、无效态、Checkbox/Radio/Switch 等仍 ≥3:1。必做 T1 契约修订、T2 字段新外观（D2 默认浅填充无阴影，design-lab 原型定稿，透明边框保留 forced-colors）、T3 命中区用伪元素扩展而非放大可见尺寸（input 与 menu-item 例外，相邻不得重叠）、T4 SettingsRow 内分段控件用紧凑档使单值行统一 44、T5 Dock 项圆角同心 12、T6 添加应用对话框层级/容器/对齐与笔记侧栏左缘、T7 Button 按压 scale(.97)、T8 直达 URL 时标题栏焦点环、T9 标题栏图标颜色统一。可选 D3–D7（圆角上调、图标描边、菜单中性高亮、侧栏高度统一、标题栏压低）默认 B。headless Chromium 默认 hover:none 会触发 44px 放大规则，实测需 --blink-settings=primaryHoverType=2,primaryPointerType=4 且不要用 emulate 覆盖。
