# Secure cookie configuration

原文：[MDN Secure cookie configuration](https://developer.mozilla.org/en-US/docs/Web/Security/Practical_implementation_guides/Cookies)；证据：[不可变提取文本](../../raw/sources/SRC-2026-10-29-001/extracted.md)，第 191–233、245–266 行。

## 摘要

MDN 建议缩小敏感 Cookie 的可访问范围：对会话标识设置 `HttpOnly`，通过 `Secure` 限制传输，并合理限制 `Domain`、`Path` 和有效期。`Max-Age` 与 `Expires` 同时存在时，前者优先；`SameSite=Strict` 或 `Lax` 限制跨站发送，但只构成部分防护。

指南建议只需当前主机且 `Path=/` 的 Cookie 使用 `__Host-` 前缀；这是一项通用配置建议，不代表 Searcher 已采用该前缀。`HttpOnly` 可限制脚本读取标识，却不阻止浏览器发起携带 Cookie 的请求；[OWASP CSRF 来源](/sources/SRC-2026-10-26-003.md)说明仍需独立防护。
