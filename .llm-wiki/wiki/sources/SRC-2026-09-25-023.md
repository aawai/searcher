# Source Code: masonry.test.ts (Unit Tests for Masonry Layout)

## Summary

`web/src/components/searcher/masonry.test.ts` 为 [[entities/searcher-项目]] 的瀑布流算法提供了完备的契约测试与边界回归防护，采用 Deno 原生测试框架 `Deno.test` 和 `jsr:@std/assert`。

测试集涵盖 4 大核心场景：
1. **基础最短列补位**：使用 6 张具有明确高度梯度的卡片（A:70, B:220, C:70, D:100, E:100, F:100），断言卡片 D 与 E 优先在短列上方补位（$Y=86\text{px}$），远早于长卡片 B 的底部（$Y=220\text{px}$），直接验证了行空白的消除；
2. **极端高度差容错**：单卡片高达 600px 时，后续卡片持续在其余列紧密交替排列，证明极端高度不阻塞其他列；
3. **响应式自适应列宽**：验证了 850px 容器推导为 3 列、600px 容器推导为 2 列、400px 容器推导为 1 列，断言列宽与容器像素完全匹配；
4. **零宽度与空数组边界**：断言在容器尚未挂载或空数据时安全返回默认 0 高度和空映射，绝不发生除零或越界异常。

## Key Takeaways

- **外部可观察契约保护**：测试聚焦于坐标 $X, Y$ 与容器实际高度，验证业务布局不变量；
- **确定性与无副作用**：纯数学断言，不依赖 DOM 渲染或异步等待，执行速度极快（< 25ms）。
