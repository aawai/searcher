# Element: setPointerCapture() method

Baseline

Widely available

This feature is well established and works across many devices and browser versions. It’s been available across browsers since July 2020.

* [See full compatibility](#browser_compatibility)
* [Learn more](/en-US/docs/Glossary/Baseline/Compatibility)

The **`setPointerCapture()`** method of the
[`Element`](/en-US/docs/Web/API/Element) interface is used to designate a specific element as the
*capture target* of future pointer events. Subsequent events for the pointer will
be targeted at the capture element until capture is released (via
[`Element.releasePointerCapture()`](/en-US/docs/Web/API/Element/releasePointerCapture) or the
[`pointerup`](/en-US/docs/Web/API/Element/pointerup_event "pointerup") event is fired).

See [pointer events](/en-US/docs/Web/API/Pointer_events#pointer_capture) for an overview and examples of how pointer capture works.

## [Syntax](#syntax)

js

```
setPointerCapture(pointerId)
```

### [Parameters](#parameters)

[`pointerId`](#pointerid)
:   The [`pointerId`](/en-US/docs/Web/API/PointerEvent/pointerId "pointerId") of a
    [`PointerEvent`](/en-US/docs/Web/API/PointerEvent) object.

### [Return value](#return_value)

None ([`undefined`](/en-US/docs/Web/JavaScript/Reference/Global_Objects/undefined)).

### [Exceptions](#exceptions)

`NotFoundError` [`DOMException`](/en-US/docs/Web/API/DOMException)
:   Thrown if `pointerId` does not match any active pointer.

## [Examples](#examples)

This example sets pointer capture on a [`<div>`](/en-US/docs/Web/HTML/Reference/Elements/div) when you press down on
it. This lets you slide the element horizontally, even when your pointer moves outside of
its boundaries.

### [HTML](#html)

html

```
<div id="slider">SLIDE ME</div>
```

### [CSS](#css)

css

```
div {
  width: 140px;
  height: 50px;
  display: flex;
  align-items: center;
  justify-content: center;
  background: #ffbbee;
  touch-action: none;
}
```

### [JavaScript](#javascript)

js

```
const slider = document.getElementById("slider");

function beginSliding(e) {
  slider.onpointermove = slide;
  slider.setPointerCapture(e.pointerId);
}

function stopSliding(e) {
  slider.onpointermove = null;
  slider.releasePointerCapture(e.pointerId);
}

function slide(e) {
  slider.style.transform = `translate(${e.clientX - 70}px)`;
}

slider.onpointerdown = beginSliding;
slider.onpointerup = stopSliding;
```
