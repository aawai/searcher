# 外观与壁纸

外观设置位于“设置 → 外观”；搜索引擎与打开方式位于“设置 → 搜索”；AI
生成默认参数在 AI 窗口按模型保存。

登录用户在桌面上的设置窗口修改外观，壁纸与首页即时预览；访客设置保留独立页面，可从首页顶栏进入并返回首页。

## 偏好存储

| 状态     | 存储                           | 同步               |
| -------- | ------------------------------ | ------------------ |
| 匿名访客 | 当前设备 IndexedDB，刷新后恢复 | 不上传服务器       |
| 登录用户 | 设备缓存按用户 ID 隔离         | 共享偏好由云端同步 |

- 匿名外观与账号缓存按用户分别保存，互不混用；退出登录或会话失效后恢复该设备的匿名外观。
- 启动时清理旧版 `visitor_appearance` 缓存（localStorage 与
  IndexedDB）。该缓存未关联用户，不再用作匿名或账号偏好。
- 初始加载在读取当前设备的本地外观缓存（IndexedDB）完成后再进入页面；读取本地缓存或云端偏好时，缺失或无效的字段回退为内置默认值，且水合过程不会重复回写未修改的缓存。
- 页面首帧即呈现所存的主题、强调色、控件形状、玻璃档位与标签图标，不先按“跟随系统”显示：每个用户（及匿名访客）在当前设备另以 localStorage 同步保存这几项，并记录最近一次确认的登录身份；页面绘制前按该身份读取。登录、退出或会话检查确定身份后改用对应的那一份，各身份互不混用；会话在其他地方失效时，下次载入先显示上个账号的这几项，确认身份后切换为访客外观。浏览器禁用 localStorage 时首帧回落为默认外观。升级后首次载入尚无该快照，读取 IndexedDB 缓存后补齐。
- 外观与壁纸修改会等待当前设备 IndexedDB 写入完成后再完成保存反馈（如上传/更新提示）；本地提交失败不会显示上传成功。登录用户的修改同时写入本地缓存并提交云端；云端提交失败时保留当前本地外观，未同步的修改留在队列中，顶部提示条的“重试”会重新提交并重新读取云端偏好。账号切换不会提交上个账号的待同步变更。
- 任务栏是独立偏好：系统入口可见性、固定应用与组内顺序通过 `PreferencesDto.dock` 账号同步，桌面布局位置、展开状态和悬浮球位置仅存当前设备并按账号隔离（旧版常驻 / 可收起模式本地数据自动迁移为对应展开状态），不随外观 PATCH 上传。任务栏保存失败时显示错误，保留最近确认的服务端状态。
- “设置 → 数据与同步”说明账户数据与设备布局的保存范围，不以登录状态断言所有数据已同步；外观同步失败仍由顶部提示提供重试。

## 主题与配色

- 主题模式：跟随系统（`system`，默认）、浅色（`light`）、深色（`dark`）、高对比浅色（`high-contrast-light`）或高对比深色（`high-contrast-dark`），设置页与顶栏外观弹层以五个主题预览图块列出（每块是该主题的缩影加短标题“系统 / 浅色 / 深色 / 高对比浅 / 高对比深”，读屏读完整主题名），五块始终一行，空间不足时同步缩小。“跟随系统”只按系统的浅色 / 深色解析，不随系统“增强对比度”切换；系统明暗变化不影响主动选择的其他主题。
- 顶栏主题按钮单击即在浅色与深色之间切换，并保留对比度档位：浅色 ⇄ 深色、高对比浅色 ⇄ 高对比深色；从“跟随系统”切到当前系统明暗的反面（系统为浅色时切到深色）。图标显示当前主题，无障碍名称为“切换到 + 目标主题”。点击顶栏切换按钮或外观弹层主题图块时，从触发控件圆心展开圆形切换过渡（减少动效与不支持 View Transitions 的环境自动降级为即时切换）。其余主题从旁边的外观弹层选择，任一主题两次点击可达。统一输入框的 `/light` `/dark` `/system` `/hc-light` `/hc-dark` 直接切换到对应主题，图标与顶栏一致。管理员可在“系统设置 → 界面主题”把五项之一设为新账户与访客的默认主题。
- 高对比主题是应用自有配色：纯白 / 纯黑画布、清晰边框、实色浮层，任何系统配色下都可使用。系统开启强制颜色（如 Windows 对比度主题）时以系统颜色为准。高对比主题下：
  - 所选强调色（含“跟随壁纸”取色）照常生效：每种强调色另有一组保持色相、只调深（浅色）/ 调亮（深色）的高对比取值，强调文字与链接对全部背景达到 7:1（WCAG AAA），选中项、焦点环与指示条随之变色，选中填充上的文字为纯白 / 纯黑；色点与顶栏芯片显示主题实际使用的颜色。
  - 玻璃效果的所有档位以实色显示（与系统“减少透明度”相同），已存档位不变；设置页“玻璃效果”一行就近说明。
  - 壁纸与构图照常显示和保存；切换回其他主题即恢复原外观。
- 浏览器标题栏颜色（`theme-color`）与 `color-scheme` 跟随生效主题的画布色与明暗（高对比浅色为白、高对比深色为黑），页面首帧即按所存主题取值；`index.html` 中按系统浅色 / 深色的两档颜色只用于页面脚本运行之前。
- 强调色（`accent`）：未登录访客默认绯红玫瑰（`rose`），登录账号默认跟随壁纸（`wallpaper`）；支持跟随壁纸（`wallpaper`）或手选经典蓝（`blue`）、天青蓝（`cyan`）、松石绿（`teal`）、电光紫（`violet`）、暖晨橙（`orange`）、黑曜钛（`mono`）、绯红玫瑰（`rose`）、森林翡翠（`emerald`）、金珀破晓（`amber`）。强调色用于按钮、焦点环与激活标签。
- 跟随壁纸时，强调色基于整张壁纸主色（以画面中心平滑软加权、不随构图焦点变化），并按浅色 / 深色分别校正到可读的对比度；黑、白、灰等中性壁纸得到中性色。没有壁纸、图片无法读取（包括未开放 CORS 的远程图片）时使用经典蓝。更换壁纸后即时生效，调整构图不改变主题色；同一壁纸在不同设备上得到同一颜色。
- 手选颜色会覆盖壁纸取色；在色点中选回第一个“跟随壁纸”即恢复。
- 顶栏右侧主题按钮旁的调色板芯片（显示当前强调色及其按下色、前景与次级文字色）打开外观弹层：依次提供五个主题图块、强调色色点（标题行右侧显示当前名称）、内置插画（开关与每日 / 春兰 / 夏竹 / 银杏 / 红枫 / 尤加利 / 寒梅 / 蕨类八项枝型快捷切换）、深色主题处于常规深色时额外提供“深色壁纸模式”（跟随 / 流光 / 纯黑 / 独立）四档快捷切换、壁纸快捷条（在“独立”模式下操作深色槽位，否则操作浅色/默认槽位；存在最近上传或当前壁纸时展示“不使用壁纸”与最多 5 张缩略图，登录用户按需拉取最近上传，访客在有本地壁纸时也可一键停用），末行“更多外观设置”进入“设置 → 外观”管理上传、链接、构图与删除；即点即生效、按上述规则保存与同步，访客同样可用。方向键在图块、色点、插画、深色壁纸模式或壁纸间选择，Escape 关闭并把焦点还给芯片。
- 强调色色点空间不足时按五项分两行，避免缩窄的设置窗口与粗指针下的外观弹层出现孤点；<640px 的设置页色点独占分组标题下方整行并按五列均分。“跟随壁纸”始终排在首位，键盘方向键选择方式不变。
- 账户页与顶栏头像使用 `--foreground` 文字、中性底，身份不使用强调色：账户页与非首页顶栏为 `--surface-soft`；首页顶栏头像使用 `--surface-control-thumb` 底并带发丝环，外观芯片使用 `--appearance-chip-surface` 底并带控件细边，主题切换采用无外框的双色实心天体图标（`--accent` 主体配 `--foreground` 次级点缀），其余非桌面端图标按钮使用微染强调色的芯片底板与 `--accent` 图标，在明暗主题与任意壁纸上都可辨认。顶栏字标“s.”的句点使用当前强调色。
- 首页顶栏左侧字标与右侧操作组采用克制的轻材质底座（与搜索框、任务栏同源，高对比主题下保留 1px 清晰边框），悬停、键盘聚焦或菜单 / 弹层打开时底座内控件呈现半透明高亮；字标外缘与操作组外缘对齐页面左右边距（手机上即搜索框两缘），任务栏在左侧时字标对齐任务栏中轴，任务栏在右侧时头像对齐任务栏中轴。
- 回收站空状态采用居中的正文字重；分段项显示“应用 0 / 笔记 0”一类无括号计数。
- 升级前已有的账户与设备缓存保留原来的强调色（包括默认的经典蓝），不会改为跟随壁纸；新账户与首次使用的设备默认跟随壁纸。

## 控件形状与玻璃效果

“外观”顶部分组（与主题、强调色、标签图标同组）提供全局“控件形状”与“玻璃效果”偏好，访客与登录用户均可用，修改后即时生效并按上述规则保存与同步（API 字段保持 `searchShape` 与 `glassIntensity`，不新增存储字段或数据库迁移）：

| 设置                          | 可选值                                                            | 默认 |
| ----------------------------- | ----------------------------------------------------------------- | ---- |
| 控件形状（API `searchShape`） | 利落（`rounded`）、胶囊（`pill`）                                 | 利落 |
| 玻璃效果（`glassIntensity`）  | 关闭（`off`）、雾面（`soft`）、磨砂（`regular`）、通透（`clear`） | 磨砂 |

- **控件形状**：默认“利落”（`rounded`）采用精密小圆角尺度（按钮、单行输入、下拉触发器与分段控件 8px、分段子项 6px、首页搜索框与建议浮层 12px、任务栏与首页顶栏操作底座 10px / 内部 6px、粗指针任务栏 12px / 内部 8px、首页应用底板 14px）；选“胶囊”（`[data-shape="pill"]`）时，除首页搜索框及其内部同心控件（`--search-radius` / `--search-inner-radius`）、首页顶栏底座与任务栏及其内部项（`--shape-dock-radius` / `--shape-dock-inner-radius`）以及首页应用底板（`--shape-plate-radius`，20px；实色回退下的宽屏刊头容器亦复用该两档容器圆角）外，还统一作用于全局操作控件——普通独立按钮（primary / subtle / danger / ghost 及 `sm` 尺寸，`--shape-button-radius`）、独立单行输入框与搜索 / 筛选框（`.cn-input`，`--shape-field-radius`）、独立原生下拉选择触发器（`[data-slot="native-select"]`，仅改变页面内触发字段，不改变操作系统展开菜单）、分段控件（`[data-slot="radio-group"][data-variant="segmented"]`）与默认分段式标签页（`[data-slot="tabs-list"][data-variant="default"]`，外壳 `--shape-segment-radius` 与选中项 `--shape-segment-inner-radius` 同心）。宽屏刊头收折态直接保持原刊头日期块的无框直排形态（无外框，仅日期时间皆关兜底态的悬停/实色回退使用小圆角 `--control-radius`）。切换形状只改变圆角，不改变控件高度、内边距、间距或命中区。已保存“胶囊”偏好的设备与账号在升级后自动扩展到上述新控件范围。
- **形状排除项**：横向设置行内的单行输入与下拉选择（`.settings-row:not(.settings-row--vertical) .settings-row-control` 内固定 `--radius-input` 12px；纵向行 `.settings-row--vertical` 内的独立字段仍响应形状偏好）、撤销提示内按钮（`.undo-toast .button`，保持与提示外壳同心的内缩圆角）、图标按钮（`size="icon"` / `.button--icon`）与窗口标题栏按钮（`.window-frame__button`）、`link` / `content` 按钮变体、搜索建议项与图标、下划线式标签页（`variant="line"`）、列表式单选、复选框 / 开关 / 滑块、主题预览图块与强调色色点、多行输入（Textarea）与编辑器、展示徽标（Badge）/ 附件块 / AI 工具芯片、头像与应用图标，以及菜单、Popover、文件夹弹层、窗口、对话框等容器圆角均保持各自固定几何，不被全局胶囊覆盖（首页应用底板及实色回退下的宽屏刊头容器按 14px / 20px 两档容器圆角切换，不变为全胶囊）。
- **玻璃效果分层**：按表面职责分为轻材质（Material，`--material-regular` + `--material-regular-filter` + `--material-regular-sheen`）与厚材质（Floating，`--material-thick` + `--material-thick-filter` + `--material-thick-sheen`）；宽屏展开态首页刊头在图片壁纸上不作为玻璃卡片，改为按壁纸局部亮度三档自适应的零模糊环境护底：
  - **Material（轻材质）**：用于常态首页搜索框、首页应用底板、任务栏与悬浮球、文件夹图块、添加 / 更多图块、首页顶栏控件的悬停 / 键盘聚焦 / 弹层打开底座、同步失败徽标与首页整理提示条。四档的观感差距主要体现在壁纸上的常态轻材质：`off` 关闭（实色 100% / 100%，无模糊，顶光 0）、`soft` 雾面（浅色 76% / 深色 78%，浅色 `blur(28px) saturate(1.35)` / 深色 `blur(28px) saturate(1.15) brightness(0.84)`，顶光缩放 0.35）、`regular` 磨砂（浅色 48% / 深色 50%，浅色 `blur(18px) saturate(1.75)` / 深色 `blur(18px) saturate(1.35) brightness(0.94)`，顶光缩放 0.45）、`clear` 通透（浅色 14% / 深色 18%，浅色 `blur(6px) saturate(1.9) brightness(1.03)` 顶光缩放 0.20 / 深色 `blur(8px) saturate(1.65) brightness(1.04)` 顶光缩放 0.65，并强化清晰玻璃晶透高光边缘，贴近系统级清晰玻璃质感）。当应用主题与壁纸明暗极性对立时（常规非高对比、非强制颜色、未关闭透明），搜索框、任务栏与非隐藏应用底板保持应用主题身份并自动切换为高实度对立壁纸玻璃：深色主题配亮壁纸使用曜石深色玻璃（`off` 100% / `soft` 86% / `regular` 76% / `clear` 62%，配 `brightness(0.55~0.58)` 背景压暗与 `0.5px` 暗外丝 + `1px` 内高光环，任务栏保持实态不降不透明度）；浅色主题配暗壁纸使用高实度白玉玻璃（`off` 100% / `soft` 84% / `regular` 72% / `clear` 58%）。在深色配暗壁纸时仍使用纯平烟熏磨砂玻璃。`off / soft / regular` 兼顾通透与可读性；`clear` 是用户主动选择的高通透档位，首页轻材质文字可读性随壁纸变化。宽屏刊头收折态不再使用 Material 玻璃或曜石/烟熏容器，直接保持原刊头日期块的无框直排形态与局部壁纸自适应策略。
  - **Floating（厚材质）**：用于菜单、Popover、搜索建议列表、文件夹弹层、撤销提示、首页行内 AI 回答与窄屏展开态首页刊头浮层。Floating 在所有档位均优先保证信息文字可读（`off` 100% / 100%、`soft` 92% / 92% 配 `blur(20px) saturate(1.5)` 与 0.40 顶光缩放、`regular` 88% / 86% 配 `blur(20px) saturate(1.8)` 与 0.55 顶光缩放、`clear` 浅色 90% / 深色 86% 配 `blur(14px) saturate(1.8)` 与浅色 0.35 / 深色 0.55 顶光缩放），不随轻材质一起大幅降低不透明度。
  - **宽屏刊头壁纸局部亮度自适应与零模糊环境护底**：仅在宽屏展开态且启用图片壁纸时生效（无图片壁纸时不铺设护底）。壁纸采样对左右各 34% 刊头区同遍计算 OKLab 亮度均值 `L` 与纹理离散度 `spread`（随壁纸摘要缓存 `searcher:wallpaper-accent-cache-v5` 同步读取），首先按 `resolveBackdropPolarity` 自动判定前景文字极性（深色主题下 `L >= 0.58` 切为深色墨字，浅色主题下 `L <= 0.50` 切为浅色象牙字，无样本时回落当前主题极性），再按同向极性分为三档（无样本时回落 `textured`）：
    - `clean`（同向干净底：亮底极性 `L >= 0.74 && spread <= 0.14`，暗底极性 `L <= 0.34 && spread <= 0.14`）：零护底、零 `text-shadow`，直接使用对应极性的标准 `--muted` / `--accent` 呈现清透四阶墨色（暗底极性大号日期保留暖象牙微渐变）。
    - `textured`（中调 / 轻纹理底）：启用与当前前景极性一致的轻量零模糊环境护底（亮底极性 `#F8F8FA` / 暗底极性 `#07080C`，零 `blur()`、零壁纸副本；全列采用单层纯底色配正交可分离柔和遮罩 `mask-composite: intersect` 消除叠加复利并贴齐视口边，纯日期紧凑态采用单层无平顶钟形高斯角晕并按亮 `0.70×` / 暗 `0.56×` 缩放，均平滑衰减至 0% 且不触及顶栏与画面中轴），亮底零阴影、暗底轻度底托影，次级墨用 `--masthead-textured-muted`；全列单层峰值随 `glassIntensity` 联动：`soft` 亮 48% / 暗 40%、`regular` 亮 36% / 暗 28%、`clear` 亮 20% / 暗 14%。
    - `contrast`（高离散度复杂纹理底：亮底极性 `spread > 0.22 && L < 0.68`，暗底极性 `spread > 0.22 && L > 0.40`）：启用同向极性的标准零模糊正交可分离护底（纯日期紧凑态按亮 `0.84×` / 暗 `0.60×` 缩放）与广域柔和文字微光，强化 `--masthead-muted`（`clear` 档进一步收紧为 `--masthead-clear-muted` 并提高摘要实度至 `88%`）与 `--masthead-accent-text`；全列单层峰值随 `glassIntensity` 联动：`soft` 亮 66% / 暗 52%、`regular` 亮 54% / 暗 40%、`clear` 亮 42% / 暗 24%。
    - `off` 关闭时三档护底均归 `0%`，关闭文字软影并回退为遵循当前应用主题的带 1px 清晰边框与内边距的实色容器，还原标准清透四阶墨色。
  - **搜索框聚焦态与聚光呼吸**：首页搜索框桌面默认宽 `--layout-home-search-max`（<1024px 580px，宽屏 `clamp(580px, 32vw, 620px)`，高 52px / 移动端 50px，与应用底板解耦），常态下使用所选档位的 Material（浅色主题带白玉定向顶部高光线与晶透微边，深色纯黑画布带月光定向镜面细丝，深色图片壁纸改用无顶光条与无黑边的纯平烟熏磨砂玻璃或亮壁纸上的曜石深色玻璃）；当搜索框内任意控件获得焦点（`:focus-within`）时，搜索框整组（填充、模糊滤镜与顶光）平滑提升为 Floating 厚材质并呈现克制的双发丝聚焦边（深色图片壁纸使用柔和强调色内发丝与轻外晕，高对比主题保持 2px 清晰焦点环，强制颜色使用系统 Highlight 轮廓），优先保证输入与操作清晰；常规浅色主题以及深色主题配亮壁纸下，搜索框聚焦时周边刊头（含宽屏收折微签）、顶栏、应用底板、任务栏与插画轻度呼吸让位（无暗角遮罩，避免深色墨字被黑幕吞噬），深色配暗壁纸 / 无图片画布下则叠加柔和聚光暗角并进一步沉静周边元素（任务栏通过自身 `--dock-rest-opacity` 调整，不破坏 `backdrop-filter` 采样；关闭玻璃、高对比、减少透明度、减少动效与强制颜色下均保持实色表面静默，交互命中区不变），失焦或悬停即时恢复。
  - **说明与实色回退**：关闭（`off`）、高对比主题、系统开启“减少透明度”（`prefers-reduced-transparency: reduce`）、强制颜色（`forced-colors: active`）或浏览器不支持 `backdrop-filter` 时，Material 与 Floating 均按实色（fill 100%、filter `none`、顶光 0）渲染，仍保留清晰材质边缘，已保存的档位不变；宽屏展开态刊头在关闭玻璃、高对比主题、减少透明度与强制颜色下亦关闭环境护底与文字软影，回退为实色容器加 1px 边框（强制颜色使用 `CanvasText` 轮廓）并还原标准清透四阶墨色。设置页在系统开启“减少透明度”或处于高对比主题时优先显示对应的实色回退说明；否则固定说明“主要影响首页搜索框、应用底板与任务栏；输入聚焦时及菜单等浮层优先保证可读性。”，选中“通透”时在其上方补充提示“通透会明显透出壁纸，首页文字可读性随壁纸变化”。未设置壁纸时，浅色画布仅在右上方呈现极轻的晨光空气感（无暗角、无颗粒），深色画布为 `#07080C` 曜石夜空配斜向银月光（高对比、减少透明度与强制颜色下静默为纯色画布）。

## 系统插画

全站空状态与引导/异常页（`EmptyState`、AI 对话初始态、404 与路由错误页）统一采用「博物植物套色版画」主题自适应 SVG 插画风格（提按笔触、铜版细排线与错版套色，覆盖空文档、空应用、AI 初始态、空回收站、无匹配结果、404 迷途、未登录/受限与加载异常 8 类场景，无设置开关与偏好字段）：

- 插画颜色完全绑定界面语义 Token，随浅/深主题、高对比主题与强调色自动适配；高对比与强制颜色模式下自动隐藏错版套色层，收敛为清晰单色线稿。
- 装饰性图形标记 `aria-hidden="true"` 与 `focusable="false"`，支持轻量指尖微交互（如 404 实时指路罗盘、无结果视差寻虫、空文档点墨盖章、空回收站轻晃等），不进入键盘焦点流；系统开启“减少动效”时保持静止。
- 行内列表空状态（`EmptyState` 的 `density="inline"`，如活跃设备记录、操作记录）不渲染插画，保持列表对齐。

| 显示时间（`showHomeTime`）                  | 开启、关闭 | 关闭 |
| 显示“继续”（`showHomeContinue`）            | 开启、关闭 | 开启 |
| 窄屏默认收起刊头（`homeMastheadCollapsed`） | 开启、关闭 | 开启 |

宽屏下首页刊头展开态在安全区有余量时从页面左右留白克制内退最多 `36px` 作为扉页留白（不覆盖顶栏），高度随内容自适应收口：常规玻璃档位（`soft / regular / clear`）下始终保持无框直排（含仅显示日期 / 时间的紧凑态），启用图片壁纸时按当前侧壁纸局部亮度与纹理离散度自动切换三档（同向干净底 `clean` 零护底零阴影直排；纹理底 `textured` 与强反色底 `contrast` 在排版背后铺设零模糊、贴合内容尺寸的单层正交柔和护底或纯日期钟形角晕，不模糊壁纸且不触及顶栏与画面中轴，并匹配对应文字软影与墨色分层），日期、时间、导语与待办 / 置顶笔记以四阶墨色同列排版；关闭玻璃效果、高对比主题、减少透明度或强制颜色下关闭护底并回退为带清晰边框的实色容器，还原标准清透四阶墨色；无图片壁纸（含纯色画布、深色“氛围流光 / 深黑画布”及仅启用内置植物插画）时零护底、无边框直接排版在画布上。存在“继续”/ 待办 / 固定笔记时，宽屏展开态右上角支持一键收折——直接保持原刊头日期块的尺寸比例与锚点位置（不缩小、不加胶囊壳、不跳动），仅折叠下方列表并在时间行附带未完成待办数（日期时间皆关时回退为无框“今日”兜底微签），该宽屏收折状态按账号或访客隔离保存在当前设备本地，与上表中的云端“窄屏默认收起刊头”相互独立。窄屏收起时露出的日期块直接印在壁纸上，展开完整刊头时在顶栏下方呈现同源圆角厚材质（Floating）玻璃浮层（关闭玻璃效果、高对比主题、减少透明度、强制颜色或不支持 `backdrop-filter` 时回退为实色带清晰边框）。
应用底板保持 `--layout-home-content-max`（<1024px 640px，宽屏按 `clamp(640px, 40vw, 880px)` 增长），与搜索框（`--layout-home-search-max`：<1024px 580px，宽屏 `clamp(580px, 32vw, 620px)`）解耦，圆角随“控件形状”偏好切换（利落 14px / 胶囊 20px）；≥768px 内边距 16px，<768px 全宽且内边距 8px。应用名在底板上直接呈现，不再逐项加 Material 胶囊或壁纸文字光晕。关闭“在首页显示应用”时底板一并消失；首页没有已固定图块时只显示“+”，有图块时不显示“+”。
“显示应用底板”关闭时，首页应用网格不绘制底板（无背景、模糊、阴影与边缘），图标与文件夹直接放在壁纸上，名称改用壁纸文字光晕；底板的内边距与尺寸保留，切换时图块不移动，每屏行数不变。
应用图标固定为桌面 48px、移动端 44px，方格为桌面 76px / 间距 12px（粗指针 80 / 8）、移动端 64 / 6（粗指针 68 / 4），不提供大小档位，旧缓存大小字段被忽略。列数按底板内容宽度计算，仅在不增加行数时平衡末行；显示名称时图标与名称组内垂直居中，隐藏名称不改变行高、格宽或图标尺寸。此偏好统一作用于首页、文件夹弹层和应用窗口，保留可访问名称与提示。大文件夹仍占 2×2，表面与两列图标外缘对齐，名称位于第二行基线。任务栏图标下始终不显示可见文字，保留无障碍名称与桌面提示。
日期、时间与“继续”控制[首页刊头](workspace.md#首页刊头)的刊头块与导语栏；“窄屏默认收起刊头”决定手机与窄窗口打开首页时刊头是否只露出顶部日期块（下滑或点按展开），访客同样可用。访客的这些开关只保存在当前设备，“继续”只对登录用户显示。
“在首页显示应用”是登录用户的跨设备偏好，默认关闭（首页中部留给壁纸，常用网站由任务栏承载）；访客没有应用，不显示该项。关闭时首页不显示应用网格，“显示应用底板”随之隐藏；“显示应用名称”仍可设置，控制应用窗口中的名称。应用仍可通过搜索建议打开，通过任务栏“应用”或 `/apps` 管理，见 [应用](apps.md#在首页显示应用)。已保存过偏好的账号保留原值。

## 任务栏

“设置 → 外观”不再重复提供任务栏设置区；仅登录用户在任务栏选项菜单的“管理”弹窗配置桌面位置（上 / 下 / 左 / 右，默认底部；手机展开后统一固定于底部，不覆盖桌面方向）、桌面“自动隐退”开关与六个系统入口的可见性开关。任务栏在浅色模式下补齐白玉内高光与微边投影，深色保留漆光与对立壁纸自适应玻璃；首次默认展开，所有用户始终可从任务栏选项菜单点击“收起”手动收起为悬浮球，不再区分“常驻 / 可收起”展示模式。

系统入口与常用应用按“系统入口 → 固定应用”顺序分组，排序与取消固定直接在任务栏本体通过拖拽或操作菜单（桌面右键、手机长按静止松开）完成；常用应用在首页或应用窗口中固定到任务栏，取消任务栏固定不删除应用、不影响首页固定。首次不自动复制首页应用。完整交互与旧设备状态迁移见 [任务栏](workspace.md#任务栏)。

API `dock` 包含 `systemOrder`、`hiddenSystemIds` 与 `appIds`，PATCH 支持分别更新。系统顺序必须包含 `home`、`apps`、`notes`、`ai`、`settings`、`trash` 六个合法入口且不能重复；`hiddenSystemIds` 必须为合法系统入口且不重复；应用 ID 必须属于当前账号、未删除且不重复。`dock: null` 重置为六项默认值。旧四项快照被拒绝并提示刷新，不修改已保存偏好。原数据库迁移 `0033` 增加的偏好列继续保存 JSON，本次扩展不增加列或数据库迁移。

## 壁纸

设置页“壁纸”分组支持上传图片与 HTTPS 图片地址，并独立提供“内置插画”植物墨线开关与枝型选择；两者可单独启停，也可同时启用叠加显示。

- 上传支持 png、jpeg、webp、avif，单张不超过 5 MiB，上传后自动设为当前图片壁纸。
- 图片地址仅接受 `https://`，不含账号密码，长度不超过 2048 字符。CSS gradient 等其他字符串不再作为壁纸来源，会被拒绝。
- 内置插画（`botanicalScene`）独立于图片壁纸（`backgroundImage`）存储与开关，提供每日一枝（`auto`，按二十四节气四季物候轮换）、春兰（`orchid`）、夏竹（`bamboo`）、银杏（`ginkgo`）、红枫（`maple`）、尤加利（`eucalyptus`）、寒梅（`plum`）与蕨类（`fern`），访客默认启用“寒梅”（`plum`）并本地保存、登录账号默认关闭并跨设备同步；未启用时按需懒加载，不增加首屏体积。
  - 可在纯色主题背景上单独启用，也可叠加在图片壁纸之上；采用 OKLCH 东方矿物设色（各品种以博物本色为基调并与当前强调色感知融合）、撞水撞色双色晕染与连续毛细水渍凝边（浅色冷灰白画布保留 `#F4F4F5` 纯净基底并仅在生长侧铺设无轮廓素绢清气微晕与轻宣纸微肌理；深色画布以「计白当黑、见光不见月」铺设无轮廓清冷月华微晕与泥金砂子微尘，不绘具象远山或月轮），线条与版画套色随当前主题与强调色自动联动（深色主题使用月光银墨枝干与微光强调色套色，叠加于照片壁纸上时自动柔化以礼让主体），并随二十四节气同株物候、晨昏光影风速及冬季寒梅覆雪细腻变化；高对比主题与系统开启“强制颜色”时自动隐藏，系统开启“减少动效”时直接呈现静态成品。
  - 宽屏启用图片壁纸且构图焦点偏左（`focalX < 0.5`，首页刊头换至右侧）时，植物画布与纯画布晨光/月光同步水平镜像至左侧生长以礼让刊头；宽屏下依品种性格分化贯顶立竿、悬崖垂挂、铁干横斜与坡石丛生四类跨画幅章法，以「密不透风，疏可跑马」编排主景繁花画眼与探空孤梢并避让中轴搜索区与任务栏，非预览画布角落落款二十四节气全字库手工小篆矢量金石闲章（春夏朱文阳刻 / 秋冬白文阴刻，文字保持正向）。
  - 首次选用、切换品种或跨日首次打开时播放逐笔描边绘制过程，同日内重复打开直接呈现成品；常态静息下自动挂起动画循环以实现零功耗静立，按间歇自然阵风波阵面或交互响应唤醒；页面不可见时暂停动画，输入控件聚焦时微风平缓静默；切换主题时同步重绘以避免过渡延迟。
  - 前景枝叶包含克制的微生态点缀（如寒梅/红枫宿雀、春兰粉蝶、夏竹豆娘、银杏草虫、浅色叶尖晨露与深色流萤），并响应首页轻共鸣（搜索提交惊鸿、快速记录落瓣、待办完成拂风与清零开花、主题切换微风）；缩略预览与系统开启“减少动效”时保持静止。
  - 仅启用内置插画（无图片壁纸）时，不提供构图裁切，且不触发照片壁纸的顶栏文字描边；“停用壁纸”与“内置插画”开关互不影响。
- 地址输入为草稿，点击“应用”才保存；输入无效时显示错误提示。
- 旧版保存的 CSS gradient 背景由迁移 `drizzle/0035_remove_gradient_wallpaper.sql` 清空，恢复为默认背景。
- 未设置壁纸（或图片地址无效，以及深色模式选择“深黑画布”）时，背景为当前主题的纯色画布：浅色主题浅灰、深色主题深黑曜石（`#07080C`），深色界面玻璃与暗角基底随当前强调色微染色（`--material-dark-base` / `--wallpaper-shade-base`），高对比主题自动回退纯中性黑；随主题即时切换，不提供纯色背景调色选项。
- 深色壁纸模式（`darkWallpaperMode`，默认 `follow`）与双套壁纸槽（浅色 `backgroundImage` / 深色 `darkBackgroundImage`）：
  - `follow`（跟随浅色，默认）：深色主题下跟随并原样展示浅色壁纸（不压暗、不叠暗角与噪点），首页无框前景与内置插画按壁纸明暗自动切换极性。
  - `ambient`（氛围流光）：将浅色壁纸高度柔化并叠加由壁纸主/辅色驱动的双色光学径向流光罩层（`--wallpaper-ambient-glaze`）与轻量胶片颗粒消色带，保留色彩氛围同时避免亮底灰墙，不触发图片壁纸前景描边。
  - `canvas`（深黑画布）：深色主题下隐藏图片壁纸，仅呈现深黑曜石画布（以及已启用的内置植物插画）；不触发图片壁纸前景描边。
  - `custom`（独立壁纸）：为深色主题保存并使用独立的 `darkBackgroundImage` 上传或 HTTPS 图片（支持访客本地 `data:` URL 与登录账号跨设备同步）；设置页与顶栏外观弹层可在独立模式下切换编辑“浅色壁纸 / 深色壁纸”槽位，预览舞台同步以对应主题模拟呈现，“跟随壁纸”强调色亦自动追踪当前生效壁纸。独立深色壁纸 100% 保留原生色彩与明度（零压暗、零暗角、零噪点），首页无框前景按壁纸明暗自适应。
- 页面刷新时通过 `localStorage` 同步读取当前壁纸的采样摘要缓存（主色、整图平均亮度、顶部 16% 顶栏区亮度及左右 34% 刊头区局部亮度 / 纹理离散度，`v5`），避免“跟随壁纸”强调色、双向极性判定与宽屏刊头护底档位在首帧闪现回退态。
- 图片按 `cover` 裁切，每张图片独立保存焦点（`focalX` / `focalY`，取值 0–1，默认
  0.5，即居中）。当前壁纸行的“调整构图”打开桌面（16:9）与手机（9:19.5）预览，支持点击、拖动、方向键微调和“居中重置”；切换视口不会丢失未保存的构图。
- 构图对话框提示：首页搜索框与应用底板会覆盖视口约 38% 高度处的中部区域。桌面预览以淡淡的覆盖区标出该范围，焦点放在区域之外；首页搜索框的 38% 锚点与布局不因此移动，也不增加遮罩。
- “移除”清除当前编辑槽位的壁纸，不删除已上传的图片，也不改变上传历史。
- HTTPS 图片只能移除引用，不能删除远端文件。
- 图片壁纸在浅/深主题下均以 100% 原始色彩与明度呈现，不再对其施加压暗滤镜、四周暗角、全屏噪点或缩略图压暗。

可读性保证：在常规非高对比、非强制颜色且未关闭透明材质的首页图片壁纸上，直接落在壁纸上的无框前景（宽屏展开态刊头列、顶栏字标/按钮/分割线、隐藏底板时的应用名称、窄屏收起态刊头与内置植物插画）根据所在区域的壁纸 OKLab 感知亮度自动切换极性——亮壁纸配深色墨字与轻量浅色细描边，暗壁纸配浅色象牙字与多层光学投影（不加厚重黑边），消除异向黑/白雾护底。“氛围流光”与“深黑画布”模式下已具备深黑底衬则不再叠加该图片描边，系统开启“强制颜色”时去掉描边与投影，由系统配色保证对比度。“通透”玻璃档是用户明示选择的豁免。首页刊头宽屏展开态及收折态启用图片壁纸时按局部亮度与离散度三档自适应呈现（同向干净底直排零阴影，中调纹理与高离散度复杂纹理底由零模糊贴字柔和环境护底与对应文字软影、墨色护色；窄屏展开态落在圆角 `Floating` 厚玻璃浮层上），均不属于此项（见 [首页刊头](workspace.md#首页刊头)）。

### 上传历史

- 登录用户最近 5 张上传图片保存在服务器，上传第 6
  张时淘汰最早的一张；被淘汰图片的构图记录一并清除，若它正用于浅色或深色壁纸槽位，同时清空对应引用并恢复默认背景。
- 历史卡片主操作打开“调整构图”；菜单提供“设为当前壁纸”（独立模式下分别为“设为浅色壁纸”与“设为深色壁纸”）、“调整构图”和“删除”。鼠标悬停卡片时菜单按钮浮在缩略图右上角，按 Escape 可隐藏它直到指针移出卡片；键盘聚焦或菜单打开时始终显示，触屏常显。
- 删除会从最近上传中永久删除该图片。删除正被浅色或深色槽位使用的当前壁纸时触发单独确认，删除后同步清空对应引用。
- 服务器上传图片使用私有 ETag
  缓存（`Cache-Control: private, no-cache`），每次读取或条件请求仍需鉴权。

### 访客壁纸

- 访客外观及当前本地图片（最大 5
  MiB）保存在当前设备/浏览器，刷新后保留；本地缓存同时保留当前浅色壁纸与深色独立壁纸两张正在使用的图片（超出引用后清理）。
- 访客上传历史只保存在设置页的组件状态中，离开页面即清空，不上传服务器。
- 登录不自动迁移本地图片；只有登录后新上传的图片可以跨设备同步。

## AI 生成默认参数

AI 窗口可为每个模型保存默认生成参数，按模型标识（`modelId`）写入
`aiGenerationDefaults.models`。

- 可保存字段为 `temperature`、`topP`、`maxTokens` 与
  `reasoningEffort`。超出范围的数值或未知的推理强度会被服务端拒绝。
- 保存与清除只作用于当前模型，服务端合并写入，不改变其他模型的默认值。
- 切换模型时，`temperature`、`topP`、`maxTokens`
  依次取该模型保存的值、当前参数、全局默认值（`aiGenerationDefaults.default`）；`reasoningEffort`
  依次取当前参数、该模型保存的值、全局默认值中第一个目标模型支持的档位，都不支持时使用模型默认推理强度。严格推理模型省略
  `temperature` 与 `topP`。
- AI 窗口只写入按模型的默认值；全局默认值由 API 维护。

回归入口：`deno run -A scripts/e2e/run.ts wallpaper`。
