# 外观与壁纸

外观设置位于“设置 → 外观”。工作区风格与标题开关见
[首页与工作区](workspace.md#工作区风格)。

## 偏好存储

| 状态     | 存储                           | 同步               |
| -------- | ------------------------------ | ------------------ |
| 匿名访客 | 当前设备 IndexedDB，刷新后恢复 | 不上传服务器       |
| 登录用户 | 设备缓存按用户 ID 隔离         | 共享偏好由云端同步 |

- 匿名外观与账号缓存不混用；退出登录或会话失效后恢复该设备的匿名外观。
- 升级时删除旧的未关联账号外观缓存；新增字段缺失时使用 canonical defaults。
- 云端读取或保存失败时保留本地外观，可通过顶部“重试”重新读取或提交；账号切换不会提交上个账号的待同步变更。

## 控件形状

“控件形状”可选“默认”或“胶囊”。默认使用小圆角；胶囊联动搜索框、内部搜索引擎与提交按钮，以及常规单行
输入框、按钮和控件内图标。便签编辑器的标题、正文与预览，以及其他多行编辑区、卡片、应用图标、头像与
状态指示保持正常圆角。

## 壁纸

“壁纸与背景效果”支持上传图片、HTTPS 图片地址和 CSS gradient。

- 地址输入为草稿，点击“应用”才保存；gradient 不支持
  URL、变量、动态表达式或外部资源。
- 图片按 `cover` 裁切，每张图片独立保存焦点（0–1，默认中心）。构图弹窗提供
  Desktop / Mobile 真实效果预览，支持点击、拖动、方向键微调和重置焦点。
- HTTPS 与 gradient 只能停止使用，不能删除远端文件。

### 上传历史

- 登录用户最近 5 张上传图片保存于服务器，上传第 6 张时淘汰最早的一张。
- 历史卡片主操作仅预览；菜单提供设为当前壁纸、调整构图和删除。
- 删除当前壁纸需单独确认，并同时解除引用、恢复默认背景；清除当前壁纸不删除文件。
- 服务器上传图片使用私有 ETag 缓存，每次读取或条件请求仍需鉴权。

### 访客壁纸

- 访客外观及当前本地图片（最大 5 MiB）保存在当前设备/浏览器，刷新后保留。
- 访客上传历史只在当前设置页面有效，不上传服务器。
- 登录不自动迁移本地图片；只有登录后新上传的图片可以跨设备同步。

### 背景效果

| 设置         | 范围                      | 默认        |
| ------------ | ------------------------- | ----------- |
| 主题光晕强度 | 0–30%                     | 14%         |
| 动态氛围     | 关闭 / 呼吸 / 呼吸 + 涟漪 | 呼吸 + 涟漪 |
| 动态强度     | 0–100%                    | 35%         |
| 壁纸遮罩     | —                         | 36%         |

壁纸遮罩只控制图片可读性，不压制上层主题光晕。系统 reduced-motion
关闭动画但保留静态光晕，不改变已保存偏好。

## 动态桌面场景

“动态桌面场景”在壁纸之上叠加底部装饰场景，默认关闭（`none`）。目前提供“动态游乐场”（摩天轮、过山车、
旋转木马、秋千船等原创矢量 SVG）。

- 只在首页显示；纯装饰、`aria-hidden`、不拦截指针事件，不改变搜索框、应用图标与窗口的布局。
- 层级位于壁纸之上、所有正常内容、窗口、Dock 与浮层之下。
- 按需懒加载，关闭时不加载；加载失败时静默回退为无场景。
- 标签页不可见时暂停；系统 reduced-motion
  下显示静态画面；两者均不改变已保存偏好。
- 偏好字段 `desktopScene` 随账号同步；缺失、损坏或来自更新版本的未知 ID
  一律降级为 `none`，不影响其他外观字段。匿名与账号偏好的存储规则同上。

### 新增场景

1. 在 `src/shared/desktop-scenes.ts` 的 `DESKTOP_SCENE_IDS` 注册
   ID。无需数据库迁移：字段为自由文本，由共享白名单校验。
2. 在 `web/src/features/desktop-scenes/scene-registry.ts` 添加
   `SceneDefinition`（label、description、懒加载组件）。
3. 在 `scene-previews.tsx` 补设置页缩略图。
4. 样式使用独立前缀（如 `sp-`）与 Design
   Token。色板在场景根选择器上声明为前缀局部变量（如 `--sp-*`），分亮色与
   `.scene-host[data-scene-theme="dark"]`
   暗色两组；形状选择器只引用这些变量，禁止在选择器内散写十六进制色值。
   与主题重合的颜色（地面、远景等）优先由 Token 派生（如
   `color-mix(… var(--accent) …)`）。

宿主与场景的职责边界：

- 场景组件仅接收宿主计算的 `running`，不得修改壁纸控制器或以逐帧 React state
  驱动动画。
- 宿主拥有可见性、reduced-motion、定位和暂停规则。reduced-motion 另有
  `@media (prefers-reduced-motion: reduce)` CSS 兜底，不依赖 JS 写入
  `data-motion`。
- 场景的 CSS 动画选择器须低于宿主暂停规则的优先级；新增场景需验证异步 CSS
  加载后仍能暂停。

回归入口：`deno run -A scripts/e2e/run.ts desktop-scenes`（Chromium，自动生产构建）。
