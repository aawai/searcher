# 外观与壁纸

外观设置位于“设置 → 外观”；搜索引擎与打开方式位于“设置 → 搜索”；AI
生成默认参数在 AI 问答页按模型保存。

登录用户在桌面上的设置窗口修改外观，壁纸与首页即时预览；访客设置保留独立页面，可从首页顶栏进入并返回首页。

## 偏好存储

| 状态     | 存储                           | 同步               |
| -------- | ------------------------------ | ------------------ |
| 匿名访客 | 当前设备 IndexedDB，刷新后恢复 | 不上传服务器       |
| 登录用户 | 设备缓存按用户 ID 隔离         | 共享偏好由云端同步 |

- 匿名外观与账号缓存按用户分别保存，互不混用；退出登录或会话失效后恢复该设备的匿名外观。
- 启动时清理旧版 `visitor_appearance` 缓存（localStorage 与
  IndexedDB）。该缓存未关联用户，不再用作匿名或账号偏好。
- 初始加载在读取当前设备的本地外观缓存（IndexedDB）完成后再进入页面；读取本地缓存或云端偏好时，缺失或无效的字段回退为内置默认值，且水合过程不会重复回写未修改的缓存。
- 外观与壁纸修改会等待当前设备 IndexedDB 写入完成后再完成保存反馈（如上传/更新提示）；本地提交失败不会显示上传成功。登录用户的修改同时写入本地缓存并提交云端；云端提交失败时保留当前本地外观，未同步的修改留在队列中，顶部提示条的“重试”会重新提交并重新读取云端偏好。账号切换不会提交上个账号的待同步变更。
- 任务栏是独立偏好：系统入口可见性、固定应用与组内顺序通过 `PreferencesDto.dock` 账号同步，桌面布局位置、展开状态和悬浮球位置仅存当前设备并按账号隔离（旧版常驻 / 可收起模式本地数据自动迁移为对应展开状态），不随外观 PATCH 上传。任务栏保存失败时显示错误，保留最近确认的服务端状态。

## 主题与配色

- 主题模式：跟随系统（`system`，默认）、浅色（`light`）或深色（`dark`）。
- 强调色（`accent`）：跟随壁纸（`wallpaper`，默认）或手选经典蓝（`blue`）、天青蓝（`cyan`）、松石绿（`teal`）、电光紫（`violet`）、暖晨橙（`orange`）、黑曜钛（`mono`）、绯红玫瑰（`rose`）、森林翡翠（`emerald`）、金珀破晓（`amber`）。强调色用于按钮、焦点环与激活标签。
- 跟随壁纸时，强调色取自壁纸构图焦点附近的主色，并按浅色 / 深色分别校正到可读的对比度；黑、白、灰等中性壁纸得到中性色。没有壁纸、图片无法读取（包括未开放 CORS 的远程图片）时使用经典蓝。更换壁纸或调整构图后即时生效；同一壁纸在不同设备上得到同一颜色。
- 手选颜色会覆盖壁纸取色；在色点中选回第一个“跟随壁纸”即恢复。
- <640px 的强调色色点独占分组标题下方整行，按五列均分为两行；“跟随壁纸”始终排在首位，键盘方向键选择方式不变。
- 账户页与顶栏头像统一使用 `--surface-soft` 中性底和 `--foreground` 文字，身份不使用强调色。
- 回收站空状态采用居中的正文字重；分段项显示“应用 0 / 笔记 0”一类无括号计数。
- 升级前已有的账户与设备缓存保留原来的强调色（包括默认的经典蓝），不会改为跟随壁纸；新账户与首次使用的设备默认跟随壁纸。

## 首页外观

“外观”的“首页”分组保留以下选项；修改后即时生效，并按上述规则保存与同步。

| 设置                               | 可选值                                                          | 默认 |
| ---------------------------------- | --------------------------------------------------------------- | ---- |
| 控件形状（API `searchShape`）      | 圆角（`rounded`）、胶囊（`pill`）                               | 圆角 |
| 玻璃效果（`glassIntensity`）       | 关闭（`off`）、轻（`soft`）、标准（`regular`）、通透（`clear`） | 标准 |
| 显示应用名称（`showAppLabels`）    | 开启、关闭                                                      | 开启 |
| 在首页显示应用（`showHomeApps`）   | 开启、关闭                                                      | 开启 |
| 显示应用底板（`showHomeAppPlate`） | 开启、关闭                                                      | 开启 |
| 显示日期（`showHomeDate`）         | 开启、关闭                                                      | 开启 |
| 显示时间（`showHomeTime`）         | 开启、关闭                                                      | 关闭 |
| 显示“继续”（`showHomeContinue`）   | 开启、关闭                                                      | 开启 |

控件形状作用于搜索框及其内部控件；玻璃效果是全局档位，统一决定搜索框、首页应用底板、文件夹、菜单、建议列表与任务栏等半透明表面的透明度、模糊与饱和度。关闭（`off`）或系统开启“减少透明度”时为实色、无 blur，仍保留材质边缘；系统降级时设置页会提示，已保存的档位不变。首页笔记与搜索框、应用底板同档，统一使用中性 Material 材质并消费全局玻璃档位，不再着色或显示色点（底层颜色保留在笔记面板列表与编辑器中）。轻与标准保证搜索框、底板、文件夹与首页笔记上的文字在任何壁纸上可读；通透会让这些表面明显透出壁纸，不再保证文字可读性，选中时设置页显示说明；菜单、建议列表与任务栏在所有档位都保持可读，AI 问答页的任务栏回退为实色表面。
应用底板与搜索框同宽（`--layout-home-content-max`：<1024px 640px，宽屏按 `clamp(640px, 40vw, 880px)` 增长），圆角 16px；≥768px 内边距 16px，<768px 全宽且内边距 8px。应用名在底板上直接呈现，不再逐项加 Material 胶囊或壁纸文字光晕；底板外的“静”状态继续使用原壁纸文字规则。关闭“在首页显示应用”时底板一并消失；首页没有已固定图块时只显示“+”，有图块时不显示“+”。
“显示应用底板”关闭时，首页应用网格不绘制底板（无背景、模糊、阴影与边缘），图标与文件夹直接放在壁纸上，名称改用与“静”状态相同的壁纸文字光晕；底板的内边距与尺寸保留，切换时图块不移动，每屏行数与笔记避让不变。
应用图标固定为桌面 48px、移动端 44px，方格为桌面 76px / 间距 12px（粗指针 80 / 8）、移动端 64 / 6（粗指针 68 / 4），不提供大小档位，旧缓存大小字段被忽略。列数按底板内容宽度计算，仅在不增加行数时平衡末行；显示名称时图标与名称组内垂直居中，隐藏名称不改变行高、格宽或图标尺寸。此偏好统一作用于首页、文件夹弹层和应用面板，保留可访问名称与提示。大文件夹仍占 2×2，表面与两列图标外缘对齐，名称位于第二行基线。任务栏图标下始终不显示可见文字，保留无障碍名称与桌面提示。
日期、时间与“继续”控制首页搜索框上方的“静”状态，见 [首页与桌面 · “静”状态](workspace.md#静状态)；访客的日期与时间开关只保存在当前设备，“继续”只对登录用户显示。
“在首页显示应用”是登录用户的跨设备偏好，访客没有应用，不显示该项；关闭后首页不显示应用网格，“显示应用名称”与“显示应用底板”随之隐藏。应用仍可通过搜索建议打开，通过任务栏“应用”或 `/apps` 管理，见 [应用](apps.md#在首页显示应用)。

## 任务栏

“设置 → 外观”不再重复提供任务栏设置区；仅登录用户在任务栏选项菜单的“管理”弹窗配置桌面位置（上 / 下 / 左 / 右，默认底部；手机展开后统一固定于底部，不覆盖桌面方向）与六个系统入口的可见性开关。任务栏首次默认展开，所有用户始终可从任务栏选项菜单点击“收起”手动收起为悬浮球，不再区分“常驻 / 可收起”展示模式。

系统入口与常用应用按“系统入口 → 固定应用”顺序分组，排序与取消固定直接在任务栏本体通过拖拽或操作菜单（桌面右键、手机长按静止松开）完成；常用应用在首页或应用管理面板中固定到任务栏，取消任务栏固定不删除应用、不影响首页固定。首次不自动复制首页应用。完整交互与旧设备状态迁移见 [任务栏](workspace.md#任务栏)。

API `dock` 包含 `systemOrder`、`hiddenSystemIds` 与 `appIds`，PATCH 支持分别更新。系统顺序必须包含 `home`、`apps`、`notes`、`ai`、`settings`、`trash` 六个合法入口且不能重复；`hiddenSystemIds` 必须为合法系统入口且不重复；应用 ID 必须属于当前账号、未删除且不重复。`dock: null` 重置为六项默认值。旧四项快照被拒绝并提示刷新，不修改已保存偏好。原数据库迁移 `0033` 增加的偏好列继续保存 JSON，本次扩展不增加列或数据库迁移。

## 搜索引擎与打开方式

| 设置                               | 可选值                                          | 默认           |
| ---------------------------------- | ----------------------------------------------- | -------------- |
| 默认搜索引擎（`defaultEngine`）    | Google、Bing、百度、DuckDuckGo                  | Bing           |
| 搜索结果打开方式（`searchTarget`） | 当前标签页打开（`same`）、新标签页打开（`new`） | 当前标签页打开 |

- 服务端系统设置（`SystemSettingsStore`）中的默认搜索引擎、默认主题与默认打开方式会覆盖上表的内置默认值。

## 搜索历史

- `searchHistoryEnabled`
  默认关闭。开启后，搜索记录写入当前账号的服务端搜索历史；关闭时不写入。
- 设置页目前没有对应开关，需通过 `PATCH /api/preferences` 修改。
- 搜索框的本地搜索建议历史（IndexedDB）与该选项无关。

## 壁纸

设置页“壁纸”分组支持上传图片、HTTPS 图片地址和 CSS gradient 三种来源。

- 上传支持 png、jpeg、webp、avif，单张不超过 5 MiB，上传后自动设为当前背景。
- 图片地址仅接受 `https://`，不含账号密码，长度不超过 2048 字符。gradient 仅接受
  `linear-gradient`、`radial-gradient`、`conic-gradient`（可带 `repeating-`
  前缀），不支持 `url()`、`var()`、`image()`、`image-set()`、`expression()`
  等外部资源或表达式，也不接受分号、花括号与注释。
- 地址与 gradient 输入为草稿，点击“应用”才保存；输入无效时显示错误提示。
- 图片按 `cover` 裁切，每张图片独立保存焦点（`focalX` / `focalY`，取值 0–1，默认
  0.5，即居中）。当前壁纸行的“调整构图”打开桌面（16:9）与手机（9:19.5）预览，支持点击、拖动、方向键微调和“居中重置”；切换视口不会丢失未保存的构图。
- 构图对话框提示：首页搜索框与应用底板会覆盖视口约 38% 高度处的中部区域。桌面预览以淡淡的覆盖区标出该范围，焦点放在区域之外；首页搜索框的 38% 锚点与布局不因此移动，也不增加遮罩。
- “移除”清除当前壁纸并恢复默认背景，不删除已上传的图片，也不改变上传历史。
- HTTPS 与 gradient 只能移除引用，不能删除远端文件。
- 可读性：壁纸上覆盖的遮罩浓度分为五档，默认“均衡”；未设置壁纸时滑块不可用。

| 档位         | 遮罩浓度 |
| ------------ | -------- |
| 无           | 0%       |
| 清透         | 12%      |
| 均衡（默认） | 24%      |
| 沉静         | 36%      |
| 专注         | 48%      |

### 上传历史

- 登录用户最近 5 张上传图片保存在服务器，上传第 6
  张时淘汰最早的一张；被淘汰图片的构图记录一并清除，若它是当前壁纸，同时恢复默认背景。
- 历史卡片主操作打开“调整构图”；菜单提供“设为当前壁纸”“调整构图”和“删除”。
- 删除会从最近上传中永久删除该图片。删除当前壁纸使用单独的确认提示，删除后同时恢复默认背景。
- 服务器上传图片使用私有 ETag
  缓存（`Cache-Control: private, no-cache`），每次读取或条件请求仍需鉴权。

### 访客壁纸

- 访客外观及当前本地图片（最大 5
  MiB）保存在当前设备/浏览器，刷新后保留；本地只保留当前使用的一张图片。
- 访客上传历史只保存在设置页的组件状态中，离开页面即清空，不上传服务器。
- 登录不自动迁移本地图片；只有登录后新上传的图片可以跨设备同步。

## AI 生成默认参数

AI 问答页可为每个模型保存默认生成参数，按模型标识（`modelId`）写入
`aiGenerationDefaults.models`。

- 可保存字段为 `temperature`、`topP`、`maxTokens` 与
  `reasoningEffort`。超出范围的数值或未知的推理强度会被服务端拒绝。
- 保存与清除只作用于当前模型，服务端合并写入，不改变其他模型的默认值。
- 切换模型时，`temperature`、`topP`、`maxTokens`
  依次取该模型保存的值、当前参数、全局默认值（`aiGenerationDefaults.default`）；`reasoningEffort`
  依次取当前参数、该模型保存的值、全局默认值中第一个目标模型支持的档位，都不支持时使用模型默认推理强度。严格推理模型省略
  `temperature` 与 `topP`。
- AI 问答页只写入按模型的默认值；全局默认值由 API 维护。

回归入口：`deno run -A scripts/e2e/run.ts wallpaper`。
