# 首页与工作区

首页以搜索为主操作，应用库与固定到首页的笔记为个人内容层；应用在首页直接管理，笔记在
Workspace Host 中管理。本文记录首页布局、Host
呈现形态、搜索框、撤销反馈与快捷键的用户可观察契约。视觉规则见
[Visual Language](design/VISUAL_LANGUAGE.md)。

## 首页

首页只有 Zen（极简）一种形态。

- 搜索框是首页的主操作；匿名与登录状态的搜索框纵向锚点保持一致，个人内容仍须登录。
- 搜索框下方显示应用库（见 [应用](apps.md#首页应用库)）；固定到首页的笔记以
  首页纸张呈现（见 [笔记](documents.md#首页纸张)）。
- 不显示品牌大标题。
- 首页底部居中 Dock 进入笔记工作区。

## 搜索框

搜索框是 combobox：输入框保持焦点；建议列表为 listbox，选项使用稳定 ID，并通过
`aria-activedescendant` 指向当前项。选项不进入 Tab 顺序，结果数量由 polite
状态区播报。

- 搜索模式占位文案为“搜索或输入网址”；引擎选择器紧邻输入内容，右侧只保留提交按钮，
  聚焦搜索的快捷键在按钮 tooltip 中提供，不常驻占用输入空间。
- 网页联想最多显示 6 条；匹配应用显示与应用网格相同的图标（加载失败回退首字母），
  应用结果与后续历史 / 网页联想通过留白与细分隔线区分，键盘仍沿单一选项序列导航。

- 输入法组合期间，方向键与 Enter
  交给输入法，不切换联想或提交搜索；兼容组合结束后仍带 `keyCode=229`
  的选字回车同样不提交。
- Escape 只关闭建议列表，焦点保留在输入框。
- 在线联想失败时显示“在线联想暂不可用”，本地历史与应用结果保持可用。
- 粗指针（触屏）下搜索按钮与建议选项使用 44px 点击目标。

## 工作区呈现

Workspace Host 承载笔记工作区（应用不在工作区中，见 [应用](apps.md)），按视口宽度呈现：

| 宽度    | 呈现                               |
| ------- | ---------------------------------- |
| >=768px | 非模态右侧 Panel，笔记编辑时可展开 |
| <768px  | 模态底部 Sheet                     |

- Panel 或 Sheet
  打开时，若面板不会遮挡搜索框则不推动、不缩小搜索框与首页内容；会遮挡时（宽度
  <1496px），
  搜索框与应用库在面板左侧的剩余空间内居中，纵向位置不变，过渡与面板同步。
  笔记编辑展开面板时不让位。首页纸张不随之移动，面板打开期间不重排。破坏性确认与未保存修改确认使用
  AlertDialog。
- ≥768px 的 Panel 非模态：无遮罩、无全局焦点陷阱，背景仍可交互。<768px 的 Sheet
  为模态：带抓手，从底边滑入、下滑关闭，避开安全区，焦点在 Sheet 内循环。
- 关闭时 Panel 淡出、Sheet
  滑出后再卸载，退场期间保留原内容且不可交互；退场中再次打开会直接恢复。
- 打开时焦点进入工作区根视图的“收起工作区”按钮；嵌套页进入“返回上一级”。关闭或
  Escape
  后焦点回到打开它的控件；工作区内部切换不覆盖已记录的打开控件，若该控件已卸载，焦点回退到工作区入口。
- 登出或切换账号时，工作区的 route、query 与草稿状态一并清空。
- 标题栏提供关闭按钮；根视图另有“新建笔记”图标主操作，标题仅作为可访问名称，
  嵌套视图显示返回与标题。
- 打开工作区时首页 Dock 淡出隐藏，关闭后淡入。

## 撤销与反馈

- 应用移至回收站，或首页纸张（笔记）移至回收站后，按账号提供 10
  秒撤销窗口：提示展示名称，支持逐项与批量撤销，并链接到回收站。悬停或聚焦提示时暂停计时；菜单或弹窗打开时暂停并暂藏提示，关闭后继续剩余时间。
- 撤销失败时保留对应项目与错误信息，允许重试；长名称换行，不超出视口。
- Ask 会话删除保留 5 秒撤销，见 [AI](ai.md)。

## 快捷键

搜索、AI 问答、笔记编辑的快捷键与搜索快捷命令统一列在“设置 → 快捷键”
（`/settings/shortcuts`），无需登录即可查阅，按当前平台展示键位与生效上下文。编辑器
本地操作优先于首页聚焦搜索；不提供快捷键自定义或同步。优先级依次为：局部可编辑控件 >
当前页面或工作区 > 首页全局 > 浏览器默认。首页全局快捷键不在
input、textarea、select、contenteditable 或 `role="textbox"`
中触发；已被处理的事件与输入法合成期间不执行快捷键。Ask 的会话内查找保留页面级
composer 语义，离开 Ask 后不拦截浏览器查找。方向键、Escape、Enter、Tab、Space
等导航键不列为产品快捷键。macOS 使用 Command，其他平台使用 Ctrl。

Escape
通过统一层栈一次只消费最上层的菜单、弹窗或工作区，不误关下层工作区；优先级为浮层、Host，输入法合成中不分发，注销的层不穿透到
window。焦点归还规则见 [前端 · 可访问性契约](frontend.md#可访问性契约)。

开发维护：

- 通用 binding 与命令 target 在
  `web/src/features/shortcuts/shortcut-catalog.ts`。
- 业务组件保留事件处理归属，说明页消费各自的同一 catalog。
