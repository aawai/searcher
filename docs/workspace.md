# 首页与桌面

首页以搜索为主操作，固定到首页的应用、文件夹与笔记为个人内容层；首页是唯一桌面，
应用与笔记通过任务栏直接打开管理面板，AI 问答使用独立页面，不再提供“资料库”聚合层。
本文记录首页布局、任务栏、工作面板、搜索框、撤销反馈与快捷键的用户可观察契约。视觉规则见
[Visual Language](design/VISUAL_LANGUAGE.md)。

## 首页

首页只有 Zen（极简）一种形态。

- 搜索框是首页的主操作；匿名与登录状态的搜索框纵向锚点保持一致，个人内容仍须登录。
- 搜索框下方显示 Material 底板中固定到首页的根级应用与文件夹（见 [应用](apps.md#首页应用库)），底板与搜索框同宽（<1024px 640px，宽屏按 `clamp(640px, 40vw, 880px)` 增长），圆角 16px，≥768px 内边距 16px、<768px 内边距 8px。关闭“在首页显示应用”不渲染底板；关闭“显示应用底板”时保留底板几何但不绘制底板；没有固定项时只含“+”，有固定项时不显示“+”，文件夹弹层锚定底板上缘。未固定到首页的应用与文件夹仍可从应用面板或搜索访问；取消固定即时从首页移除，刷新后保持。
- 底板内名称不加逐项胶囊或壁纸光晕；底板统一消费玻璃档位，关闭玻璃效果或减少透明度时为实色且保留边缘。图标块、底板 / 搜索框、浮层依次为贴面、Material、Floating 三档高度。
- 方格与图标尺寸不因底板、名称偏好或平衡改变，网格在底板内居中；容量列末行只剩 1 个图块时，在现有布局算法外层收窄到不增加行数的最少列数（19 个 / 6 列 → 5 列 × 4 行；末行已有 ≥2 个时保持原列数），不改变大文件夹的 2×2 足迹与回填。有效行数计入底板内边距（网格顶已含上内边距，另计下内边距），底板外下缘须保留至少 48px 视口留白；不足时减少有效行数，不移动搜索框的 38% 锚点。
- 放不下的固定项收进末格“更多（N）”；点击直接打开应用面板（含全部应用与“添加应用”）。
- 固定到首页的笔记以 Material 笔记呈现（见 [笔记](documents.md#首页笔记)）：≥1024px 且至少一侧有完整单元时使用分带吸附网格——两侧列从搜索框 / 底板外缘向外展开，行 0 对齐搜索框上缘，可向上到顶栏下缘加一个间距、向下到视口底部 48px 留白；底板下方另有 20px 间距的 shelf。768–1023px 与 1024–1087px 无侧列时为两列流式，<768px 纵向堆叠；没有新增尺寸档位，材质、字号、中性视觉与截断规则在各断点一致（首页统一为中性 Material，无背景着色与色点）。
- 不显示品牌大标题。尺度分为主体块（搜索框 + 应用底板）、次级（“静”状态日期 / 时间、首页笔记）与辅助（顶栏字标、主题与头像）；只使用已登记字号，不用放大顶栏争夺搜索焦点。
- 顶栏右侧只有主题切换与身份入口（登录用户为头像菜单，访客为“登录”）。头像菜单只保留
  “账户与安全、设置、管理后台、回收站、退出登录”，其中管理后台仅管理员可见。
- 登录用户通过任务栏的“首页、应用、笔记、AI 问答、设置、回收站”切换工作区；访客不显示任务栏。
  搜索框仍支持 `/settings`、`/shortcuts`、`/notes`、`/apps` 和有可用模型时的 `/ai 问题`。
  滚轮与捏合不切换首页状态。

### “静”状态

搜索框上方是一层只读信息，直接放在壁纸上，不占用搜索框的布局位置：开关其中任何一项、
“继续”加载完成或为空，搜索框的纵向锚点都不变；这一层没有任何动画。

- **日期**：默认显示，格式“10月24日 星期六”，按本地时间在午夜更新。
- **时间**：默认关闭；开启后显示 24 小时制“09:05”，每到整分钟更新，数字等宽，更新时文字不移动。
  日期与时间可分别关闭，二者都关闭时不显示这一行。
- **继续**（仅登录用户，默认开启）：一行，最多两项，以“·”分隔：
  1. 最近编辑的笔记（“继续编辑 标题”）与最近的未完成 AI 对话（“继续对话 标题”）中较新的一项；
     时间相同取笔记。
  2. 首页笔记中未勾选的待办总数（“首页 N 项待办”），为 0 时不显示。
     点击笔记与待办在[笔记面板](#应用与笔记工作面板)打开对应笔记（待办打开首页顺序中第一张含未完成待办的笔记），点击对话进入
     `/ask/:id`。超出宽度时截断笔记 / 对话标题，待办计数完整显示。没有候选时该行保留高度但不显示内容。
     笔记变更、回到标签页与关闭笔记面板后重新读取；读取失败时保持原样，不显示错误。
- 访客只显示日期（以及开启的时间）。三项开关位于“设置 → 外观 → 首页”，见
  [外观](appearance.md#首页外观)。

候选来自 `GET /api/home/continue`（需登录，未登录 401），响应 `HomeContinueDto`：

| 字段           | 内容                                                                                                                                                                |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `document`     | 未删除笔记中 `updatedAt` 最大者：`{ id, displayTitle, updatedAt }`，无则 `null`                                                                                     |
| `conversation` | 未删除、开启历史的会话中，当前分支末条消息不是已完成助手回复（用户消息待回复，或助手消息生成中 / 中断 / 失败）且最近更新者：`{ id, title, updatedAt }`，无则 `null` |
| `homeTasks`    | 首页笔记（按首页顺序）中未勾选任务项总数与首个含未完成任务的笔记：`{ open, documentId }`；代码块内的 `- [ ]` 不计；总数为 0 时 `null`                               |

## 搜索框

搜索框是 combobox：输入框保持焦点；建议列表为 listbox，选项使用稳定 ID，并通过
`aria-activedescendant` 指向当前项。选项不进入 Tab 顺序；每个分组使用带可访问名称的
`role="group"` 包裹在 listbox 内；结果数量由 polite 状态区播报。

- 搜索模式占位文案为“搜索或输入网址”；引擎选择器紧邻输入内容，右侧只保留提交按钮，
  聚焦搜索的快捷键在按钮 tooltip 中提供，不常驻占用输入空间。
- 输入框内容即意图：输入后按来源分组显示结果，不改写用户输入，也不做智能路由。

### 分组与排序

分组固定按以下顺序显示，空分组不显示；键盘沿单一选项序列依次跨组导航，分组之间用留白与细分隔线区分，分组标题仅作视觉与可访问名称。

| 顺序 | 分组  | 内容与组内顺序                                                                                               | 可见范围           |
| ---- | ----- | ------------------------------------------------------------------------------------------------------------ | ------------------ |
| 1    | 问 AI | 单行，把当前输入交给 AI                                                                                      | 登录且存在可用模型 |
| 2    | 我的  | 笔记（含固定到首页的笔记）。≥3 个字符按相关度，更短的输入先标题命中再按更新时间；见 [文档 API](documents.md) | 登录               |
| 3    | 应用  | 名称前缀、名称子串、网址、首页顺序；不限是否固定到首页；显示与应用网格相同的图标（加载失败回退首字母）       | 登录               |
| 4    | 网页  | 本地搜索历史在前（最多 3 条），在线联想在后，合计最多 6 条                                                   | 所有人             |
| 5    | 命令  | 以 `/` 开头时列出搜索快捷命令与引擎前缀，随输入的前缀过滤；非 `/` 输入时不显示                               | 所有人             |

- “我的”“应用”两组来自 `GET /api/search/personal`，每组最多 5 条；请求带防抖并在输入变化时中止过期请求。
- 访客只看到“网页”与“命令”。个人检索返回 401 时，“我的”“应用”两组立即消失，其余分组保持可用。
- 没有可用模型（未配置或未启用）以及访客：搜索建议不显示“问 AI”行与 `/ai`，`Alt/Option+Enter` 不响应；引擎菜单只含搜索引擎，`/ai 文本` 按字面搜索。登录用户的任务栏仍保留“AI 问答”，进入后显示不可用原因；有相应权限时提供配置入口。

### 键盘

| 输入               | 行为                                                                                                                                                                   |
| ------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Enter`            | 未选中建议时始终用默认引擎搜索当前输入，不做智能路由；选中建议时执行该项                                                                                               |
| `Alt/Option+Enter` | 把当前输入交给 AI，等同于选中首行“问 AI”后回车，在输入框下方打开[回答卡片](#ai-回答卡片)；无可用模型时不响应，且不显示 AI 行                                           |
| `Mod+Enter`        | 在新标签页提交搜索（选中建议时在新标签页执行该项的搜索）                                                                                                               |
| `Shift+Enter`      | 快速记录：创建一条未归档、未固定到首页、非收藏的笔记，清空输入并给出提示，提示提供“撤销”（把这条新笔记移到回收站）与“固定到首页”；访客与会话失效（401）时不可用        |
| `Tab`              | 保持浏览器默认焦点移动，不被搜索框占用                                                                                                                                 |
| `↑` / `↓`          | 在选项序列中移动，首尾循环并跨分组不中断；建议列表关闭时不响应                                                                                                         |
| 以 `/` 开头        | 列出命令与引擎前缀。选中后回车：动作类命令立即执行；引擎前缀与 `/ai` 把输入替换为“前缀 ”等待关键词                                                                     |
| `Escape`           | 先关闭建议列表，焦点保留在输入框；建议已关闭时才交给 Escape 层栈：打开的菜单、弹窗先于 AI 回答卡片关闭，其次才是卡片（流式中同时中止请求）；见[回答卡片](#ai-回答卡片) |
| 输入法合成中       | 以上按键一律不响应（含方向键、Enter、`Shift+Enter`、`Alt+Enter`、Escape）；兼容合成结束后仍带 `keyCode=229` 的选字回车同样不提交                                       |

“未选中建议”时的 `Enter` 没有例外：输入 `/settings`、`/g`、`/ai` 这类仅有命令名的文本同样按字面用默认引擎搜索，要执行命令必须先选中它。唯一的显式语法是“引擎前缀 + 关键词”：`/g 关键词` 等以该引擎搜索关键词（并把默认引擎切换为该引擎），`/ai 问题` 把问题交给 AI。

### 命令

命令以 `web/src/features/shortcuts/shortcut-catalog.ts` 的 `SEARCH_QUICK_COMMANDS` 为唯一 catalog，设置页说明消费同一份 catalog。动作命令包含主题（`/light` `/dark` `/system`）、壁纸（`/wallpaper`）、设置（`/settings`）、快捷键（`/shortcuts`）、回收站（`/trash`）、笔记（`/notes`，直达笔记面板）、应用（`/apps`，直达应用面板），另有引擎前缀 `/g /b /ba /d` 与 `/ai`。按前缀或动作名称过滤；动作执行后清空输入并关闭建议。访客不显示账号命令，没有可用模型时不显示 `/ai`。

### AI 回答卡片

“问 AI” 行、`Alt/Option+Enter` 与 `/ai 问题` 不跳转页面：问题交给默认模型，答案流式显示在搜索框正下方的卡片里（首页内容随之下移）。输入框保持原文与焦点，可改写后再次提问，新问题替换旧卡片并中止仍在进行的请求。

- **数据与流**：沿用 Ask 的会话与流式接口（`POST /api/ai/chat/stream`，客户端为 `features/ask/useAskStream`），每次提问是一个普通会话（历史开启），启用 `documents` 工具，服务端配置了 SearXNG 时同时启用联网搜索。卡片不另建流式实现，也不保存第二份历史。
- **来源**：卡片底部“参考来源”，个人笔记（标记“笔记”，点击在笔记面板打开）排在网页之前，各自保持引用顺序，同一笔记或网址只列一次；Ask 页消息中的来源使用同一排序。
- **状态**：等待首个字时显示“正在查找笔记并生成回答…”；流式中 `aria-busy`，状态区用 polite 播报开始与结束，不逐字播报；失败显示 alert 与原因，中断提示展开后可继续。
- **关闭**：右上“关闭回答”按钮或 `Escape`。流式中关闭会中止请求（服务端把已生成部分保存为“中断”），已写入的内容保留在 Ask 历史；关闭后焦点回到搜索框。退出登录、模型被移除时卡片随之关闭。
- **Escape 层级**：建议列表（输入框自己处理并 `preventDefault`）→ 打开的菜单 / 弹窗（overlay 层）→ 回答卡片（host 层，由 `useEscapeLayer` 注册）。每次 Escape 只关闭其中一层；输入法合成中不响应。
- **展开**：卡片完成（含中断、失败）后“展开”可用；流式中禁用，避免展开后请求被丢弃。展开按[共享元素过渡](design/VISUAL_LANGUAGE.md#动效)进入 `/ask/:id`：每次生成唯一的 `view-transition-name`，卡片是旧快照的唯一 source，Ask 对话工作区（`[data-shared-target="ask-conversation"]`）是新快照的唯一 target，路由更新以 `flushSync` 提交；减少动态效果时同时长（`--motion-panel`）纯透明度交叉淡入，不插值尺寸与位置；不支持 View Transitions 时立即切换。展开后焦点进入输入框，对话历史取自服务端，与卡片中的问题、答案、来源逐项一致。
- **返回**：从 `/ask/:id` 回到首页（顶栏标志、浏览器后退）后焦点落在搜索框；首页不保留卡片。

### 其他

- 网页联想失败时显示“在线联想暂不可用”，本地历史、应用与个人结果保持可用。
- 网页联想的 `GET /api/search/suggestions` 通过可选 `language` 参数指定界面语言（BCP 47 标签，最多 64 字符）；省略时回退为 `zh-CN`。首页使用当前界面语言（文档语言），语言规范化后传给上游 Google / Bing，避免依赖上游默认市场与混入其他语言结果。
- 搜索框为空或仅有空白时，聚焦不会打开建议列表；输入 `/` 后仍可选择命令。笔记和应用也可通过任务栏进入。
- 粗指针（触屏）下搜索按钮与建议选项使用 44px 点击目标。
- 未选中建议时，`aria-activedescendant` 为空；选中项随结果刷新保持，所选项消失时回到未选中。

## 捕获入口

快速记录有两个入口，共用同一流程（创建未归档、未固定到首页、非收藏的笔记，提示提供“撤销”与“固定到首页”，见[键盘](#键盘)中的 `Shift+Enter`）：

- 首页搜索框 `Shift+Enter`：正文为输入内容，无标题。
- 系统分享：安装 Searcher（[部署 · Service worker](deployment.md#service-worker-与离线外壳)）后，它出现在系统分享面板中。manifest 的 `share_target` 以 GET 打开 `/share?title&text&url`，不使用 POST，因此不绕过 API 的 Origin 检查。
  - 标题为分享的页面标题（超过 200 字符截断）；正文为 URL，空一行后接附带文本。只有 `text` 且它本身是网址时作为 URL；文本中重复的 URL 去除。三项全空时不记录，直接回首页。
  - `/share` 立即以 replace 离开，参数不留在地址栏与历史中；页面 `referrer` 策略为 `strict-origin`，任何请求的 Referer 都不携带路径与参数。
  - 已登录：回到首页并记录，提示与 `Shift+Enter` 相同。
  - 未登录：分享内容只暂存在当前标签页的 `sessionStorage`，不发往服务器；跳转登录（`next=/share`），登录后回到 `/share` 取出暂存并记录。放弃登录时不产生任何服务端数据，暂存在下次 `/share` 时覆盖，关闭标签页即清除。

## 任务栏

- **范围与视觉**：登录后在首页、应用面板、笔记面板及 AI 问答页持续保留；账户、设置、后台、回收站等独立页面不显示。六个系统入口“首页、应用、笔记、AI 问答、设置、回收站”默认全部展示，可各自设置是否在任务栏中展示，并可组内排序；具体常用应用作为独立组加入，两组不混排（系统入口在前、常用应用在后）。任务栏维持现有材质与尺寸样式，系统入口与常用应用图标下均不显示可见文字，保留无障碍名称与桌面悬浮提示。
- **默认与停靠**：首次默认展开并展示六个系统入口，不复制已有首页固定项。桌面支持四边停靠，默认底部；窄屏（<768px）统一底部，不覆盖桌面方向设置。任务栏定位、应用滚动轴与内容及浮层避让共同使用该实际方向。
- **展开与悬浮球**：所有登录用户始终可通过任务栏选项菜单的“收起”手动收起为悬浮球（首次默认展开，不再区分“常驻 / 可收起”展示模式，也不在栏尾重复展示独立减号按钮）。球可拖动并吸附左右边缘，位置限制在可见安全范围；点击后回到配置的停靠位置展开。不提供悬停、空闲或点击外部自动收起。
- **固定与排序**：应用在首页或应用管理面板的菜单中选择“固定到任务栏 / 取消任务栏固定”，或直接在任务栏应用菜单中选择“取消任务栏固定”；取消任务栏固定不会删除应用，也不影响“固定到首页”及应用库 `sortOrder`。同一应用可同时固定到两处。只支持具体应用，不固定文件夹或单篇笔记。移到回收站清除任务栏固定，恢复后不自动重新固定。
- **操作**：组内排序与取消固定直接在任务栏本体完成；操作区与前序入口之间以细线分隔。桌面保留直接拖拽与右键菜单（左 / 右纵向停靠时移动文案随方向显示为“向上移动 / 向下移动”，上 / 下横向停靠为“向左移动 / 向右移动”；固定应用另提供在当前或新标签页打开与“取消任务栏固定”）。手机长按后移动进入组内拖拽排序，长按静止松开打开操作菜单，短按正常打开，提前滑动正常滚动；手机菜单为系统入口与应用提供无需拖拽的“向左移动 / 向右移动”，为应用提供“取消任务栏固定”，同时保留键盘无障碍排序与操作。
- **容量**：单行排列，常用应用区按任务栏方向滚动；窄屏空间不足时系统入口组可水平滚动，选项按钮仍可达。常用应用区溢出时，任务栏选项菜单列出固定应用供直接查找、打开与操作，不缩小命中区、不造成整页横向溢出。
- **避让**：展开时预留内容空间，手机底部计入安全区，避免遮住列表末项和 AI 输入框；收起后释放空间。手机软键盘打开或笔记明确进入全屏编辑时隐藏任务栏与球，结束后恢复。真正的模态弹窗阻断任务栏操作。
- **保存与迁移**：系统入口显示状态、固定内容、系统与应用组内顺序按账号同步。旧账号按原四项相对顺序保留并追加默认可见的设置和回收站，原隐藏项与固定应用不变；读取不主动改写数据库，下一次有效任务栏写入保存完整六项。停靠方向、展开状态（`collapsed`）、球的位置按账号保存在当前设备本地；手机底部布局不反向改写桌面方向。读取旧版设备本地布局时，原 `mode: "fixed"` 自动迁移为 `collapsed: false`，原 `mode: "collapsible"` 或无 `mode` 结构保留既有 `collapsed` 值与其余本地数据。
- **管理与快捷键**：任务栏选项菜单可见文案为“管理”与“收起”。“管理”弹窗仅保留桌面位置（上 / 下 / 左 / 右）和六个系统入口的可见性开关；“设置 → 外观”不再重复提供任务栏配置区。`Mod+.` 展开并聚焦任务栏当前入口，不再打开旧聚合视图。

## 应用与笔记工作面板

### 呈现与内容

| 宽度   | 呈现                                                           |
| ------ | -------------------------------------------------------------- |
| ≥768px | 首页右侧非模态面板，无遮罩，首页保持可交互；编辑笔记时可展开   |
| <768px | 接近全屏的非模态工作面板，底部避让任务栏；有明确的返回首页入口 |

- 应用与笔记直接进入各自完整管理视图，不再显示“资料库”根视图或 AI 对话列表中转。AI 历史由 AI 问答页统一管理。
- 面板使用 Overlay 实色，首页壁纸不改变、不压暗、不缩放；可覆盖搜索框，但不覆盖任务栏。
- 标题栏包含当前功能标题、至多一个主操作和“返回首页”。笔记编辑器内部返回“笔记”或上一级，不经过聚合总览。
- 应用保留全部应用与文件夹、搜索、编辑、归组、首页固定与文件夹管理；管理网格不受首页容量限制，应用库排序仍在首页整理。任务栏排序是独立偏好。
- 笔记保留全部 / 最近 / 首页 / 收藏筛选、笔记本、搜索、创建与编辑，见 [笔记](documents.md)。

### 导航、关闭与状态

- `/?view=apps` 与 `/?view=notes` 分别表示应用和笔记面板；`/` 为首页；`/ask` 与 `/ask/:id` 为 AI 工作区。任务栏及原“更多”入口、搜索命令直接进入对应功能。
- 功能切换使用浏览器历史；首页 → 笔记 → 应用后，返回依次回到笔记和首页。重复点击当前入口不关闭、不重置内容；展开、收起和排序不增加历史。
- 切换尽量保留当前筛选、搜索和滚动位置。退出登录或切换账号清空当前账号的面板与编辑状态，不能泄漏到下个账号。
- **未保存保护**：切换功能、返回上一级、返回首页、Escape 与浏览器返回均不能绕过编辑器或应用表单的未保存保护；取消后保持原状。
- **焦点与 Escape**：打开面板后焦点进入标题栏；返回笔记列表恢复触发控件和滚动位置，关闭后回到入口，入口不存在时回到搜索框。Escape 每次只关闭一层：菜单 / 弹窗 → 笔记内部编辑页 → 工作面板。输入法合成中不响应。
- 笔记明确进入全屏后隐藏任务栏及悬浮球，提供退出按钮，桌面可用 Escape 退出；退出后恢复原任务栏状态。

转场与材质见 [Visual Language](design/VISUAL_LANGUAGE.md)。

## 撤销与反馈

- 应用移至回收站，或首页笔记移至回收站后，按账号提供 10
  秒撤销窗口：提示展示名称，支持逐项与批量撤销，并链接到回收站。悬停或聚焦提示时暂停计时；菜单或弹窗打开时暂停并暂藏提示，关闭后继续剩余时间。
- 撤销失败时保留对应项目与错误信息，允许重试；长名称换行，不超出视口。
- Ask 会话删除保留 5 秒撤销，见 [AI](ai.md)。

## 快捷键

搜索、AI 问答、笔记编辑的快捷键与搜索快捷命令统一列在“设置 → 快捷键”
（`/settings/shortcuts`），无需登录即可查阅，按当前平台展示键位与生效上下文。编辑器
本地操作优先于首页聚焦搜索；不提供快捷键自定义或同步。优先级依次为：局部可编辑控件 >
当前页面或工作面板 > 首页全局 > 浏览器默认。首页全局快捷键不在
input、textarea、select、contenteditable 或 `role="textbox"`
中触发；已被处理的事件与输入法合成期间不执行快捷键。Ask 的会话内查找保留页面级
composer 语义，离开 Ask 后不拦截浏览器查找。方向键、Escape、Enter、Tab、Space
等导航键不列为产品快捷键。macOS 使用 Command，其他平台使用 Ctrl。

Escape
通过统一层栈一次只消费最上层的菜单、弹窗、笔记编辑页或工作面板，不误关下层；优先级为浮层、Host，输入法合成中不分发，注销的层不穿透到
window。焦点归还规则见 [前端 · 可访问性契约](frontend.md#可访问性契约)。

开发维护：

- 通用 binding 与命令 target 在
  `web/src/features/shortcuts/shortcut-catalog.ts`。
- 业务组件保留事件处理归属，说明页消费各自的同一 catalog。
