# 移动端极简空间：无容器便签展示实施计划

状态：已实现并完成验收，关联
[Issue #191](https://github.com/aawai/searcher/issues/191)。实际验证记录见 Issue
与对应 PR 描述。

## 目标与设计依据

按本次对话最终效果图实现移动端 Zen
首页便签：取消卡片外框，让一张便签的内容自然融入首页；只在固定到首页的便签之间手动切换。搜索仍是第一视觉与操作焦点。

最终效果图是构图参考，不是像素规范：采纳无容器内容、共享中轴、轻量位置标记；不修改应用启动器的图标对齐与网格逻辑，不复制合成图的固定坐标、背景拼接、文字大小与页脚裁切。正文不能因追求对称而全部强制居中。

现有依据：

- 原设计原则文档（现并入
  [Visual Language](../design/VISUAL_LANGUAGE.md)）：Search-first、Content
  before chrome、Semantic spacing、Shared geometry、Restrained motion。
- 原设计系统文档（现并入 Visual Language）：Notes、Token taxonomy、Surface /
  elevation、Workspace semantic surface。
- `web/src/features/home-layouts/ZenLayout.tsx`：当前首页固定便签复用
  `FloatingNotes`，打开便签调用 `editNote`。
- `web/src/app/SearchHome.tsx`：`fixedNotes` 已由
  `currentNotes.filter(note => note.isHomeFixed)` 派生。
- `web/src/features/workspace/NotesWorkspace.tsx`：已有 `isHomeFixed` 操作，且与
  `isPinned` 分开。
- `web/src/features/home-layouts/noteOrder.ts`：已有 canonical
  `sortOrder ASC, id ASC` 排序约定。

## 范围与非目标

- 新展示仅用于 Zen 移动首页（沿用现有 `<768px` 移动边界），不扩展到 Widgets
  或桌面 Zen。
- 搜索、应用网格、便签形成共享中轴；底部导航居中属于本次必要关联布局修改；应用图标保持既有流式排列，不改动网格内部逻辑。
- 不移动现有 Search anchor，不重构全局导航、壁纸系统、Markdown
  编辑器或桌面便签画布。
- 不新增后端字段、数据库迁移、跨设备“当前页”偏好或设置页。
- 不修改
  `isPinned`、`isHomeFixed`、便签排序与颜色的业务含义；预览不采用彩色纸卡，不删除便签原有颜色数据。
- 固定、移除、排序、颜色、删除仍在现有工作区管理，首页不新增管理工具栏。

## 锁定的展示与交互契约

### 固定集合与当前项

1. 数据只来自 `isHomeFixed === true` 的便签；普通置顶便签不自动加入。
2. canonical 顺序为
   `sortOrder ASC, id ASC`；编辑内容或更新时间不触发重排，不通过首页滑动写回排序。
3. 首次进入显示集合第一张；恢复本设备、当前账号上次浏览且仍有效的便签 ID。
4. 当前项以 ID 而非数组下标追踪。重新排序后保留当前
   ID；删除或从首页移除当前项时选择原位置的下一项，无下一项则选上一项。
5. 恢复时若记录已失效则回到第一张；集合清空时移除展示及位置标记，不留空白占位。
6. 当前项只属于本设备账号视图状态，按账号命名空间持久化；复用现有账号本地存储约定，不写入账号外观偏好或
   `note_layouts`。存储不可用时使用内存状态，不阻断阅读。
7. 退出或切换账号立即清除内存中的当前项与内容，另一账号不能看到前一账号预览；匿名状态不挂载便签内容。

### 阅读与切换

- 一次只展示一张；左右滑动只切换固定集合，首尾停止，不自动播放、不无限循环。
- 点击内容通过现有 `editNote` 进入现有 Notes editor / 移动
  Sheet；不新增全屏编辑器，不在首页展开正文。
- 滑动触发后不产生点击打开；纵向滚动、取消手势、多指操作不误翻页，手势只作用于便签区域。
- 同一视口与字体设置下，切换便签不改变预览区高度，不使应用区、Search
  或底部导航跳动；字体缩放、横竖屏及可用宽度变化可以重新布局。
- 只有一张时无位置标记、无翻页行为；零张时整个便签区域不占空间。
- 两张及以上时仅保留不可点击的位置标记；无
  `1 / 3`、下拉按钮、分页选择面板、箭头、常驻“查看全文”。多张时标记采用有限可见数量的连续窗口，首尾与当前项映射准确，不形成随便签数量无限增长的一排圆点。
- 便签区域可键盘聚焦，左右方向键切换，Enter
  打开当前便签；范围限制在该区域，不截获 Search 或编辑器按键。
- 屏幕阅读器可获得区域名称、当前便签标题和当前位置。提供仅辅助技术可见的上一张/下一张操作，使用现有控件
  primitive；非活动项不进入 Tab 顺序或重复朗读。
- reduced-motion
  下取消翻页位移动画；正常模式只做用户触发的有限过渡，不新增环境循环动效。

## 设计语言与内容规则

### 新系统语义：Zen inline note preview

该语义属于 secondary content，是透明的正常流内容预览，不是新的
surface/elevation，也不是新 Card 变体。由 home-layouts
拥有布局与交互，复用现有文字、间距、焦点与动效规范。

- 无背景板、外边框、阴影、圆角纸张、折角、分隔线、常驻菜单、图钉或编辑工具栏。
- 标题消费现有 component title role，正文消费 body
  role；不另造字体、字号体系，不用低对比正文伪装轻盈。
- 默认文字消费现有主题前景色；弱化限于次要位置标记，标题和正文保持可读对比。
- Search、应用网格、便签阅读区域共享水平中轴和响应式外侧安全边距。便签阅读列可比搜索框窄，但必须居中，不能向某侧溢出。
- 应用最后一行按实际数量居中；保留应用 canonical
  顺序、图标尺寸、触摸目标与管理态拖拽语义。不用占位应用、负间距或伪内容凑对称。
- 底部导航在移动 Zen
  内整体居中并避让安全区；正文可完整滚至其上方，不以固定屏幕高度裁切内容。
- 间距使用既有 section/row/inline
  Token。确有缺失的预览几何、标记或手势动效值，先命名系统语义、确定唯一 owner
  并写入设计文档，再实现；不得散落 raw visual value 或扩大 guard allowlist。

### 真实内容，而不是只有示例短句

- 短纯文本使用居中排版，适合最终效果图中的短句；只有无结构、无软换行溢出且能保持短行的内容可进入此模式。实际字体与可用宽度变化后重新判定，不用固定字符数假设中英文等宽。
- 长段落、列表和代码摘要在同一居中阅读区域内左对齐，不把每一行或列表标记强制居中。
- 首页只消费只读摘要，不嵌套完整 Markdown 文档滚动。复用既有 Markdown
  解析能力派生安全文本摘要，不用正则直接剥除 Markdown，不复制编辑器 runtime。
- 摘要保留基本段落/列表含义，代码、表格、链接不产生可横向滚动或可独立点击的嵌套内容；截断使用可见省略语义，不隐藏后仍保留可聚焦链接。
- 有标题时显示真实标题；无标题时正文为主，提供辅助技术名称，不强加可见“无标题”。空内容使用简短“空白便签”提示并允许打开编辑。
- 预览预算由共享字体与布局规则约束，不因长文无限撑高，不根据每张内容重新改变窗口高度。
- 不为首页消费引入编辑器依赖；保留无固定便签时不加载预览相关重模块的既有按需加载目标。

### 壁纸与主题

- 浅色、深色都消费同一语义 Token，不固定使用效果图中的浅灰绿或黑色文字。
- 默认背景、系统支持的纯色/渐变与代表性图片壁纸必须实页检查。若系统支持组合下无容器文字无法满足可读性，应在共享
  wallpaper/content Token owner
  解决并重新审阅，不悄悄加回便签卡片、局部黑幕或文字描边。
- 沿用原设计原则文档（现并入 Visual Language）
  对任意自定义高对比图片和最弱干预配置的明确可读性例外；不承诺任意壁纸绝对安全，也不自动改用户壁纸设置。

## 实施中确认的设计细节

- 设备视图状态复用 `DocumentEditor` 的同步 localStorage 范式，仅保存按账号隔离的
  当前便签 ID。生产 E2E 曾复现 IndexedDB 被立即刷新中断的竞态，已删除异步恢复和
  写入路径；相同刷新场景修复后通过，不引入兼容层或服务器字段。
- 轻量 `ZenHomeNotes` owner 等待账号便签加载完成后挂载，即使无固定便签也能清理
  失效视图状态；Markdown 摘要与移动预览仍只在有内容且为移动 Zen 时按需加载。
- 复用 `unified` + `remark-parse` + `remark-gfm` 的纯解析入口；避免 `remark`
  根入口 经 stringify 将 editor-vendor 提前拉入首页。相关依赖版本已在原 lock
  中存在。
- 767/768 切换会卸载移动 opener；关闭编辑器后遵循共享 Host 的既有规则，回退至
  便签工作区入口。未跨断点时恢复原便签内容触发器，不为本功能改变全局焦点契约。
- 标题与正文合并为单一内容组，使用 `--space-inline-gap`（8px）。先前为多行标题
  预留的固定块高已被移除，单行标题不再产生虚空第二行；整体阅读窗口保持稳定高度，
  内容在窗口内自然居中。
