# 窗口内容的刊头排版：实施记录

状态：已实施（方案 A）。现行规则以 [Visual Language · 字号](../design/VISUAL_LANGUAGE.md#字号) 的衬线角色登记为准，本文只保留决定与依据。

## 决定

窗口内部向首页刊头的编辑感靠拢（风格方向修订），取代 2026-10-26 审计计划中“不增加第二套字体”的条件。经 `/design-lab/editorial` 原型对照后选定：

- **方案 A**：窗口内容层的标题改用衬线，字号、字重、行高不变。方案 B（另加 2px 粗线与字距拉伸的分节小标题）未采用。
- **设置 / 账户窗口纳入**：详情页标题与窄宿主下的“设置”标题。
- **字体换入保持现状**：与首页刊头一致，按 `font-display: swap` 换入，不做回退字体度量对齐。

原型在选定后删除。

## 范围

| 表面               | 改变                                   | 保持                                  |
| ------------------ | -------------------------------------- | ------------------------------------- |
| 笔记窗口           | 笔记标题、编辑器 h1–h3，分页与打印同步 | 正文、侧栏条目、工具栏、状态条        |
| AI 窗口            | 空状态标题、窗口内回答的 h1–h3         | 消息正文、composer、会话列表          |
| 设置 / 账户窗口    | 详情页标题与窄宿主的“设置”标题         | 分组列表、分组标题、表单              |
| 窗口外框与全局浮层 | 无                                     | 标题栏、窗口按钮、对话框、菜单、Toast |

边界：

- 正文不用衬线：只打包 600 字重，正文需要 400。
- 共享的 `.markdown` 基础规则不改：`AssistantMarkdown` 同时服务 AI 窗口与首页行内回答卡片，衬线标题由宿主选择器显式开启。
- 登录、注册、404、管理后台与访客设置页不变；回收站窗口没有可见 h1，不涉及。

## 依据

- `@font-face` 声明（101 条，约 102 KB，未压缩）原本就在入口样式里，对所有路由可用；引入位置从 `HomeMasthead.tsx` 移到入口 `web/src/main.tsx`，产物不变。
- 字体共 98 个 WOFF2 切片、约 3.1 MB，单片不超过 55 KB，按字符按需下载。原型页四个样本的标题共触发 10 个切片、约 345 KB。
- 标题与各级标题在两种字体下的行盒高度相同（行高为固定值），换入只影响换行位置。
- 分页在字体就绪后重排，并以 `ResizeObserver` 观察编辑根节点；打印在 `document.fonts.ready` 之后才激活。
