# 便签

便签（`notes`）是短 Markdown
内容，可置顶、固定到首页，与长篇笔记（`documents`，见
[笔记](documents.md)）是独立实体。编辑器 foundation、consumer 与样式契约见
[Markdown Editor](editor/MARKDOWN_EDITOR.md)。

## 首页呈现

### 桌面 Zen

- 固定到首页的便签以浮动便签呈现，可拖动位置、展开或折叠；位置、层级与展开状态随便签布局（`note_layouts`）保存。
- 点击便签在工作区中打开编辑。

### 移动端 Zen（<768px）

- 无卡片外框的单张内容预览，只浏览“固定到首页”的便签，不包含仅置顶的便签；没有固定便签时不显示占位。
- 左右滑动或聚焦后按方向键切换，首尾停止；位置标记不可点击；点击内容进入便签编辑
  Sheet。
- 短句居中；长文和结构化内容显示左对齐的只读摘要，完整内容在编辑器阅读。
- 正文为空时不显示占位预览文字。
- 当前项仅在本设备按账号记忆，不同步至服务器。
- 固定与取消固定等管理操作仍在便签工作区。

## 便签工作区

根视图默认紧凑显示标题、一行正文摘要与更新时间；正文为空时摘要区不显示占位文字。

- 点击标题或按 Enter/Space
  进入编辑；正文选择与滚动不打开编辑器，双击不切换展开。
- 展开/折叠仅由显式按钮控制，拖动仅由把手控制。展开状态只在当前工作区生命周期内有效，
  不参与自动保存，不改变便签版本或首页/Zen 的展开与位置。
- 无搜索词时，“已固定”（置顶或固定到首页的便签）与“其他便签”互斥分组；“其他便签”支持把手拖拽和键盘排序，
  “已固定”及搜索结果不可排序。
- 搜索覆盖全部便签，每条只展示一次，高亮标题/正文匹配；仅 Markdown
  源码命中时仍保留结果并显示源码片段。

便签列表为单列平铺分隔行；紧凑卡片不显示颜色入口与保存状态，颜色与版本历史通过 ⋯
菜单访问。

便签编辑在工作区内嵌套进行：>=768px 为右侧 Panel，<768px 为底部 Sheet。

## 编辑器

默认使用所见即所得 Live Preview，可切换至 textarea 源码模式。

- 打开、切换模式或接受云端正文不改写
  Markdown、不触发保存，只有实际编辑才序列化。
- 两种模式共用格式工具栏和本地快捷键；Live 任务 checkbox
  可编辑，卡片、冲突和历史版本保持只读。
- 长文正文独立滚动；标题、模式、保存状态和单行格式工具栏位于顶部，窄容器通过
  “标题”和“更多格式”访问全部命令；版本历史与颜色位于编辑器的 ⋯“便签选项”菜单。
- 正文最大阅读宽度 720px、最低 240px；短窗口允许整个编辑器滚动。
- 桌面端便签编辑支持“展开编辑”/“收起编辑”，这些几何操作不重建编辑实例。
- 颜色为带名称与选中状态的五项单选，位于编辑器 ⋯“便签选项”菜单与每张卡片的 ⋯
  菜单中；触控入口至少 44px。
- 便签不使用笔记的分页、资产和 outline 插件。

### 保存

- 标题或正文实际修改后等待 1500ms 自动保存；中文组合输入结束后才保存。
- 标题、正文、工具栏之间的焦点移动、标题 Enter
  跳转和模式切换不提前提交，也不重启 debounce。
- 焦点真正移至历史、颜色或外部控件时，仅未保存草稿执行一次手动保存；恢复的本地草稿同样适用。
- Ctrl/Cmd+S 为显式手动保存。关闭、Esc 或切换便签时提交防抖窗口内的待保存内容。
- 进行中保存与后续输入共用队列，不重复提交同一草稿。组合输入中关闭不提交半成品，保留设备草稿供重开恢复。

### 实时同步与冲突

多个便签编辑器在同一账号会话内共用一条 `/api/notes/events` SSE，按便签 ID
分发更新，
等待排队保存结束后再比较版本。最后一个编辑器关闭、退出登录或切换账号时关闭连接，不接收旧账号事件。

- 无本地修改时远端更新静默同步；有未保存修改才提示冲突。
- 冲突对话框与笔记共用（见
  [笔记 · 冲突处理](documents.md#冲突处理)）：对比页签为“本地修改”与“云端版本”。便签额外支持复制草稿，
  或编辑合并内容后确认保存；合并框以本地正文为起点，不预填 Git 冲突标记。

### 设备草稿

设备草稿按当前账号保存为 `note:draft:<userId>:<noteId>`。

- 退出前检查当前账号的未同步草稿并提醒；取消退出不删除草稿，确认退出仍保留，重新登录同一账号可恢复。
  其他账号的草稿不触发该提醒。
- 旧 key `note:draft:<noteId>` 仅在鉴权 API 验证归属后读取/迁移，新 key
  提交成功后才删除旧 key。
  归属或本地存储检查失败时保留数据并显示可重试错误，不静默退出。
- 编辑器恢复检查失败时暂停编辑，可点击“重试恢复草稿”。
- 会话失效后不再启动保存请求，迟到响应不更新新会话。

降级前必须备份 IndexedDB 原 key
和完整值，并转换当前账号已验证归属的新格式草稿；旧版本无法发现新 key。
转换、冲突保留与失败停止步骤见
[Markdown Editor](editor/MARKDOWN_EDITOR.md#设备草稿与降级)。

### 版本历史

版本历史为编辑器内部子视图。

- 进入前等待当前草稿保存及在途请求；保存失败或版本冲突时留在编辑。
- 展示版本号、绝对本地时间、标题与完整只读预览。
- “返回编辑”或 Escape 恢复原焦点、选区和滚动；Host 返回按钮仍返回便签列表。
- 恢复需要确认，将标题和正文替换为选中快照；取消不写入，成功使用服务端返回版本，
  失败保留当前草稿与预览供重试。
