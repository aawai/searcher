# 笔记

笔记（`documents`）是唯一的 Markdown 实体，带笔记本、图片资产、纸张设置与版本历史。
固定到首页的笔记以纸张形态呈现（见 [首页纸张](#首页纸张)）；不存在独立的便签实体、
路由、搜索或 API。所有功能需要登录。

## 入口与 Host

登录后的“笔记”入口复用 Workspace Host（形态见
[首页与工作区](workspace.md#工作区呈现)）。点击标题或创建笔记后打开编辑器：

| 宽度    | 编辑器呈现                   |
| ------- | ---------------------------- |
| >=768px | 工作区右侧 Panel，编辑时展开 |
| <768px  | 底部 Sheet                   |

保存后同步列表摘要；移至回收站会关闭该笔记的编辑视图。

## Library

- 视图：全部 / 最近 / 收藏、笔记本筛选、跨笔记本搜索与加载更多。
- 笔记操作：新建、重命名、收藏、固定到首页、移动、移至回收站；颜色与纸张相关操作位于 ⋯ 菜单。
- 固定到首页的笔记在列表中显示首页标记；非默认颜色的笔记在行首显示色点。
- 笔记本最多两层，可创建、重命名、移动、同级上移/下移；删除笔记本保留笔记并将子笔记本提升为根。
- 布局：宽度 <640px 为单列，导航与列表切换；≥640px
  为内侧栏加列表。主操作为“新建笔记”；笔记本的创建与行操作为次级操作。

### 展示标题

DTO 的 `displayTitle` 是服务端派生展示值，依次取：trimmed `title` → 首个非空
heading/paragraph 的纯文本前 100 字 → “无标题笔记”。

- `title` 可为空，仍为 canonical 字段，不回写 fallback。
- 列表和搜索只返回摘要，不返回正文。无标题记录的派生在服务端读取正文；已有标题的列表记录只读取正文前
  300 字生成 snippet。

## 首页纸张

固定到首页（`isHomeFixed`）的笔记在首页搜索框下方以不透明纸张呈现。呈现只由
`isHomeFixed` 决定，与正文长度无关；未固定的笔记只出现在笔记库、搜索与 AI 引用中。
同一笔记可以同时固定到首页、插入图片并使用分页。

- **尺寸**：展开为 220×220；折叠时只显示标题的固定高度条。
- **颜色**：`color` 取 `paper`、`amber`、`rose`、`sage`、`sky` 之一，默认 `paper`。颜色为带名称与选中状态的五项单选，位于笔记的 ⋯ 菜单与编辑器的 ⋯ 菜单中；触控入口至少 44px。
- **位置与排序**：纸张可拖动，也可通过鼠标、触控或键盘排序。位置、层级与展开状态保存在首页布局中，以笔记 ID 为键，刷新及重新登录后保持。未定位的纸张默认放在画布右侧，避开搜索框。
- **展开与折叠**：仅由纸张上的显式控件切换，状态随首页布局保存。
- **标题与正文**：纸张标题使用 `displayTitle`。纸张只显示正文的只读预览；正文超出时隐藏滚动条并在被隐藏的一侧渐隐，滚轮、触摸与键盘仍可滚动。完整内容在编辑器中阅读，点击纸张打开编辑。
- **直接勾选**：纸张上的任务列表 checkbox 可直接勾选，并与编辑器使用同一保存队列与冲突处理。
- **管理操作**：取消固定、颜色、收藏与删除在笔记库及 ⋯ 菜单中完成。纸张移至回收站后，首页提供 10 秒撤销窗口（见 [撤销与反馈](workspace.md#撤销与反馈)）。
- **实时同步**：首页纸张与编辑器共用同一事件流，远端更新见 [实时同步与冲突](#实时同步与冲突)。

### 移动端 Zen（<768px）

- 无卡片外框的单张内容预览，只浏览固定到首页的笔记；没有固定笔记时不显示占位。
- 左右滑动或聚焦后按方向键切换，首尾停止；位置标记不可点击；点击内容进入笔记编辑 Sheet。
- 短句居中；长文和结构化内容显示左对齐的只读摘要，完整内容在编辑器阅读。
- 正文为空时不显示占位预览文字。
- 当前项仅在本设备按账号记忆，不同步至服务器。
- 固定与取消固定等管理操作在笔记库中完成。

## 编辑

编辑、分页和 Markdown 源码三种视图共用一份 Markdown 正文；编辑与分页共用同一
editor、选区和 undo history，只改变排版。编辑视图默认为所见即所得（Live Preview）。
视图偏好仅在当前设备按账号与笔记隔离。

- 标题单独保存，不自动插入 H1。
- 长文正文独立滚动；标题、模式、保存状态和格式工具栏位于顶部，窄容器通过“标题”和“更多格式”访问全部命令。编辑视图正文最大阅读宽度 720px、最低 240px；短窗口允许整个编辑器滚动。
- 格式工具栏支持标题、强调、列表/任务、引用、链接、代码、表格、分隔线、分页符与图片。工具栏只有一个
  Tab 入口，方向键切换按钮，格式状态可由读屏读取；移动端保持单行横向滚动。
- 大纲在编辑/分页视图显示，点击定位正文光标。
- 纸张设置、打印、复制、导出与颜色、固定到首页等操作位于“更多笔记操作”。
- 字数按 CJK 字符和英文/数字单词统计，排除 Markdown 语法；阅读时间按每分钟 300
  字/词向上取整。

### 保存

- 标题或正文实际修改后 1500ms 自动保存，中文组合输入结束后才保存。
- 标题、正文与工具栏之间的焦点移动、标题 Enter 跳转和模式切换不提前提交，也不重启防抖。焦点真正移至历史、颜色或外部控件时，仅未保存草稿执行一次手动保存。
- Ctrl/Cmd+S 为显式手动保存。关闭、Esc、切换笔记或离开编辑区域时提交防抖窗口内的待保存内容。
- 进行中保存与后续输入共用队列，不重复提交同一草稿。组合输入中关闭不提交半成品，保留本地草稿供重开恢复。
- 网络失败时保留 IndexedDB 本地草稿，重开可恢复或放弃；本地草稿与云端版本不一致时须显式解决冲突。
- 历史恢复创建新版本，不倒退版本号。

### 设备草稿

- 本地草稿保存在设备 IndexedDB，按账号与笔记隔离。笔记编辑与首页纸张使用同一份草稿。
- 退出前检查当前账号的未同步草稿并提醒；取消退出不删除草稿，确认退出后重新登录同一账号可恢复。其他账号的草稿不触发该提醒。
- 草稿恢复检查失败时暂停编辑，可点击“重试恢复草稿”。
- 会话失效后不再启动保存请求，迟到响应不更新新会话。
- 升级前的便签草稿（旧 `note:draft:*` 键）不再读取，也不迁移为笔记草稿；升级后这些旧键会被清理。升级前请在旧版本中确认便签已保存。

### 版本历史

版本历史为编辑器内部子视图。

- 进入前等待当前草稿保存及在途请求；保存失败或版本冲突时留在编辑。
- 展示版本号、绝对本地时间、标题与完整只读预览。
- “返回编辑”或 Escape 恢复原焦点、选区和滚动；Host 返回按钮仍返回笔记列表。
- 恢复需要确认，将标题和正文替换为选中快照；取消不写入，成功使用服务端返回版本，失败保留当前草稿与预览供重试。

### 冲突处理

有未保存修改的编辑器收到远端更新时，409 冲突对话框在“本地修改”与“云端版本”两个页签间对比：

- “用云端版本”“用我的版本”须通过独立二次确认弹窗，说明将丢弃的本地修改或被覆盖的云端版本。
- “另存副本”不需要二次确认。
- “编辑合并内容后保存”打开合并框，以本地正文为起点，不预填 Git 冲突标记；确认后保存。
- “暂不处理”（Esc 同效）关闭弹窗、不修改任一版本；冲突可从编辑器头部“处理冲突”重新打开。
- 失败时显示错误并保留本地修改。

### 实时同步与冲突

同一账号会话内的笔记编辑器与首页纸张共用一条 `/api/documents/events` SSE 连接，按笔记 ID 分发
`document.updated` 事件。编辑器等待本地排队保存结束后再比较版本，必要时读取最新笔记；事件本身不是完整 DTO。
最后一个订阅者关闭、退出登录或切换账号时关闭连接，不接收旧账号事件。

- 无本地修改时远端更新静默同步；有未保存修改才提示冲突。
- 自己保存产生的广播与过期版本不触发冲突。

### 图片

- 支持 PNG/JPEG/WebP，最大 10 MiB；上传成功后才插入 `asset://<assetId>`。
- 复制与 `.md` 导出保留正文原文及 internal asset
  ref，不附加标题，不是可独立移植的图片包；完整资产须通过数据库备份保留。

### 分页、纸张与打印

- 分页视图的纸张自上而下居中排列，使用正文外层的同一个滚动区；跨页编辑、选区及撤销属于唯一编辑器。
- 窄窗口和移动端统一缩放纸张，不改正文 Token，不保留横向滚动 strip。
- 自动分页不写回 Markdown；切换纸张或视图不会把自动断页写进正文。手动
  `<!-- pagebreak -->` 保留首部、连续和末尾空白页。
- 纸张设置支持 A4/Letter、横向/纵向和四边 5–50 mm 边距，按笔记保存到服务器。
- 打印使用独立的无应用 chrome
  排版，标题仅在首个非空白页出现；正文、图片、代码、表格和手动分页参与打印，
  自动分页由浏览器决定，不承诺与编辑视图逐像素一致。

## API

所有 `/api/documents*`、`/api/document-notebooks*` 请求需要登录；跨 owner
与不存在均返回 404。

### 实体字段

- `color`：`paper` | `amber` | `rose` | `sage` | `sky`，默认 `paper`。
- `isHomeFixed`：是否固定到首页。
- `homeSortOrder`：首页纸张排序。
- `title` 可为空（nullable）；展示使用 `displayTitle`。
- summary 与 detail DTO 均包含 `color`、`isHomeFixed`、`homeSortOrder`。
- `POST /api/documents` 与 `PATCH /api/documents/:id` 接受 `color`、`isHomeFixed`、`homeSortOrder`；`POST` 另接受 `isFavorite`。

### 列表与搜索

| 方法 | 路径                                                                                            | 说明                                                           |
| ---- | ----------------------------------------------------------------------------------------------- | -------------------------------------------------------------- |
| GET  | `/api/documents?scope=all\|recent\|favorite\|notebook\|home&notebookId=...&limit=50&cursor=...` | 列表；`scope=home` 为固定到首页的笔记，按 `homeSortOrder` 排序 |
| GET  | `/api/documents/search?q=...`                                                                   | 搜索；空搜索返回空列表                                         |
| GET  | `/api/documents/trash`                                                                          | 回收站                                                         |

三者返回 `{ items, nextCursor }`，每项仅包含 summary，不返回完整 body。`limit`
为 1–100；cursor 绑定 user/scope 或 query。

搜索与 AI 的 `lookup_documents` 共用同一份全文索引，覆盖当前用户全部未删除的笔记（含固定到首页的笔记）。

### 事件流

| 方法 | 路径                    | 说明                                                                                                                         |
| ---- | ----------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| GET  | `/api/documents/events` | SSE；连接建立后先发送具名 `ready`（`{ ok: true }`），之后发送具名 `document.updated`（`documentId`、`version`、`updatedAt`） |

### 首页布局

布局按设备类别（`deviceClass`：`desktop` | `tablet` | `mobile`）与笔记 ID 保存，不需要内容 `version`。

| 方法  | 路径                                        | 说明                                                                                             |
| ----- | ------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| GET   | `/api/documents/:id/layout?deviceClass=...` | 返回 `DocumentLayoutDto`，无布局时为 `null`                                                      |
| PATCH | `/api/documents/:id/layout?deviceClass=...` | body 为 partial `{ deviceClass, x, y, width, zIndex, expanded, sortOrder }`；返回更新后的 layout |

### 实体与生命周期

| 方法        | 路径                                           | 说明                                                                              |
| ----------- | ---------------------------------------------- | --------------------------------------------------------------------------------- |
| POST        | `/api/documents`                               | 创建；可提交 `color`、`isHomeFixed`、`homeSortOrder`、`isFavorite`                |
| GET / PATCH | `/api/documents/:id`                           | 读取 / 更新；PATCH 必须提交当前 `version`，冲突返回 409 与 `data.currentDocument` |
| DELETE      | `/api/documents/:id?version=N`                 | 软删除                                                                            |
| POST        | `/api/documents/:id/restore`                   | 从回收站恢复                                                                      |
| DELETE      | `/api/documents/:id/permanent`                 | 永久删除，级联清理资产                                                            |
| GET         | `/api/documents/:id/versions`                  | 版本历史                                                                          |
| POST        | `/api/documents/:id/versions/:version/restore` | 恢复历史版本；body 提交当前 `version`，创建新版本、不回滚计数                     |

- `title` 最大 200 characters，Markdown body 最大 1,000,000
  characters，create/update JSON 请求最大 8 MiB；超限拒绝、不截断。
- 内容变化的 autosave snapshot 间隔 10 分钟，每篇笔记仅保留最近 100 个；`manual`
  / `conflict_resolution` / `restore` / `system` 快照不参与清理。title/body
  未改变不生成内容快照。

### 笔记本

| 方法           | 路径                               |
| -------------- | ---------------------------------- |
| GET / POST     | `/api/document-notebooks`          |
| PATCH / DELETE | `/api/document-notebooks/:id`      |
| POST           | `/api/document-notebooks/:id/move` |
| PUT            | `/api/document-notebooks/reorder`  |

最多两层，允许同名。删除不删除笔记：直接笔记转为未分类，子笔记本提升为
root。排序提交目标 parent scope 的完整 ids。

### 图片资产

| 方法         | 路径                                          |
| ------------ | --------------------------------------------- |
| POST         | `/api/documents/:id/assets`（multipart file） |
| GET / DELETE | `/api/documents/:id/assets/:assetId`          |

- 仅 PNG/JPEG/WebP，校验 MIME 与 magic bytes，最大 10 MiB。
- 读取同时校验 document/asset/owner；正文仍引用的资产不能直接删除。
- bytes 存于 SQLite BLOB，`storage_ref`
  不公开；软删除保留资产，永久删除级联清理。

### 纸张设置

`GET/PUT /api/documents/:id/settings`：仅同步
`a4`/`letter`、`portrait`/`landscape` 与四边 5–50 mm margins（默认 20
mm）；不保存 view、sidebar、outline 等设备 UI 状态。
