# 笔记

笔记（`documents`）是唯一的 Markdown 实体，带笔记本、图片资产、纸张设置与版本历史。
固定到首页的笔记排进首页刊头（见 [首页刊头](#首页刊头)）；不存在独立的便签实体、
路由、搜索或 API。所有功能需要登录。

## 入口与笔记窗口

登录后，从任务栏“笔记”、首页刊头、“继续”、搜索建议与 `/notes`（即 `/?view=notes`）直接打开[笔记窗口](workspace.md#应用与笔记窗口)（`data-window-id="notes"`），不经过资料库总览。窗口标题在标题栏，桌面默认 960×720。
笔记窗口始终呈现侧栏与编辑区，不再有独立列表页；没有选中笔记时编辑区提示“选择或新建笔记”。布局按窗口实测宽度而非视口选择：

| 窗口宽度                               | 侧栏         | 大纲                 |
| -------------------------------------- | ------------ | -------------------- |
| <768px                                 | 窗口内左抽屉 | 窗口内右抽屉         |
| 768px ≤ W < `BREAKPOINTS.notesSidebar` | 窗口内左抽屉 | 右侧栏或右缘 Overlay |
| ≥ `BREAKPOINTS.notesSidebar`           | 常驻，可折叠 | 右侧栏或右缘 Overlay |

标题栏只有标题、全屏与窗口按钮，不再有侧栏开关、返回、创建或管理笔记本按钮。常驻侧栏在搜索行右端有折叠按钮（`PanelLeftClose`），折叠后编辑器标题行最左侧出现展开按钮（`PanelLeftOpen`，位于标题输入框之前）；抽屉模式用同一位置的按钮打开抽屉，抽屉内以遮罩点击、Escape 关闭。按钮的 `aria-label="笔记侧栏"`、`aria-expanded`、`aria-controls="notes-sidebar"` 保持不变，折叠 / 展开后焦点移到对侧可见的按钮。没有选中笔记、加载中或加载失败时渲染只含该按钮的最小标题行。常驻侧栏的折叠偏好按设备和账号保存；抽屉不记忆，恢复结果为空时自动打开，选中或新建笔记后关闭，最小化保留开合，关闭窗口重置。打开已有笔记不自动聚焦标题：常驻侧栏保留树焦点，抽屉关闭后焦点返回标题行按钮；新建笔记聚焦标题。抽屉限制在窗口内容区，编辑区不可交互，点击编辑区关闭抽屉。

常驻侧栏和 ≥768px 的大纲可拖动边界调整宽度（180–400px，默认分别为 240px 和 260px）；左右方向键每次调整 16px，Home / End 到边界，双击复位。宽度按账号和设备保存，窗口缩小时只临时夹取，不覆盖保存值；抽屉宽度不受偏好影响。粗指针命中区扩至 `--control-touch-target`。

全屏编辑覆盖整个视口，隐藏侧栏、标题行中的侧栏按钮、标题文字、窗口操作、缩放手柄、任务栏与悬浮球，仅保留“退出全屏”；进入时关闭抽屉，退出恢复常驻侧栏状态，离开活动的笔记窗口即退出全屏。保存、固定和版本恢复刷新侧栏摘要，远端事件与窗口重新激活也触发刷新，后者保留搜索与筛选。

最小化保留编辑会话、滚动、搜索、侧栏模式、树展开与抽屉状态；关闭销毁内容。下次从关闭状态打开且没有深链或分享目标时，恢复该账号跨设备最后打开的未删除笔记；没有记录或恢复失败则停在无选中状态。同一时刻只有一个编辑会话。切换笔记与关闭窗口时先提交待保存内容，无法安全保存时提示“放弃未保存的修改？”，取消保持原状；最小化、切换窗口与浏览器前进 / 后退不提示，退出登录 / 切换账号仍受保护，`beforeunload` 对最小化窗口中的未保存笔记仍会提示。Escape 依次处理菜单 / 弹窗、焦点在内的大纲 Overlay、抽屉、全屏和窗口最小化，每次只处理一层。重复点击任务栏“笔记”不重置编辑器。

若恢复目标在查询后、打开前被删除，编辑器显示笔记不可用状态。

## Library

侧栏自上而下为：搜索框（占满整行，常驻侧栏时右端为折叠按钮）→ 固定入口“最近”“收藏” → “笔记本”区（标题行右端为“新建笔记”“新建笔记本”图标，视觉约 28px、图标 16px，粗指针以扩大命中区达到 `--control-touch-target` 而不改变视觉尺寸）→ 底部“回收站”（打开回收站窗口）。没有“全部”“首页”入口、分段筛选、笔记本下拉或“管理笔记本”按钮：笔记本树直接展示根目录笔记，覆盖全部笔记；固定到首页只在笔记菜单与图钉标记中管理。

- **两种模式**：默认为树模式，笔记本区显示笔记本树；点击“最近”“收藏”或搜索框有内容时，该区替换为该范围 / 搜索结果的平铺列表（含“加载更多”）；列表模式下标题行保持可见，标题文字换成当前范围名（“最近”“收藏”或“搜索结果”，左侧带返回箭头，无障碍名称“返回笔记本，当前：…”），创建按钮不变；点击该标题或任一笔记本节点回到树模式，清空搜索后回到进入搜索前的模式。树展开状态与选中在两种模式间保留。
- **笔记本树**：`role="tree"`（WAI-ARIA）；笔记本最多两层，笔记为叶子。根级先列根笔记本，再列根目录笔记和根级“加载更多”；根目录挂载即加载（接口仍用 `scope=uncategorized`）。展开笔记本时先列子笔记本，再列直属笔记；按笔记本懒加载（`scope=notebook`，每次 20 篇），每个节点自带“加载更多”，刷新时保留已加载的数量。键盘：↑ / ↓ 移动焦点，→ 展开或进入首个子节点，← 折叠或回到父节点，Home / End，Enter / 空格打开笔记或展开 / 折叠笔记本；Tab 只有一个停靠点。
- **选中与定位**：树内至多一个选中节点：点击笔记本 = 选中并展开 / 折叠；点击树容器空白处清空选中，新建目标回到根目录；经任何入口打开笔记 = 选中该笔记并自动展开其所在笔记本（必要时翻页），滚动到可见。未加载的笔记通过 `GET /api/documents/:id` 取得所属笔记本。
- **新建笔记的目标**（纯函数 `resolveCreateTarget`）：选中笔记本 → 该笔记本；选中笔记 → 其所在笔记本；无选中或处于列表模式（最近 / 收藏 / 搜索）→ 根目录；新笔记不自动固定到首页。“新建笔记”图标的 tooltip 写明目标，如“新建笔记（在「工作」）”或“新建笔记（根目录）”。新笔记直接进入空白编辑器并聚焦标题，不弹窗；首次保存成功后树展开目标笔记本并选中、滚入新笔记。空白新笔记再次点击新建仅聚焦标题；其他创建路径（如搜索框快速记录）仍即时创建。
- **新建笔记本的目标**：选中的根笔记本 → 其子笔记本；选中笔记、子笔记本或无选中 → 根笔记本；不会出现第三层。
- **节点菜单**（一份菜单，右键 / 触屏长按 / 每个节点可见的 ⋯ / ContextMenu 键或 Shift+F10 打开；树空白处无菜单）：笔记本为新建笔记、新建子笔记本（仅根级）、重命名、移动到…、上移 / 下移、删除笔记本；笔记为重命名、收藏、固定到首页、移动笔记本、上移 / 下移、移至回收站。操作复用同一套对话框与请求，列表行的 ⋯ 与树节点使用同一份笔记菜单项。⋯ 在键盘上不是独立停靠点，键盘用户使用 ContextMenu 键 / Shift+F10。
- **标记**：收藏显示星标，固定到首页显示图钉；列表行与树节点一致。
- **排序与拖拽**：笔记和笔记本可在同级上移 / 下移；删除笔记本保留笔记并按原序追加到根目录，子笔记本提升为根。树模式支持拖拽：笔记落在笔记行上 / 下半部，排到该笔记之前 / 之后并进入其目录；落在笔记本行中部则移入该笔记本顶部。笔记本落在根笔记本中部可成为其最后子级（被拖笔记本无子级且不能为目标自身）；落在根笔记本边缘可在根级前 / 后排序，落在子笔记本边缘可在其父级前 / 后排序（被拖笔记本无子级）；子笔记本中部与笔记行均无效，但第一个根目录笔记的上边缘可作为根笔记本末尾落点。拖动展开的笔记本时隐藏其子树，悬停折叠笔记本 600ms 自动展开，并支持自动滚动；移动 6px 激活，Escape 取消。触屏长按不动打开菜单，长按后移动进入拖拽。无效落点显示禁用反馈并通过 live region 说明；放下后目标笔记本自动展开，被移动的节点保持可见；更新先乐观呈现，失败回滚。列表模式与全屏禁用拖拽。
- 同步：侧栏随编辑器保存 / 固定产生的 `onChanged`、其他设备的事件流 `subscribeAll` 与窗口重新激活刷新，已展开节点重读，未展开节点在重新展开时重读。
- 布局：侧栏整体滚动，搜索行吸顶，“回收站”在内容较短时贴底。

### 展示标题

DTO 的 `displayTitle` 是服务端派生展示值，依次取：trimmed `title` → 首个非空
heading/paragraph 的纯文本前 100 字 → “无标题笔记”。

- `title` 可为空，仍为 canonical 字段，不回写 fallback。
- 列表和搜索只返回摘要，不返回正文。无标题记录的派生在服务端读取正文；已有标题的列表记录只读取正文前
  300 字生成 snippet。

## 首页刊头

固定到首页（`isHomeFixed`）的笔记与首页待办一起排进首页刊头：一列排版放在壁纸焦点的另一侧，
窄屏收起时只露出顶部日期块，可展开。呈现只由 `isHomeFixed` 决定，与正文长度无关；未固定的笔记只出现在
笔记库、搜索与 AI 引用中。同一笔记可以同时固定到首页、插入图片并使用分页。视觉与交互契约见
[Visual Language · 首页刊头](design/VISUAL_LANGUAGE.md#首页刊头home-masthead)，首页位置见
[首页与桌面](workspace.md#首页与桌面)。

- **顺序**：按 `homeSortOrder`、`createdAt`、`id` 升序（与 `scope=home` 列表一致）。新固定的笔记排在末尾：从未固定变为固定且请求未给 `homeSortOrder` 时，服务端写入该账号其他首页笔记的最大值 + 1。刊头内拖动条目（鼠标移动 4px、触控长按 250ms）或用 ⋯ 菜单“上移 / 下移”调整顺序，乐观更新后以 `PATCH /api/documents/home-order` 一次写入完整顺序；失败回滚并重新读取。
- **条目**：序号、`displayTitle`（无标题笔记不重复首行）、摘要与相对编辑时间。摘要按内容类型：首块为代码块或整段行内代码时显示代码首行，并提供“复制命令”（复制整个代码块 / 行内代码，成功提示“已复制”）；只有任务时显示“N 项任务 · M 已完成”；其余为去掉 Markdown 语法、图片与 HTML 后的可读文本，最多两行，其中的行内代码以等宽显示。点击或 Enter 打开笔记窗口中的该笔记。完整内容在编辑器中阅读。
- **待办汇总**：刊头的“待办”按首页顺序、文档顺序列出全部首页笔记的已完成与未完成任务，已完成项划线显示，刷新后仍保留；行尾标注来源笔记。分节标题显示完成数 / 总数。代码块内的 `- [ ]` 不算任务。
- **直接勾选**：刊头待办与编辑器中的任务行可直接点击或按 Space 切换（粗指针 ≥ 44px），只翻转对应行的 `[ ]` / `[x]`，其余 Markdown 原样保留。界面立即更新且不丢失已聚焦的控件；同一笔记 1500ms 内的多次切换合并保存。笔记在编辑器中打开时，刊头操作与编辑器当前草稿同步，不能覆盖未保存的编辑；远端更新经事件流同步。未在编辑器中打开的笔记发生版本冲突时，若目标任务行文本与序号未变，则在最新正文上重放并重试一次，否则回滚并提示“笔记已在别处修改”，可“打开笔记”。
- **管理操作**：条目 ⋯ 菜单提供编辑笔记、上移、下移、取消固定与移至回收站。移至回收站后首页提供 10 秒撤销窗口（见 [撤销与反馈](workspace.md#撤销与反馈)）。
- **数量**：不设上限；条目超出刊头高度时在刊头内滚动，底部渐隐提示还有内容；“全部笔记 →”不随条目滚动、始终可见，打开笔记窗口。
- **实时同步**：刊头与编辑器共用同一事件流，远端更新见 [实时同步与冲突](#实时同步与冲突)。顺序写入不改变笔记版本，也不发布文档事件；其他设备在下次读取首页笔记时得到新顺序。

## 编辑

编辑、分页和 Markdown 源码三种视图共用一份 Markdown 正文；编辑与分页共用同一
editor、选区和 undo history，只改变排版。编辑视图默认为所见即所得（Live Preview）。
视图偏好仅在当前设备按账号与笔记隔离。

- 标题单独保存，不自动插入 H1。
- 长文正文独立滚动；标题行保留标题、大纲、历史、“更多笔记操作”和冲突入口；侧栏折叠或抽屉模式时最左侧为侧栏展开按钮，格式工具栏折叠时右侧图标组最左为“Aa”（`Type`）按钮。底部状态信息不占独立行，固定在编辑器底部两角，正文（含分页视图末页）末尾预留空间，滚到底不被遮挡：左侧为模式切换（当前模式图标，展开时其右侧显示其余两种模式），右侧显示字数、阅读时间、分页视图的页数与保存状态（`role="status"`）。两角状态与侧栏底部“回收站”入口在同一水平线，入口上下留白相等（各 8px），窗口底部不再另留边距。编辑视图正文最大阅读宽度 720px、最低 240px；短窗口允许整个编辑器滚动。
- 模式 icon 显示当前模式并在可访问名称中说明（`aria-expanded` 反映展开）；鼠标悬停 icon 时在其右侧展开其余两种模式（编辑、分页、源码中的另两项），icon 以选中底色标示当前模式，鼠标移出模式区域即收起；点击、Enter / Space 或触屏点按 icon 也可展开，焦点离开模式区域时收起。选择后自动折叠，Escape 收起并将焦点返回 icon。各模式项保留可访问名称，加载期间分页不可用。
- 格式 icon 控制工具栏展开 / 折叠；折叠时不渲染工具栏按钮，格式快捷键仍可用，焦点在工具栏内时折叠会返回格式 icon。工具栏支持标题、强调、列表/任务、引用、链接、代码、表格、分隔线、分页符与图片；展开时只有一个 Tab 入口，方向键切换按钮，格式状态可由读屏读取，移动端保持单行横向滚动，窄容器通过“标题”和“更多格式”访问全部命令。
- 工具栏展开偏好保存在当前设备并按账号隔离：未设置时，窗口宽度 <768px 或粗指针默认折叠，否则默认展开；用户设置后不再随环境默认改变。
- 格式工具栏：展开时工具栏容器第一行右端有收起 chevron（`aria-label="隐藏格式工具栏"`）；折叠时标题行右侧图标组最左出现“Aa”按钮（`aria-label="显示格式工具栏"`，`aria-pressed` 反映展开状态）。底部状态条不再有格式图标。折叠时若焦点在工具栏内，焦点移到“Aa”按钮；通过“Aa”展开后焦点移到收起 chevron。偏好与三态默认值不变。
- 大纲由标题行 icon 展开或折叠，在编辑 / 分页视图可用，源码视图禁用；展开偏好按设备和账号隔离，默认关闭。窗口 Host 实测宽度 <768px 时为窗口内右抽屉，与左侧栏抽屉镜像且互斥：打开一侧先关闭另一侧。编辑区变为圆角卡片并左移，与抽屉留出固定间隙，点击卡片或按 Escape 关闭；抽屉外内容 inert，焦点圈定在抽屉内，关闭后返回大纲 icon。选择标题后关闭并滚动到该标题；减少动态效果时卡片直接处于错开位置，不做位移动画，抽屉仅透明度变化。≥768px 时编辑区宽度足够容纳 640px 正文加 `--document-outline-width` 则并排，否则使用不改变正文排版的右缘 Overlay；宽度变化时展开状态保持，侧栏不自动收起。Overlay 非模态，可继续编辑，定位后保持打开；面板内 Escape 关闭并返回大纲 icon，正文焦点时不消费 Escape。
- 纸张设置、打印、复制、导出与固定到首页等操作位于“更多笔记操作”。
- 字数按 CJK 字符和英文/数字单词统计，排除 Markdown 语法；阅读时间按每分钟 300
  字/词向上取整。

### 保存

- 标题或正文实际修改后 1500ms 自动保存，中文组合输入结束后才保存。
- 标题、正文与工具栏之间的焦点移动、标题 Enter 跳转和模式切换不提前提交，也不重启防抖。焦点真正移至历史或外部控件时，仅未保存草稿执行一次手动保存。
- Ctrl/Cmd+S 为显式手动保存。关闭、Esc、切换笔记或离开编辑区域时提交防抖窗口内的待保存内容。
- 进行中保存与后续输入共用队列，不重复提交同一草稿。已有笔记在组合输入中关闭不提交半成品，保留本地草稿供重开恢复。
- 已有笔记网络失败时保留 IndexedDB 本地草稿，重开可恢复或放弃；本地草稿与云端版本不一致时须显式解决冲突。
- 历史恢复创建新版本，不倒退版本号。

侧栏的新建笔记使用尚无 ID 的编辑会话：

- 空白会话不创建服务器记录；标题或正文首次出现非空白内容后，等待 1500ms 防抖及组合输入结束，再以当时的标题、正文和目标 `notebookId`、`isHomeFixed` 发送一次 `POST /api/documents`。显式保存或离开时可提前提交待保存内容。
- 创建在途期间的后续输入进入同一保存队列，不重复 `POST`；成功后会话保持不变，以返回的 ID 和 `version` 继续既有 `PATCH` 流程，自己的创建广播不触发冲突。创建成功后即使内容删空也不会退回未创建状态。
- 从未输入就离开不会创建笔记或提示；已有内容但尚在防抖期时先提交，保存失败才按现有离开保护提示。最小化保留会话，关闭窗口销毁会话。
- 首次创建失败时保留编辑内容和失败状态，可重试；关闭、退出登录和 `beforeunload` 按无法安全保存的现有守卫处理。尚未创建的笔记不写入 IndexedDB 草稿，首次保存成功前刷新或崩溃会丢失内容。

### 设备草稿

- 本地草稿保存在设备 IndexedDB，按账号与笔记隔离。笔记编辑与首页刊头使用同一份草稿。
- 退出前检查当前账号的未同步草稿并提醒；取消退出不删除草稿，确认退出后重新登录同一账号可恢复。其他账号的草稿不触发该提醒。
- 草稿恢复检查失败时暂停编辑，可点击“重试恢复草稿”。
- 会话失效后不再启动保存请求，迟到响应不更新新会话。
- 升级前的便签草稿（旧 `note:draft:*` 键）不再读取，也不迁移为笔记草稿；升级后这些旧键会被清理。升级前请在旧版本中确认便签已保存。

### 版本历史

版本历史为编辑器内部子视图。

- 进入前等待当前草稿保存及在途请求；保存失败或版本冲突时留在编辑。
- 展示版本号、绝对本地时间、标题与完整只读预览。
- “返回编辑”或 Escape 恢复原焦点、选区和滚动。
- 恢复需要确认，将标题和正文替换为选中快照；取消不写入，成功使用服务端返回版本，失败保留当前草稿与预览供重试。

### 冲突处理

有未保存修改的编辑器收到远端更新时，409 冲突对话框在“本地修改”与“云端版本”两个页签间对比：

- “用云端版本”“用我的版本”须通过独立二次确认弹窗，说明将丢弃的本地修改或被覆盖的云端版本。
- “另存副本”不需要二次确认。
- “编辑合并内容后保存”打开合并框，以本地正文为起点，不预填 Git 冲突标记；确认后保存。
- “暂不处理”（Esc 同效）关闭弹窗、不修改任一版本；冲突可从编辑器头部“处理冲突”重新打开。
- 失败时显示错误并保留本地修改。

### 实时同步与冲突

同一账号会话内的笔记编辑器与首页刊头共用一条 `/api/documents/events` SSE 连接，按笔记 ID 分发
`document.updated` 事件。编辑器等待本地排队保存结束后再比较版本，必要时读取最新笔记；事件本身不是完整 DTO。
最后一个订阅者关闭、退出登录或切换账号时关闭连接，不接收旧账号事件。

- 无本地修改时远端更新静默同步；有未保存修改才提示冲突。
- 自己保存产生的广播与过期版本不触发冲突。

### 图片

- 支持 PNG/JPEG/WebP，最大 10 MiB；上传成功后才插入 `asset://<assetId>`。
- 复制与 `.md` 导出保留正文原文及 internal asset
  ref，不附加标题，不是可独立移植的图片包；完整资产须通过数据库备份保留。

### 分页、纸张与打印

- 分页视图的纸张自上而下居中排列，使用正文外层的同一个滚动区；跨页编辑、选区及撤销属于唯一编辑器。
- 窄窗口和移动端统一缩放纸张，不改正文 Token，不保留横向滚动 strip。
- 自动分页不写回 Markdown；切换纸张或视图不会把自动断页写进正文。手动
  `<!-- pagebreak -->` 保留首部、连续和末尾空白页。
- 纸张设置支持 A4/Letter、横向/纵向和四边 5–50 mm 边距，按笔记保存到服务器。对话框为分组列表：纸张规格与版面方向一组，“页边距”一组（预设与四边各一行，单位 mm）；超出范围的边在各自行内提示，保存时焦点移到第一处，保存失败的服务端错误显示在对话框顶部。
- 打印使用独立的无应用 chrome
  排版，标题仅在首个非空白页出现；正文、图片、代码、表格和手动分页参与打印，
  自动分页由浏览器决定，不承诺与编辑视图逐像素一致。

## API

所有 `/api/documents*`、`/api/document-notebooks*` 请求需要登录；跨 owner
与不存在均返回 404。

### 实体字段

- `isHomeFixed`：是否固定到首页。
- `homeSortOrder`：首页刊头中的顺序；同值时按 `createdAt`、`id` 升序，与 `scope=home` 列表顺序一致。从未固定变为固定且请求未显式给值时，服务端写入该账号其他首页笔记的最大值 + 1（无其他首页笔记时为 0）。
- `title` 可为空（nullable）；展示使用 `displayTitle`。
- summary 与 detail DTO 均包含 `isHomeFixed`、`homeSortOrder`。
- `POST /api/documents` 与 `PATCH /api/documents/:id` 接受 `isHomeFixed`、`homeSortOrder`；`POST` 另接受 `isFavorite`。

### 列表与搜索

| 方法 | 路径                                                                                                           | 说明                                                                                                                                                                      |
| ---- | -------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| GET  | `/api/documents?scope=all\|recent\|favorite\|notebook\|home\|uncategorized&notebookId=...&limit=50&cursor=...` | 列表；`scope=uncategorized` 返回未删除且不属于笔记本的笔记，排序和游标与 `notebook` 范围一致；`scope=home` 为固定到首页的笔记，按 `homeSortOrder`、`createdAt`、`id` 升序 |
| GET  | `/api/documents/search?q=...`                                                                                  | 搜索；空搜索返回空列表                                                                                                                                                    |
| GET  | `/api/documents/trash`                                                                                         | 回收站                                                                                                                                                                    |

三者返回 `{ items, nextCursor }`，每项仅包含 summary，不返回完整 body。`limit`
为 1–100；cursor 绑定 user/scope 或 query。
`notebook` 和 `uncategorized`（根目录）按目录内 `sort_order`、`id` 升序分页；新建及从回收站恢复的笔记置于目录顶部。其他范围的排序不变。

搜索与 AI 的 `lookup_documents` 共用同一份全文索引，覆盖当前用户全部未删除的笔记（含固定到首页的笔记）。

- 查询按空白拆成词，所有词都必须命中（AND）；每个词是字面量，`-`、`OR`、`"`、`(`、`*` 等均作为普通字符，不暴露 FTS 查询语法。
- 词在标题或正文中按不区分大小写的子串匹配（连续中文同样），不要求前缀或分词边界。
- 长度 ≥ 3 个字符的词走 FTS5 `trigram` 索引，结果按相关度排序；仅含 1–2 个字符的查询（如“来源”）扫描当前用户的未删除笔记，标题命中优先，其后按更新时间倒序。同一查询混合两类词时先由索引筛选，再校验短词。
- 索引重建迁移与回退见 [部署 · 笔记全文索引](deployment.md#升级笔记全文索引改为-trigram)。

### 个人内容检索

| 方法 | 路径                                | 说明                                                                                |
| ---- | ----------------------------------- | ----------------------------------------------------------------------------------- |
| GET  | `/api/search/personal?q=...&limit=` | 登录用户的笔记与应用，分组返回；`limit` 为每组上限，1–20，默认 5；`q` 最多 200 字符 |

返回 `{ query, documents, apps }`：`documents` 为笔记 summary（同上搜索规则与排序），`apps` 为未删除的应用（含文件夹内应用），按名称以整句开头、名称包含全部词、仅 URL 命中排序，同级按首页顺序。应用名称与 URL 同样按字面量子串匹配，`%`、`_` 不是通配符。空查询返回两个空数组；他人数据、回收站笔记与已删除应用不会出现，未登录返回 401。

首页搜索框用此接口生成“我的”“应用”两组（见 [工作区 · 搜索框](workspace.md#搜索框)）；返回 401 时前端移除这两组。搜索框 `Shift+Enter` 快速记录调用 `POST /api/documents`（仅 `body`，`isHomeFixed` 与 `isFavorite` 为 `false`），“撤销”移至回收站，“固定到首页”再 `PATCH` `isHomeFixed`。

### 事件流

| 方法 | 路径                    | 说明                                                                                                                         |
| ---- | ----------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| GET  | `/api/documents/events` | SSE；连接建立后先发送具名 `ready`（`{ ok: true }`），之后发送具名 `document.updated`（`documentId`、`version`、`updatedAt`） |

### 首页顺序

首页顺序只写 `homeSortOrder`，不需要内容 `version`：写入不改变 `currentVersion` 与 `updatedAt`、
不生成版本、不发布文档事件。

- body 为 `{ ids: string[] }`：1–500 项、不得重复；请求体不合法返回 400。
- `ids` 必须恰好是当前账号全部未删除且固定到首页的笔记：任一 `id` 不属于当前账号或已删除返回 404；
  缺少或多出首页笔记（含未固定的笔记）返回 409，客户端据此重新读取首页笔记。两者都不写入任何一项。
- 成功时在一个事务内按请求顺序把 `homeSortOrder` 写为 0…n−1，响应按请求顺序返回
  `{ items: [{ id, homeSortOrder }] }`。

| 方法  | 路径                        | 说明                                                |
| ----- | --------------------------- | --------------------------------------------------- |
| PATCH | `/api/documents/home-order` | body 为 `{ ids }`（完整首页顺序）；返回 `{ items }` |

旧的首页网格布局（`document_layouts` 表与 `/api/documents/:id/layout`、`/api/documents/layouts`）已删除，见 [部署 · 首页刊头](deployment.md#升级首页刊头取代首页笔记网格)。

### 实体与生命周期

| 方法        | 路径                                           | 说明                                                                                                   |
| ----------- | ---------------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| POST        | `/api/documents`                               | 创建；可提交 `isHomeFixed`、`homeSortOrder`、`isFavorite`                                              |
| GET / PATCH | `/api/documents/:id`                           | 读取 / 更新；PATCH 必须提交当前 `version`，冲突返回 409 与 `data.currentDocument`；不接受 `notebookId` |
| DELETE      | `/api/documents/:id?version=N`                 | 软删除                                                                                                 |
| POST        | `/api/documents/:id/restore`                   | 从回收站恢复                                                                                           |
| DELETE      | `/api/documents/:id/permanent`                 | 永久删除，级联清理资产                                                                                 |
| GET         | `/api/documents/:id/versions`                  | 版本历史                                                                                               |
| POST        | `/api/documents/:id/versions/:version/restore` | 恢复历史版本；body 提交当前 `version`，创建新版本、不回滚计数                                          |
| GET         | `/api/documents/last-opened`                   | 返回当前用户最近打开的未删除笔记 `{ id }`，没有则为 `null`                                             |
| PUT         | `/api/documents/:id/opened`                    | 记录打开时间，返回 `null`；不改变版本或更新时间，也不发送事件                                          |
| POST        | `/api/documents/:id/position`                  | `{ notebookId, beforeId?, afterId? }` 移动到目标目录，返回 summary；不指定锚点时置顶                   |

- `title` 最大 200 characters，Markdown body 最大 1,000,000
  characters，create/update JSON 请求最大 8 MiB；超限拒绝、不截断。
- 内容变化的 autosave snapshot 间隔 10 分钟，每篇笔记仅保留最近 100 个；`manual`
  / `conflict_resolution` / `restore` / `system` 快照不参与清理。title/body
  未改变不生成内容快照。
- 笔记定位的前后锚点最多指定一个；锚点必须属于目标目录。笔记、笔记本或锚点不存在、无权访问或已删除返回 404，目录不匹配或同时指定两个锚点返回 400。定位不更改版本或更新时间，但发送常规笔记更新事件。

### 笔记本

| 方法           | 路径                               |
| -------------- | ---------------------------------- |
| GET / POST     | `/api/document-notebooks`          |
| PATCH / DELETE | `/api/document-notebooks/:id`      |
| POST           | `/api/document-notebooks/:id/move` |
| PUT            | `/api/document-notebooks/reorder`  |

最多两层，允许同名。删除不删除笔记：直接笔记按原顺序追加到根目录，子笔记本提升为根。
`move` 接受 `{ parentId, beforeId?, afterId? }`，前后锚点最多指定一个；省略锚点时追加到目标层末尾。深度限制不变。`reorder` 提交目标 parent scope 的完整 ids。

### 图片资产

| 方法         | 路径                                          |
| ------------ | --------------------------------------------- |
| POST         | `/api/documents/:id/assets`（multipart file） |
| GET / DELETE | `/api/documents/:id/assets/:assetId`          |

- 仅 PNG/JPEG/WebP，校验 MIME 与 magic bytes，最大 10 MiB。
- 读取同时校验 document/asset/owner；正文仍引用的资产不能直接删除。
- bytes 存于 SQLite BLOB，`storage_ref`
  不公开；软删除保留资产，永久删除级联清理。

### 纸张设置

`GET/PUT /api/documents/:id/settings`：仅同步
`a4`/`letter`、`portrait`/`landscape` 与四边 5–50 mm margins（默认 20
mm）；不保存 view、sidebar、outline 等设备 UI 状态。
