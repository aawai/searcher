# UI 验收清单

UI PR 在描述中逐项勾选；不适用写原因。依据 [VISUAL_LANGUAGE.md](VISUAL_LANGUAGE.md)，条目按其三层组织：底线以 WCAG 2.2 AA 为基准、不得放宽，项目附加条目只能经人类在 Issue 中明确批准修订；系统语法的偏离须按修订门槛写明语义与验证方式，风格方向的变更须有对应契约子任务。build / test 通过不能代替实页验证；验收记录写在 PR 中，不写回本文件。

## 底线

条文与已知缺口见 [VISUAL_LANGUAGE · 底线](VISUAL_LANGUAGE.md#一底线)。light / dark 均检查；合成测试探针不替代实页检查，已登记的未达标项不因登记而视为通过。

### 基准：WCAG 2.2 AA

- [ ] **1.4.1**：选中、当前、错误等状态有颜色以外的视觉线索（勾号、外环、形状、字重、指示条长度、位置）；`aria-current` / `aria-pressed` 只是语义，不算视觉线索。
- [ ] **1.4.3**：正文与次要信息文字（含 `--muted` 与占位文字）≥ 4.5:1，≥ 24px 的大字 ≥ 3:1；禁用控件、纯装饰与品牌字标除外。
- [ ] **1.4.10**：320 CSS px 宽无双向滚动；只有表格、代码块、编辑器内容等二维内容在自身容器内横向滚动。
- [ ] **1.4.11**：识别控件或其状态所必需的视觉信息 ≥ 3:1；文本字段有占位文字或始终显示值，复选框、单选、开关等图形部件的边界与状态指示 ≥ 3:1。
- [ ] **1.4.13**：Tooltip、悬停菜单与建议可用 Escape 关闭且焦点不移动；指针可移到出现的内容上；内容在移开或关闭前不自动消失。
- [ ] **2.1.1 / 2.1.2**：全部功能可用键盘完成（含右键菜单、悬停才出现的操作、拖拽的键盘路径）；焦点能离开任何组件，模态焦点圈定可用 Escape 或关闭按钮解除。
- [ ] **2.4.3 / 2.4.7**：打开、关闭层或删除条目后焦点不丢失且落点符合阅读顺序；键盘焦点始终可见。
- [ ] **2.4.11**：获得焦点的元素不被窗口、任务栏、Toast、浮层完全遮挡。
- [ ] **2.5.7**：拖拽完成的功能有不需要拖拽的单指针替代（菜单、按钮或预设）。
- [ ] **2.5.8**：任意指针下可操作目标 ≥ 24×24，或 24px 直径圆不与相邻目标相交；段落内文字链接除外。

### 项目附加条目

- [ ] **A1**：焦点指示与相邻颜色 ≥ 3:1；焦点环为 2px `--ring`，只在 `:focus-visible` 出现。
- [ ] **A2**：粗指针下可操作目标的命中区 ≥ 44×44（可见尺寸可更小，命中区由 `primitives.css` 的共享伪元素规则扩展）；相邻目标的扩展区互不覆盖，间距不足时改为可见放大；仅悬停出现的操作在触屏常显或进入 `⋯` 菜单。另在 1440 + 触屏笔记本（主指针精细、存在触屏）检查紧凑控件的命中区。
- [ ] **A3 / A4**：`prefers-reduced-motion` 下无非必要的位移、缩放、旋转与尺寸 / 位置插值；`prefers-reduced-transparency` 或不支持 `backdrop-filter` 时为可读实色。
- [ ] **A5**：Escape 每次只关闭最上一层；焦点回到触发控件，触发控件已不存在时回到其所在容器。
- [ ] **A6**：首页改动涉及壁纸、遮罩、光晕或直接落在壁纸上的文字时，`web/e2e/wallpaper-readability.test.ts` 通过；新增直接落在壁纸上的文字消费 `--wallpaper-text-stroke` / `--masthead-text-stroke` 与光晕 Token 并进入其取样范围；默认遮罩（`balanced`）与默认玻璃档位下在浅 / 深 / 高频纹理壁纸上实页审阅描边观感。
- [ ] **A7**：`forced-colors: active` 下控件、状态与焦点指示可辨。

## 系统语法

- [ ] 只使用 Token；字号与圆角只取 VISUAL_LANGUAGE 阶梯登记的 Token；`deno task check:ui` 通过。
- [ ] 无卡片套卡片；内容层无阴影；边框只用于细线分隔或独立表单控件。
- [ ] 文本字段有占位文字或值，`--field-border` 边框可见；焦点指示（2px `--ring`）与无效态边界（`--danger`）≥ 3:1。
- [ ] 两个及以上字段的表单使用分组列表行，字段级错误与说明紧贴所属行（行内第二行，被字段的 `aria-describedby` 引用，客户端错误聚焦该字段）；单字段、搜索 / 筛选框与多行输入使用独立字段。对话框内的分组表单整窗为 `--surface-grouped-canvas`，标题与页脚无色带。
- [ ] 分组列表单值行高 44：行内分段控件为紧凑档（选项 28），按钮等高于 28 的控件不撑高行；带说明的行与 `.settings-row--vertical` 复合行按内容增高。
- [ ] 设置 `font-size` 角色 Token 的声明块同时设置对应 `line-height`（正文除外），不让 12px 文字继承 22px 正文行高。
- [ ] 圆角容器内贴着内边距的圆角子项与容器同心（子项圆角 = 容器圆角 − 内边距）；不同心时注明原因。
- [ ] 菜单与建议列表的高亮为中性底，键盘移动时另显示 2px `--ring` 内描边，指针悬停只有底色；按钮按压有缩放反馈，hover 只在可悬停指针下出现。
- [ ] 字重只用 400 / 500 / 600；不用全大写。
- [ ] 每个区域最多一个 primary 按钮。
- [ ] 没有复述标签的说明行、使用说明段落或“登录后可用”类提示；空状态为一句话 + 至多一个操作。
- [ ] 动作名称全流程一致；使用应用窗口、笔记窗口与任务栏，无旧资料库总览入口、无右侧面板或视口底部 Sheet 呈现；笔记通过侧栏 / 窗口内抽屉切换而非返回列表；首页固定与任务栏固定文案明确区分。
- [ ] hover / focus-visible / active / selected / disabled / loading / error 均可辨识，且不改变尺寸。
- [ ] 次要操作可通过 hover、`⋯`、右键或长按发现。
- [ ] 破坏性操作经 AlertDialog 确认或提供撤销。
- [ ] 新增 Token、例外或阶梯登记项已写入 VISUAL_LANGUAGE，并说明语义、owner 与验证方式。

## 风格方向

- [ ] 强调色只用于已登记的交互语义与色样；作为 background / fill 的位置已登记；未用于装饰、大面积背景或渐变。
- [ ] 材质只出现在壁纸之上；透明度、模糊只取 `data-glass` 档位 Token，并有实色回退与 `--shadow-material-edge`。
- [ ] 动效回应操作；出现与消失成对；入场位移不超过 8px（底部 Sheet 除外）；共享元素仅变形同一对象，reduced-motion 下同时长纯透明度、无尺寸 / 位置插值，无 API 时立即切换；展开后焦点进入目标，关闭后返回触发控件。
- [ ] 偏离风格方向的改动已有对应契约子任务，原型停留在 `/design-lab/*` 的不进入生产。

## 实页矩阵

实验通道（`/design-lab/*`）不适用本节。生产 UI 按本次影响面选择范围，明确要求的验收场景与既有 CI 门禁不得省略：

- **完整矩阵**：改变共享 Token / 组件的视觉输出、全局或页面布局、响应式规则、主题或窗口几何时，
  受影响页面须覆盖 390×844、768×1024、1440×900 × light / dark。
  窗口内容还须覆盖受影响的 Host 宽度阈值两侧及默认几何，不能用视口宽度代替 Host 宽度。
- **局部验证**：仅局部文案、独立控件状态或不影响上述共享契约的调整，可选择能暴露回归的代表组合；
  文案检查受影响容器的窄宽度与换行，交互检查相关状态、键盘和焦点，颜色或材质变化检查 light / dark。
  影响面不确定或局部证据不足时扩大到完整矩阵。
- **行为与视觉分开**：不在每个视觉组合重复完整业务流程；下方专项清单仅对受影响的契约适用，
  不因历史验收记录自动增加本次范围。

- [ ] 已记录影响面、所选页面 / 视口 / 主题 / Host 组合及选择依据；不适用项说明原因。
- [ ] 所选组合的实页截图逐张审阅；无横向溢出、无裁切、无重叠，受影响交互验证通过。
- [ ] 首页改动涉及登录可见性或壁纸 / 材质时，另检查对应的访客 / 登录、无壁纸 / 图片壁纸状态。
- [ ] 截图路径、发现的问题与影响交付的未验证项写入 PR 描述。

## #338 窗口体系验收

C1 接入设置 / 账户和回收站，C2 接入应用与笔记，C3 接入 AI 问答；五个功能窗口均已上线。实验原型不能替代真实业务及浏览器历史验证。

- [ ] 唯一首页桌面及五个功能窗口均有 Host、canonical URL、恢复与销毁保护；访客设置仍为独立页，刷新只按 URL 重建。
- [ ] 1440×900 校准五种初始矩形，1024 检查内容容量及工作矩形；四边 Dock 的应用锚点、隐藏入口/悬浮球回退和最大化避让均可操作。
- [ ] 任务栏入口对所有窗口都是切换（活动则最小化，已最小化则恢复）；浏览器失焦、portal、全局模态、IME 不误触收起；拖动、调整、最大化后入口仍可切换，窗口位置在最小化与关闭重开后保持，按下标题栏不跳位。
- [ ] 360 与 390 手机实测六入口滚动、固定应用独立容量和选项菜单可达，命中区不小于 44px；手机窗口四周内缩 8px（与任务栏之间同为 8px），应用窗口网格排 4 列且无横向溢出；768 单活动窗口与 1440 重叠窗口均检查。
- [ ] 活动与已打开状态不只靠颜色；最小化/返回桌面保留内容与焦点，不触发销毁保护。
- [ ] 唯一 blocker、POP 的 reset/proceed 和局部路由方案经 spike 验证；取消保护时 URL、焦点、内容保持，关闭和会话替换才触发相应保护。
- [ ] 标题栏及操作菜单键盘移动/调整、Enter 提交、Escape 撤销、状态播报；窗口层 Escape 应用/笔记最小化，AI/设置/回收站不响应；portal、全屏笔记与 IME 层次正确。
- [ ] Host 宽度而非视口决定功能紧凑布局；默认几何、Dock inset、安全区与投影的语义、owner、guard 精确边界登记并有测试；不得扩大原型豁免。
- [ ] 360 / 390 / 768 / 1440 × light / dark 实际浏览器审阅并记录截图与问题，另检查粗指针、减少动效和透明度；未验证项明确标注。

## #340 笔记窗口 I2 验收

## #340 笔记窗口 I3 / I4 验收

- [ ] 左侧栏抽屉打开时编辑区为 `--radius-sheet` 圆角卡片并右移；右侧大纲抽屉打开时镜像左移，宽度为 `min(--document-outline-width, 80%)`，卡片 inert、点击关闭；`prefers-reduced-motion: reduce` 下无位移与缩放，仅同时长透明度变化；焦点、inert 与 Escape 在动效期间不变。360 / 390 × light / dark 实页检查，另检查 768 边界。
- [ ] 笔记本树：方向键 / Home / End / Enter、单一停靠点、aria-level / expanded / selected；按笔记本懒加载与每节点“加载更多”；根笔记本后直接显示根目录笔记及根级“加载更多”；点击树空白清空选中并使新建目标回到根目录；打开笔记自动展开并滚入可见。
- [ ] 节点菜单：右键、⋯、ContextMenu 键与 Shift+F10 同一份；触屏长按打开且松手不触发节点；笔记本 / 笔记菜单项与禁用状态正确，均可同级上移 / 下移。
- [ ] 树拖拽：笔记在笔记行上 / 下半部前 / 后排序或移入该笔记的目录，落在笔记本中部移入顶部；笔记本在根笔记本边缘排序、中部移为最后子级，在子笔记本边缘同级排序，受两层限制；第一个根目录笔记上边缘可放到根笔记本末尾，其余笔记落点与子笔记本中部无效。检查拖动浮层、插入线 / 高亮、无效落点及 live region、失败回滚、展开子树隐藏、600ms 悬停展开、自动滚动、6px 激活与 Escape 取消；触屏长按不动打开菜单、长按后移动拖拽；列表和全屏禁用拖拽。
- [ ] 模式切换：固定入口与搜索进入列表，“笔记本”与节点回到树，清空搜索恢复前一模式；新建笔记 / 笔记本目标与 tooltip 正确，延迟创建后树展开目标并选中新笔记。
- [ ] 图钉标记在列表行与树节点；无分段筛选、笔记本下拉、管理笔记本按钮；回收站入口打开回收站窗口。390 / 768 / 1440 × light / dark 实页检查无裁切与重叠。
- [ ] 笔记常驻侧栏 / 大纲分隔条的指针拖动、粗指针命中区、方向键 / Home / End / 双击复位、窗口缩小时临时夹取及账号 / 设备隔离正确；抽屉不提供调宽。
