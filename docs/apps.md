# 应用

应用（webapps）是登录用户保存的网址快捷方式，可分组到文件夹并固定到首页。

## 首页固定应用

登录后首页搜索框下方显示固定应用；完整管理通过首页 Dock 进入应用工作区。

- PC
  从搜索框左边界起排，移动端整组图标居中，均按容器宽度自动换行；展开文件夹后，内部应用从左侧起排。
- 首页保留 64px 方形占位，图标之间的行列间距均为 6px。
- “设置 → 搜索”选择显示 8、12、16 个或全部。
- 右键应用图标（触屏长按；键盘菜单键或
  Shift+F10）打开操作菜单，包括首页的“编辑布局”；
  编辑时可拖动带提示的图标，键盘用方向键排序。
- 首次进入首页时显示一次“整理”提示，说明右键、长按与 Shift+F10 /
  菜单键的入口；关闭状态按设备与账号保存。
- 不显示悬浮省略号按钮或图标下方的左右移动按钮。

## 应用工作区（Unified Launcher）

应用工作区打开即为完整 Unified Launcher：文件夹与未归组应用在同一 root
网格混排，包括空文件夹。

- 文件夹原地展开，返回恢复原图块的焦点与滚动位置，不切换工作区路由。
- 搜索应用名称或网址返回去重后的应用，搜索文件夹名返回文件夹；打开匹配文件夹清空搜索。
- 搜索结果分“文件夹”与“应用”两组；应用行显示名称、hostname
  与所属文件夹，打开与更多操作为并列按钮。
- 图块菜单支持改名、大小与删除；删除文件夹不删除成员。
- 标题栏以“添加应用”图标按钮作为唯一主操作；空状态不重复添加按钮，不显示常驻操作说明。
- 应用表单以会话隔离：有未保存修改时，应用内离开与返回均先经过确认（统一由路由
  blocker 裁决，与工作区 Escape 和确认共用同一归属）；仅 dirty
  会话注册浏览器离开提示。
- 自动生成的名称不覆盖用户手动输入的名称；网址变化后的过期响应被忽略。
- 图标区默认折叠，校验错误时自动展开；“更换图标”进入图标编辑。

### 空白面菜单与整理模式

搜索框以下的应用内容面（包括最后一行图标下方）支持空白处右键、键盘菜单或触屏长按，
菜单提供“新建文件夹”和“整理布局”；搜索结果、空状态和文件夹内联视图保留相同入口。空白面保留正常触屏滚动。

进入整理会清空搜索；整理时菜单改为“完成整理”并禁用“新建文件夹”，同时隐藏添加入口。

- 应用拖到文件夹为归组；其他 root
  图块拖拽为混排排序；文件夹内拖拽仅改变成员顺序。
- 失败回滚并显示错误。
- Root 混排以单次 `PUT /api/webapps/reorder` 的 `{ items, groups }`
  原子保存；成员移入与移出追加到目标末尾，不改变首页 `pinnedSortOrder`。
- 布局保存在服务端快照确认后才采用；失败时提示可关闭，且不把旧数组覆盖到更新的排序上。退出整理或关闭工作区不终止已发出的保存；布局缓存与保存按账号隔离。

## AI 生成图标

添加或编辑应用时，在“图标 → AI 生成”选择图片模型、图片生成协议和风格。Provider
配置见 [AI](ai.md)。

### 协议

| `imageProtocol`              | 端点                                   | 请求                                               |
| ---------------------------- | -------------------------------------- | -------------------------------------------------- |
| `openai`（默认，省略时使用） | `/images/generations`                  | `n: 1`、`size: "1024x1024"`                        |
| `gemini`                     | `v1beta/models/:model:generateContent` | `responseModalities: ["IMAGE"]`，解析 `inlineData` |

- 仅当服务商支持 Gemini 原生接口时选择 `gemini`。协议仅用于本次图片请求，不修改
  Provider、文本模型配置、模型发现或聊天 SSE。
- Gemini 原生接口从 Base URL 去掉末尾 `/v1`、`/v1beta` 或对应的 `/openai`
  后缀，保留代理前缀；模型 ID 仅去掉原生 `models/` 前缀，不推断命名空间。Google
  官方域名使用 `x-goog-api-key`，其他代理沿用 Bearer。

### 发送内容

- 风格：极简、几何、符号、线性、双色、柔和渐变、柔和 3D、图形角色。
- 应用名称必填；域名从应用网址提取且只发送 hostname，不发送路径、query 或
  fragment。
- 可选“用途”最多 300 字，仅用于本次生成，不保存为应用字段。
- 生成前展示
  Provider、模型、图片协议、风格及实际发送的名称、域名和用途；取消不发起请求。

### 生成与结果

- 每次生成发起三个独立的单图请求；请求可能产生 Provider 费用。
- Prompt
  以已知官网/品牌图标的核心视觉语言为身份基线，要求单张画布只展示一个图标，并约束
  32 / 48 / 64px 可读性、单焦点、安全边距和候选差异；实际效果取决于 Provider /
  模型。
- 选中候选后沿用上传与图片校验流程，文件上限 2 MiB。
- 单次上游请求超时 60 秒；失败详情遮蔽当前 Provider 的 API Key。
