## 本次验证

- 认证与图标上传路由测试、AI 客户端与临时对话测试、AI 路由测试通过；覆盖长邮箱、图标大小边界及图标生成错误不暴露上游内容。
- 浏览器测试覆盖登录注册、导航与同步说明、应用编辑、AI 窗口、笔记树与回收站操作。应用测试首次因旧“本地上传”选择器失败，更新后按默认超时复查通过。
- 实页逐项审阅：浅色默认外观、390×844 访客首页 / 登录 / 注册 / 数据与同步 / 404，普通用户首页 / 应用及表单 / 笔记及长标题编辑器 / 回收站 / 账户 / 数据与同步 / AI 问答及生成参数，管理员备份 / 删除确认 / 无模型状态；1440×900 审阅普通用户应用 / 笔记 / 数据与同步 / AI 问答及管理员用户 / 备份页面。窗口使用页面默认 Host。窄屏生成参数弹层曾被视口裁切，修复后滚动到底部的操作可达，并有聚焦 E2E 覆盖。
- 删除确认在隔离账户上验证：`copyuser` 可启用确认，`@copyuser` 与 `CONFIRM` 不可；取消未执行删除。生成参数在隔离账户上验证当前重置不清除已保存的模型默认，清除默认则移除已保存设置。注册密码最小值前一位、最小值、最大值、最大值后一位的 API 边界测试通过。
- 实页证据不覆盖所有失败注入、分享入口或窄 Host 组合；聚焦测试通过不代表完整浏览器门禁通过。部分旧选择器首次失败，修正后仅复查受影响文件。
- AI 生成参数未设置时，滑块仍显示固定回退值；实际请求按用户模型默认、全局默认继承。该既有显示行为未在本次变更，不能把滑块的显示值当作实际请求的证明。
