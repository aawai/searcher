# #383 高对比主题实页验收（PR-D）

日期：2026-11-06。基于 main `90beaa4`（PR-A #388、PR-B #389、PR-C #390 已合入）及本 PR 的修复。环境：生产构建 + 隔离内存数据库，Playwright 1.56.1 Chromium（Linux）。截图位于 [evidence/](evidence/)，参考图为 [evidence/reference.png](evidence/reference.png)（#383 正文拼图）。

## 影响面与组合选择

PR-B/C 改变了颜色 Token、边界与选中态，按 [UI_CHECKLIST · 实页矩阵](../../design/UI_CHECKLIST.md#实页矩阵) 适用完整矩阵的高对比部分：

| 维度     | 覆盖                                                                                                                                                                                                                                                                |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 主题     | 高对比浅色、高对比深色；浅色 / 深色只复查外观设置页（5 项主题入口在普通主题下同样可见）                                                                                                                                                                             |
| 视口     | 390×844、768×1024、1440×900                                                                                                                                                                                                                                         |
| 页面     | 首页（登录 / 访客）、设置 → 外观（登录 / 访客、键盘焦点）、回收站（应用 / 笔记两个 Tab）、彻底删除 AlertDialog、笔记窗口（Markdown：标题、链接、行内代码、列表、引用、代码块、表格）、AI 问答（会话含代码块与表格）、管理后台用户页、任务栏右键菜单、强调色 Popover |
| 壁纸     | 无壁纸（全部组合）；合成风景照片壁纸（390 / 1440，登录）                                                                                                                                                                                                            |
| 辅助模式 | 1440 × 两个高对比主题 × `forced-colors: active` / `prefers-reduced-transparency: reduce` / `prefers-reduced-motion: reduce`，首页与外观设置                                                                                                                         |

窗口 Host 宽度阈值未单独扫描：本次只改变颜色与边界，不改变几何；几何仍由既有 workspace / documents 矩阵覆盖。

截图命名：`<页面>-<主题>-<视口>.png`，如 `settings-appearance-high-contrast-dark-768.png`；辅助模式为 `<页面>-<模式>-<主题>-1440.png`。每张截图前检查文档横向溢出，全部为 0。

## 优先级

- `forced-colors: active` 叠加高对比主题（`*-forced-*`）：系统色主导：导航当前项、分段与 Switch 为系统 `Highlight`，链接类文字为系统 `LinkText`，应用高亮不出现。由 `forced-colors.test.ts` 在两个高对比主题下断言（暂时去掉 `@media (forced-colors: none)` 包裹时该断言失败）。
- `prefers-reduced-transparency: reduce` 与高对比主题：搜索框、任务栏实色、无 `backdrop-filter`，与单独的高对比主题相同。
- `prefers-reduced-motion: reduce`：高对比主题不引入动效；外观与单独的高对比主题相同。

## 自动化

- `forced-colors.test.ts`：A7 用例扩展到高对比浅色 / 深色；`high-contrast.test.ts` 中重复的 forced-colors 单点断言随之移除。
- `ai-window.test.ts`：输入框聚焦环上缘像素等于 `outline-color`。
- 对比度下限仍由 `glass-contrast.test.ts` 的高对比用例与 `wallpaper-readability.test.ts`（A6）保证，本次未改动。
